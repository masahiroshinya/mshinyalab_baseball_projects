# 棒グラフと個人の値の点（bar-points）

状態：試行中。作成：2026-10-19。

## 1. 対象の図

条件（または群）ごとの平均の棒と、個人の値の点。含みうる要素：

- 条件ごとの棒（平均）と誤差棒（SD など）
- 個人の値の点
- 個人を結ぶ線（任意。反復測定のとき）
- Affinity で加える有意差記号（ブラケットと記号。任意）

## 2. 既定値

[defaults.json](defaults.json)（共通の既定値は [../defaults.json](../defaults.json)）：

| 項目 | 値 | 意味 |
|---|---|---|
| `barWidth` | 0.6 | 棒の幅（条件の間隔に対する割合） |
| `barColourPercent` | 40 | 棒の塗り：条件の色の割合 [%]（残りは白）。点（条件の色 100 %）と区別するため |
| `errorBarsBehindBars` | true | 誤差棒を棒の背面に置く（2026-10-19、ユーザーの指定）。棒から上に出た部分だけが見える |
| `participantLineColour` | [153, 153, 153] | 個人を結ぶ線の色（黒 40 % の灰色） |

## 3. 作図と成分のページ

- 描く順（背面から）：誤差棒（`errorBarsBehindBars` が true のとき）、棒、個人を結ぶ線、点、誤差棒（false のとき）。MATLAB で描く順と、成分のページの順（`spec.components`）を揃える。
- 棒は条件ごとに 1 つの `bar` で描き、`'ShowBaseLine', 'off'` にする（横軸と重なる基準線を出さない：docs/figure-panel-style.md の 3 節）。
- 個人を結ぶ線がない図では、`lines participants` の成分を作らない。
- 成分（サブレイヤー）：`error bars`、`bars <条件>`、`lines participants`（任意）、`markers <条件>`、`axes`。
- 縦軸：非負の量は 0 から切りのよい値まで。有意差記号の分の余白を含めて範囲を決める。

## 4. Affinity で加える注釈

- `bracket`：有意差のブラケットと記号。記号の文字は、有意かどうかだけを示す（`*`、有意でなければ `n.s.`。p の大きさで記号の数を変えない：2026-10-19、ユーザーの方針）。
- 隣り合う比較のブラケットは同じ高さにし、端を少し内側に寄せて接しないようにする。両端の比較は上の段に置く。
- 記号とブラケットの間隔は `textGapMm`（既定 0.5 mm）、ブラケットの脚の長さは `legMm`（既定 1 mm）。
- 記号の文字・フォント・大きさは、Affinity で Panel style の「significance marks」でパネルごとに変えられる。

## 5. 方針との違い

なし。

## 6. 確認すること

- 誤差棒が棒の背面にあること（レイヤーの順：`X: error bars` が棒より下）。
- 有意差記号が縦軸の範囲に収まること（例のスクリプトは収まらないときに止まる）。
