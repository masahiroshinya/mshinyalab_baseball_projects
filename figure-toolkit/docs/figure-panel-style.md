## 1. 軸範囲と目盛り

- xlim・ylimは明示し、切りのよい数値を使う。自動設定による端数の範囲をそのまま採用しない。例えば[-0.4, 0.4]、[0, 0.5]、[-20, 20]とする。
- ゲイン、トルク、誤差など、正負の符号を持つ量の線形縦軸は、原則として0を中心に正負対称の[-L, L]とする。例えば[-1.5, 1]なら[-1.5, 1.5]へ広げる。一方の符号しか現れない場合も、符号付き量の波形はこの原則を用いる。
- Lは表示対象の全系列の最大絶対値を収める値へ切り上げる。例えば1、1.5、2、2.5、3、4、5、6、8、10の10の整数乗倍から、少し余白を確保できる値を選ぶ。対称化のためにピークや試行を切り落とさない。
- 目盛りは読みやすい間隔とし、対称な軸では0と正負に対応する目盛りを表示する。多数のパネルではラベルが重ならない数に抑える。
- パネルごとに範囲を選ぶ場合も上記を満たす。同じ単位・同じ指標の条件比較では、比較に必要な共通範囲を優先する。単位が異なる量へ同じ数値範囲を機械的に適用しない。
- 分散・RMSE・割合など非負の量や、位置・高さなど座標原点による表示は、量と図の目的に合った範囲を使う。対数軸へ正負対称の原則を適用しない。対数軸では10の整数乗などを目盛りに使い、0の扱いや表示下限による切断を説明する。

## 2. 表示

- 図中のラベル・凡例は英数字を基本とし、英語・英数字のフォントはArialとする。軸ラベル、目盛り、凡例、タイトル、注釈にも適用する。gridはoffとする。
- 軸線・目盛り線とプロットの線幅は、原則1 ptとする。個別の図で線種・成分ごとの線幅が指定された場合は、その指定を優先する。例えば、関節内成分1 pt・関節間成分2 ptという指定は、その図のプロット線に適用する。
- 縦線・横線は意味があるものだけを表示する。軸端に達したイベントを重ねて強調する必要がない場合、イベント線は省く。表示範囲やイベント線についての個別指定を優先する。
- データに依存する内容（軸、目盛り、ラベル、凡例、線の色・太さ、データの値に正確に合わせる線（イベント線、基準線など））は描画環境（MATLAB 等）で指定する。組み立て後に Affinity で個別に直すと、図を作り直すたびに同じ修正が必要になるため。
- 有意差記号、スケールバー、説明の矢印などの注釈は、Affinity でパネルの `X: annotations` に加える（4.1 節）。多少位置がずれても、レイヤーが適切に組まれていれば手で容易に調整できるため（2026-10-16 決定）。
- 文字の大きさ（既定。2026-10-19 決定、ユーザーの指定）：パネル記号 9.75 pt（Arial Bold、Affinity で加える）、軸ラベル・タイトル 9 pt、目盛り・凡例・グラフ内の文字（イベント線の名前、注釈、有意差記号）7.5 pt。値は [figure-types/defaults.json](../figure-types/defaults.json) の `fontSizePt`（panelLabel、axisLabel、tickLabel）。
  - パネル記号 > 軸ラベル > 目盛り の大小関係を保つ。値を変えるときも、この関係は崩さない。
  - いずれも 0.75 pt の倍数にする。MATLAB の書き出しでは、文字の大きさが 0.75 pt の倍数に切り捨てられるため（3 節）。
  - 図は原寸で原稿に置く（拡大縮小しない：figure-assembly-style.md の 4 節）ので、ここで指定した大きさが印刷される大きさになる。
  - 1 つの雑誌の規定に合わせて変える場合（例：Nature 系の上限 7 pt）は、その図の個別の注文として扱い、既定値は変えない（figure-style.md の「個別の注文の扱い」）。

## 3. 保存（描画環境からの書き出し）

- PNGと、後で編集できるSVGを保存する。SVGは文字を保持し、可能な範囲でベクトル要素として出力する。
- 図を Affinity で組み立てる場合は、加えて PDF（ベクター、文字を保持）を書き出す。複数パネルを 1 枚にまとめる図では、各パネルを 1 ページずつ追記した複数ページの PDF も書き出す（`'Append', true`）。Affinity には別ファイルを配置する API がないため、1 つの PDF として開いてページ間で移す（開発時の試行 A4）。
- MATLAB で組み立て用の PDF を書き出すときは、次の指定にする（2026-10-16 に R2025a で確認）。
  ```matlab
  ax.Color = 'none' ; % 軸の背景の白い矩形を出さない
  barHandle.ShowBaseLine = 'off' ; % 棒グラフ：横軸と重なる基準線を出さない
  exportgraphics(fig, 'x.pdf', 'ContentType', 'vector', ...
      'BackgroundColor', 'none', ... % 図の背景の白い矩形を出さない
      'Padding', 'figure') ; % ページを図の大きさに固定する（既定では内容に合わせて余白が切り詰められる）
  ```
  - `'Padding'` を指定しないと、同じ 8×6 cm の図でもページ幅が内容によって変わった（71.3 mm と 72.0 mm）。`'Padding', 'figure'` ではどちらも 80.1×60.3 mm になった。
  - 背景の矩形と基準線を出さない理由と、組み立て時の扱いは 5 節。
  - 手での微修正のために意味のまとまり（軸、条件ごとの棒など）を作る図は、成分ごとにページを分けて書き出す（5 節）。
- EPS は組み立てに使わない。Affinity で開くと文字が曲線に変換され、字形も置き換わる（同 A3）。
- 図の寸法（幅・高さ）は書き出し時に決める。組み立て後に拡大縮小すると、文字は縮むが線幅は変わらない（同 B3）。
- 図の幅は、図全体の幅（段の幅。既定は single column 90 mm、double column 190 mm）以下にする（figure-assembly-style.md の 4 節）。
- 並べるパネルは、図の大きさと軸の位置を揃えて書き出す。MATLAB では figure の Position を揃え、axes は `PositionConstraint = 'innerposition'` にして InnerPosition（軸の枠の位置と大きさ）を数値で固定する。既定の `'outerposition'` では、目盛りラベルの幅に応じて軸の枠が変わる（2026-10-16 の確認：縦軸 0〜1 と 0〜10000 で、枠の左端が 1.04 cm と 1.27 cm、幅が 6.19 cm と 5.96 cm。y ラベルの長さだけの違いでは変わらなかった）。`'innerposition'` で InnerPosition を指定すると、y ラベルの長さを変えても指定どおりの位置・大きさになった（目盛りラベルの幅が違う場合は未確認だが、枠の位置・大きさは指定値で決まる）。
- MATLAB の vector 書き出しでは、文字の大きさが 96 dpi の整数画素に切り捨てられ、0.75 pt の倍数になる（指定 6/7/7.5/8/8.25/8.5/9/10 pt → 出力 6/6.75/7.5/7.5/8.25/8.25/9/9.75 pt。2026-10-18 に R2025a の Windows で確認）。文字の大きさは 0.75 pt の倍数で指定する（2 節）。Mac（R2025a）での挙動は未確認。下限の文字サイズを守る必要がある図では、書き出した PDF で実寸を確認する。
- 変更後は、データの意図しない切断、軸を共有するパネルの位置対応、ラベルの重なり、および本文・キャプションとの一致を確認する。

## 4. Affinity での取り込みとパネル内の構成

### 4.1 パネル内のレイヤー構成

1 つのパネルの構成（Affinity のレイヤーパネルと同じく、上ほど前面）。図全体の中での位置は figure-assembly-style.md の 1 節。

```
Panel A                          描画環境の図 1 枚分
├── A: annotations               このパネルのグラフに付く注釈（Affinity で追加）
│   ├── peak arrow               矢印
│   ├── scale bar                スケールバー
│   └── significance             有意差記号（ブラケットと *）
├── A: axis labels               軸ラベル、タイトル（取り込み）
├── A: tick labels               目盛りの文字（取り込み）
├── A: axes lines                軸線、目盛り線（取り込み）
├── A: error bars                誤差棒（取り込み）
├── A: bars cond 2               条件 2 の棒（塗りと枠線、取り込み）
└── A: bars cond 1               条件 1 の棒（塗りと枠線、取り込み）
```

Panel レイヤーの中のサブレイヤー（手での微修正で、色・線幅などをまとめて変える単位）：

| サブレイヤー名の例 | 中身 |
|---|---|
| `A: annotations` | このパネルのグラフに付く注釈（Affinity で追加）。サブレイヤーの最前面に置く |
| `A: axes lines` | 軸線と目盛り線 |
| `A: tick labels` | 目盛りの文字（横軸と縦軸） |
| `A: axis labels` | 軸ラベル、タイトル |
| `A: bars cond 1`, `A: bars cond 2`, … | 条件（系列）ごとの棒（塗りと枠線） |
| `A: markers cond 1`, … | 条件ごとの散布図の点 |
| `A: lines cond 1`, … | 条件ごとの折れ線 |
| `A: error bars` | 誤差棒 |
| `A: legend` | 凡例 |

注釈の置き場所の区別：1 つのパネルのグラフ（データや軸）に付くもの（有意差記号、スケールバー、データ点を指す矢印、グラフ内の追加の文字）は、そのパネルの `X: annotations` に置き、パネルと一緒に動くようにする。複数のパネルの関係を示すもの（拡大範囲の補助線など）は、図全体の最上位の Annotations に置く（figure-assembly-style.md の 1 節）。

- レイヤー名は上の英語名で固定する（サブレイヤーは「パネル記号: 成分 条件」の形）。スクリプトはこの名前で対象を探す。
- 写真・模式図など描画環境以外で作るパネルも、`Panel X` のレイヤーに入れる。
- Affinity の SDK にはグループ（GroupNode）を作る機能がないため、まとまりはサブレイヤー（コンテナ）で作る。サブレイヤーを選択して色・線幅を指定すると、中の要素すべてに適用される（28_component_layers.js で確認）。画面上でオブジェクトをクリックしたときは、グループと違ってサブレイヤー全体ではなく個々の要素が選ばれる。まとめて選ぶときはレイヤーパネルでサブレイヤーを選ぶ（画面上の操作は未確認）。

### 4.2 ルール

1. 取り込みは PDF で行う。PDF はグループを作らず平らな構造で開く。SVG は要素ごとにグループが作られる（4.3 節）。
2. Panel レイヤーの中は、成分ごとのサブレイヤーで構成する（5 節）。サブレイヤーの中は取り込んだ構造のまま保ち、要素の削除・統合、グループの解除・作り直しはしない。データ・軸・ラベルの修正は描画環境に戻って行う。例外は、フォントの統一、線幅・文字サイズの下限の修正、サブレイヤー単位の色・線幅の変更など、まとまり全体に一律に適用する修正。
3. 元の図を作り直したときは、Panel レイヤーの中の取り込んだサブレイヤー（axes、bars など）だけを差し替え、`X: annotations` は残す。データ座標で位置が決まる注釈（有意差記号の高さ、矢印の先など）は、値と位置を確認して直す。図全体で残すもの（Labels、最上位の Annotations）は figure-assembly-style.md の 2 節。

### 4.3 SVG を扱う場合

- MATLAB の SVG を Affinity で開くと、要素ごとのグループに 0.75 倍の変形がかかる。グループを残したままなら、見た目の寸法は PDF と同じで、Affinity で線幅・文字サイズを指定しても見た目どおりに設定される（開発時の試行の記録の 8 節、26_svg_adjust_check.js）。
- グループを解除する（中身をグループの外へ移す）と、線幅が 1.00 pt → 1.33 pt に変わった（同 I12。スクリプトでの解除で確認。画面の「グループ解除」での挙動は未確認）。解除した場合は、最後に Affinity で線幅を指定し直す。
- 属性値（線幅 1.33、文字 11 など）と見た目の寸法が一致しないため、画面に表示される数値が見た目と異なる可能性がある（未確認）。寸法の確認は書き出した PDF で行う。
- SVG を Affinity の外（テキストとして、またはスクリプトで）編集してから Affinity で開く場合も、上と同じ扱いになる。最後に Affinity で寸法を指定し直せば、見た目は指定どおりになる。

## 5. MATLAB の図のオブジェクト構成と重複の扱い

MATLAB の PDF を Affinity で開いたときの構成（2026-10-16、R2025a の exportgraphics、27_matlab_object_structure.js で確認）：

- グループはない。MATLAB 上のまとまり（凡例、棒グラフの系列など）は保たれず、線・図形・文字が平らに並ぶ。SVG で開いたときのグループは要素 1 つごとのもので、MATLAB 上のまとまりではない。
- そのため、「一度ばらしてからグループ化し直す」作業は行わない。意味のまとまり（軸、条件ごとの棒・点・線、誤差棒、凡例）は、MATLAB で成分ごとにページを分けて書き出し、Affinity で重ねてサブレイヤーにする。取り込んだ後に色や位置からまとまりを推定する方法は、図の種類ごとに判定を作る必要があり、確実でないため使わない。

成分ごとのページの書き出しと重ね合わせ（開発時の試行の materials/make_component_pages.m、scripts/28_component_layers.js で確認。実装は matlab/exportPanel.m と affinity/compose/compose_single_panels.js）：

1. MATLAB で、表示する成分を切り替えながら 1 つの PDF にページを追記する。データだけのページは、`ax.Visible = 'off'` にすると軸線・目盛り・ラベルが消えてデータが残る。軸は次の 3 ページに分ける（データはすべて `Visible = 'off'`）。
   - 横軸のページ：`ax.XAxis.Visible = 'on'`、`ax.YAxis.Visible = 'off'`、軸ラベル・タイトルの `Visible = 'off'`。横軸の軸線・目盛り線・目盛りの文字が残る。
   - 縦軸のページ：上の横軸と縦軸を入れ替えたもの。
   - 軸ラベルのページ：`ax.Visible = 'off'`、`ax.XAxis.Visible = 'off'`、`ax.YAxis.Visible = 'off'`、軸ラベル・タイトルの `Visible = 'on'`。軸ラベルとタイトルだけが、全体の図と同じ位置に残る。
   - 注意：`ax.XAxis.Visible`・`ax.YAxis.Visible` を一度 `'on'` に明示すると、`ax.Visible = 'off'` でも軸が表示される。そのため、どのページでも `ax`・`XAxis`・`YAxis`・軸ラベル・タイトルの `Visible` をすべて明示する（2026-10-18 に R2025a で確認、matlab/exportPanel.m）。
2. 1 ページ目は全体の図（比較用）にし、成分は 2 ページ目以降に置く。同じ図を続けて書き出すと、1 回目だけページの高さが 0.35 mm 小さくなるため（59.97 mm と 60.32 mm。drawnow では変わらない）。
3. Affinity で開き、各ページの要素を 1 ページ目の Panel レイヤー内のサブレイヤーへ移す。軸は、横軸・縦軸のページの文字以外を `axes lines`、文字を `tick labels` に、軸ラベルのページを `axis labels` に入れる（目盛りの文字と軸ラベルを別に変更できるように。2026-10-18 決定）。全ページで図の大きさと軸の位置が同じなので、移すだけで元の図と同じ配置になる。
4. 比較用の全体図は非表示のレイヤーに残すか削除する。

確認結果：棒グラフ（3 項目 × 2 条件、誤差棒つき）で、重ねた 57 要素がすべて全体の図の要素と対応した（位置の差は最大 0.27 mm で、比較用の 1 ページ目の高さの違いによる）。条件 2 のサブレイヤーの色の変更、軸線のサブレイヤーの線幅の変更（1.5 pt）が、中の要素すべてに適用された。ただし色の変更では、枠線だけのオブジェクトにも塗りが付く（同じ外形の塗りの上なので見た目は変わらない）。

重複・分割されたオブジェクトと扱い：

| 内容 | 例 | 扱い |
|---|---|---|
| 図の背景の白い矩形 | ページとほぼ同じ大きさ | 書き出し時に出さない（`'BackgroundColor', 'none'`） |
| 軸の背景の白い矩形 | 軸の枠の大きさ | 書き出し時に出さない（`ax.Color = 'none'`） |
| 同じ位置の線の重複 | 棒グラフの基準線と横軸 | 書き出し時に出さない（`ShowBaseLine = 'off'`）。他の原因の重複は、見つけた時点で発生源の設定を調べる |
| 塗りと線が別のオブジェクト | 棒の塗りと枠線（同じ外形の 2 つ） | 書き出しの設定では統合できない。統合せずに残し、色や線幅を変えるときは同じ外形の組を一緒に扱う（スクリプトでは外形の一致で組を見つける）。変更は原則 MATLAB で行う |
| マーカーが 1 つずつ別のオブジェクト | 散布図の点 | そのまま残す |

- 背景の矩形があると、ポスターなど色付きの背景の上で白い四角が見え、パネルを重ねると下のものを隠す。白い紙面の論文図では見た目に影響しないが、書き出し時に出さない設定に統一する。
- 重複・分割されたオブジェクトは、残しても書き出した図の見た目は正しい。Affinity 上で削除・統合はしない（4.2 節のルール 2）。発生源の設定で出さないようにできるものは、MATLAB 側で対処する。塗りと枠線に分かれた棒は、同じ成分のページから同じサブレイヤーに入るので、サブレイヤー単位で一緒に扱える。
