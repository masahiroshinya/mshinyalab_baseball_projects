## 1. 前提

- 対象の図：affinity/compose/ のスクリプト（compose_single_panels.js、compose_test_figure.js）で組み立てた図。レイヤー名の規則（最上位の `Panel X`、その中の `X: 成分`。figure-panel-style.md の 4.1 節）でパネルと成分を探す。規則に沿わない図（写真・模式図を含むものなど）は、選択中のオブジェクトを対象にする方法で扱う。
- Affinity での変更は仕上げの微修正である。MATLAB で図を作り直すと、取り込んだサブレイヤーは差し替えられるので、変更は失われる（figure-panel-style.md の 4.2 節のルール 3）。既定として残したい値は、MATLAB の作図スクリプトに戻す（figure-style.md の「MATLAB と Affinity の分担」）。
- 凡例の記号と形による大きさの違い（例：MATLAB の四角は同じ MarkerSize の丸より小さい）は、スクリプトでは揃えない。手直しと個別の依頼で対応する（2026-10-18 決定）。

## 4. どのプロパティにも共通する機能

- 対象の選び方：パネル（A, B …）× 成分（markers、lines、bars …）× 系列（cond 1 …）。ダイアログの欄は、開いているドキュメントのレイヤー名から実行時に作る（パネルの数・図の種類に依存しない）。規則に沿わない図では、選択中のオブジェクトを対象にする。
- 指定のしかた：倍率（%）または絶対値（pt、mm）。大きさは倍率、線幅・文字サイズは絶対値が扱いやすい。
- プレビュー：値を変えるたびに仮に適用し、OK で確定、キャンセルで元に戻す（SDK の examples/makeGrid.js と同じ方法）。確定した変更は 1 回の取り消しで戻せる。
- MATLAB に戻す値の表示：変更後の値を MATLAB のプロパティに換算して表示する（例：MarkerSize 4 × 150 % → 6）。作り直しても残したい場合に、作図スクリプトへ書き写す。
- 動作の確認：処理の部分は AI が MCP 経由で確認し、ダイアログの操作はユーザーが Affinity の画面で確認する（MCP からダイアログは操作できない）。
