# examples：原案の作図スクリプトから論文用の図を作る

このフォルダには、原案の作図スクリプトから論文用の図を作る手順を試すためのファイルを置いている。手順の規則は [../docs/figure-style.md](../docs/figure-style.md) の「原案の作図スクリプトから図を作る」、AI 向けのコマンドは [../AGENTS.md](../AGENTS.md) の 4 節にある。

## 作業の流れ

### 1. MATLAB で図の原案を作る

この toolkit は、図の見た目を整えるためのもの。データを作り変えてはならないので、データを描く部分（`plot`、`fill`、`errorbar` など）は、人が書いて確認したスクリプトから始める。原案の体裁（軸範囲、文字の大きさ、線幅など）は MATLAB の既定のままでよい。

### 2. AI に清書を依頼する

図全体の幅、パネルの並べ方、成果物の保存先を指示して、清書を依頼する。保存先を指示しなければ、AI が作業の前に保存先を尋ねる。そのほかの情報が足りないときも AI が質問するので、そのつど答える。

プロンプト例：

> figure-toolkit/examples/draft_figures.m の figure 1〜4 を、2×2 のパネル（A〜D）に配置した図にしてください。figure-toolkit を使い、論文クオリティーで仕上げること。

AI は、指定した保存先に `<図の名前>/` を作り、作図スクリプト（`make_<図の名前>.m`）と完成図（`output/` の PDF・PNG）を置く。原案のスクリプトとデータは変更しない。

### 3. 図を確認する

作成された図と、図を作った MATLAB のスクリプトを確認する。

- データの部分は原案と同じはずだが、念のため確かめる。AI は報告の前に、原案と新しい図のデータが一致することを確かめ、結果を報告する。
- スクリプトは、パネルごとに「データ」「データを描く」「体裁」「注釈」「書き出し」の段落に分かれている。データの段落には、原案のどの figure・どの行に当たるかが書いてある。
- AI が組み立てた図（.af）は Affinity で開いたままになっているので、この後の修正を画面で見ながら進められる。

### 4. AI との対話で修正する

修正が必要なら、チャットで AI に依頼する。AI は作図スクリプトを直して図を作り直す。

- AI が図を作り直すと、Affinity で開いている同じ図は閉じられ、新しい図に置き換わる。前のバージョンを残したい場合は、別の名前で保存しておくこと。
- フォントやマーカーの大きさ、色などは、5 のスクリプトパネルで変える方が手早い。

プロンプト例：

> figure-toolkit/examples/draft_figures_2x2_revised/ の図（make_draft_figures_2x2_revised.m で作った 2×2 の図。figure-toolkit を使用）を、次のように修正してください。
>
> 1. A の横軸を -200〜50 ms にして、目盛りを 50 ms ごとに
> 2. D の縦軸を 28〜44 m/s、目盛りを 4 ごとに
> 3. 全パネルの目盛り線を内向きに
> 4. 全パネルの軸を四角で囲む

> 続けて、同じ図に次の修正をお願いします。
>
> 1. C の有意差のバーのヒゲ（両端の縦線）をなくして、水平線だけにする
> 2. B の衝撃ピーク（10 % 付近の山）を指す矢印と「Impact peak」の文字を加える
> 3. A の FC から MER までの区間を示す両矢印と「Arm cocking」の文字を加える

> さらに、同じ図に次の修正をお願いします。
>
> 1. 全パネルで、x 軸と y 軸の目盛りの数字を、軸から少し離す
> 2. C の棒に重ねた個人の点の横位置を、ランダムに少しずらす（個人を結ぶ線も点に合わせる）


### 5. Affinity のスクリプトパネルで修正する

フォント、マーカーの大きさ、系列の色、線の太さと線種、有意差記号などのよくある修正は、スクリプトパネルの「Panel style」で一括でできる（使い方は [../README.md](../README.md) の 3 節、調整できる項目は [../docs/adjustable-properties.md](../docs/adjustable-properties.md)）。

### 6. Affinity で手作業で仕上げる

細かい調整を Affinity で行って完成させる。仕上がったら、書き出しを AI に頼める。

プロンプト例：

> 仕上げた図を PDF と PNG で書き出してください。

「PNG で」「PDF で」のような短い依頼でも、AI が推奨の設定（PDF はベクターのまま文字を埋め込む、PNG・TIFF は 600 dpi、RGB）で書き出すので、多くの場合はそれで十分。投稿規程などで解像度や形式の指定があれば、「TIFF の 1200 dpi で」「CMYK で」のように注文を付ける。書き出されるのは Affinity で表示している状態。.af は自動では保存先に保存されないので、AI が「.af も同じフォルダに保存しましょうか」と尋ねる。保存する場合は、案内に沿って Affinity で保存する（AI は図を保存しない）。

5 と 6 の変更は Affinity の中だけにあり、MATLAB で図を作り直すと失われる。そのため、AI に頼む修正（4）を先に済ませてから、5 と 6 を行う。5 に入る前に、図を保存先の `<図の名前>/` に別の名前（例：`<図の名前>_edited.af`）で保存しておく。AI が組み立てた .af（デスクトップの `affinity_mcp_work/panels/`）は、AI が図を作り直すと上書きされる。
