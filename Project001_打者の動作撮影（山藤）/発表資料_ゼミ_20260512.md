# ゼミ発表資料

## 打者のマーカーレスモーションキャプチャーシステム開発

**発表者：山藤　　2026年5月12日**

---

## 1. 内容

バットを振る打者の**体の動きとバットの軌跡**を、カメラ映像だけから自動的に計測するシステムを開発している。

- マーカーレス
- 市販のアクションカメラ2台を使ってグラウンドで撮影
- AI（深層学習）で映像を自動処理

---

## 2. 目的

### 何を測るか

**① 打者の姿勢：体の 17 か所の関節座標（YOLOv8-Pose）**

| 部位   | 測定点                                           | バッティングでの重要度 |
| :----- | :----------------------------------------------- | :--------------------- |
| 顔     | 鼻、左目・右目、左耳・右耳                       | —                     |
| 上半身 | 左肩・右肩、左肘・右肘、**左手首・右手首** | ● 重要                |
| 下半身 | **左腰・右腰、左膝・右膝**、左足首・右足首 | ● 重要                |

> 📌 「バッティング動作に重要な関節：**肩・肘・手首・腰・膝**」（`sandbox/Step02/実装ステップ.md`）

**② 打者の自動特定：手首とバットの距離で判定**（`sandbox/Step04/実装ステップ.md`）

**③ バットの位置：YOLOv8-Detect によるバウンディングボックス検出**

### なぜやるか

- 従来のモーションキャプチャーは**マーカーの装着が必要** → グラウンドでの実計測が困難**（Open Capでは精度不十分）**
- アクションカメラを使えば**フィールドでそのまま計測**できる
- 先行研究（Welch et al., 1995）が示した数値（骨盤714°/s、肩937°/s）を精度検証の基準として使う→研究に耐えうる精度を確保する

### 先行研究

|  年  | 研究            | 主な内容                                                 |
| :--: | :-------------- | :------------------------------------------------------- |
| 1995 | Welch et al.    | 運動連鎖（骨盤→肩→腕→バット）を3Dデータで初めて定量化 |
| 2011 | Inkster et al.  | エリート選手は前肘の角速度が有意に高い                   |
| 2011 | Fortenbaugh     | 球種・コース別の詳細解析                                 |
| 2023 | Orishimo et al. | 下半身のGRFとバットスピードの関係を再定量化              |

## 3. 方法

### 使用機材・実行環境

| 項目                   | 内容                                                                     |
| :--------------------- | :----------------------------------------------------------------------- |
| カメラ                 | DJI OSMO Action 3（2台）                                                 |
| 解像度・フレームレート | 1080p @**240 fps**                                                 |
| 実行環境               | **Google Colab（T4 GPU）**：ブラウザで動くGoogleの無料クラウド環境 |
| ファイル管理           | 動画はその都度アップロード；セッション切断でファイル消失                 |
| UI                     | ipywidgets スライダーでフレーム操作；フォーム機能でパス入力              |

### 使用技術

| 役割                     | 技術                                                         |
| :----------------------- | :----------------------------------------------------------- |
| 姿勢推定（打者）         | **YOLOv8-Pose**（17点キーポイント）                    |
| バット検出               | **YOLOv8-Detect**                                      |
| カメラキャリブレーション | **OpenCV**（cv2.calibrateCamera / stereoCalibrate）    |
| 映像同期                 | **音声クロスコリレーション**（scipy.signal.correlate） |

### カメラ特有の技術課題と対策

| 課題                            | 対策                                                 |
| :------------------------------ | :--------------------------------------------------- |
| レンズ歪み（広角による樽型）    | 四隅までチェスボードを動かして撮影                   |
| 電子手ブレ補正                  | 撮影時は**必ずOFF**（ON にすると3D計算が破綻） |
| 240fps の時間同期               | 音声クロスコリレーション＋手拍子イベント             |
| データ量（10秒 = 2400フレーム） | スイング前後 1〜2秒のみをトリミングして処理          |
