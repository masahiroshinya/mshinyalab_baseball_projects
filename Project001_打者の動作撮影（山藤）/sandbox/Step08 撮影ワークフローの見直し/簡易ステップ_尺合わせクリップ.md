# 簡易ステップ：尺合わせクリップ（LED同期不要版）

## 概要と使用場面

**LED同期を使わず、「短い方の動画の長さに合わせて長い方の動画の先頭を削る」**だけの最もシンプルなクリップ手法です。

### 前提・制約

| 項目 | 内容 |
|:---|:---|
| **適用条件** | 2台のカメラが**ほぼ同じタイミングで録画を終了**している場合 |
| **考え方** | 録画終了タイミングが一致 → 短い動画のフレーム数 = 両動画の共通末尾区間 |
| **削る方向** | 長い動画の**先頭**をカット（末尾は揃っているとみなす） |
| **出力** | フレーム数が同一の動画2本 |
| **LED同期との違い** | フレーム単位の精密な時刻合わせは行わない。目安精度：±数秒程度 |

> **注意：** カメラの停止タイミングがバラバラな場合（片方だけ先に止めた場合など）は誤差が出ます。

---

## 作業ステップ一覧

| ステップ | 内容 | 所要時間 |
|:---|:---|:---|
| A-1 | ライブラリのインポートと動画情報の取得 | 1〜2分 |
| A-2 | フレーム数の確認と削除量の計算 | 1分 |
| A-3 | クリップ・保存の実行 | 5〜15分（動画長に依存） |
| A-4 | 結果の確認 | 2〜3分 |

## 手順 A-1：ライブラリのインポートと動画情報の取得

```python
# ============================================================
# 簡易尺合わせクリップ — A-1: ライブラリと動画情報の取得
# ============================================================
import cv2
import numpy as np
import os

def get_video_info(path):
    """動画ファイルの基本情報を取得する"""
    cap = cv2.VideoCapture(path)
    if not cap.isOpened():
        raise FileNotFoundError(f"動画ファイルを開けません: {path}")
    info = {
        "path": path,
        "fps": cap.get(cv2.CAP_PROP_FPS),
        "width":  int(cap.get(cv2.CAP_PROP_FRAME_WIDTH)),
        "height": int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT)),
        "n_frames": int(cap.get(cv2.CAP_PROP_FRAME_COUNT)),
    }
    info["duration_sec"] = info["n_frames"] / info["fps"] if info["fps"] > 0 else 0
    cap.release()
    return info

# ============================================================
# 動画ファイルのパス入力
# ============================================================
#@title 動画ファイルのパス { display-mode: "form" }
camera1_path = "/content/cam1.MP4"  #@param {type:"string"}
camera2_path = "/content/cam2.MP4"  #@param {type:"string"}

video_paths = [camera1_path, camera2_path]
video_infos = [get_video_info(p) for p in video_paths]

print("=== 動画情報 ===")
for i, info in enumerate(video_infos):
    print(f"  Camera {i+1}: "
          f"FPS={info['fps']:.2f}, "
          f"{info['width']}x{info['height']}, "
          f"{info['n_frames']} frames, "
          f"{info['duration_sec']:.1f} sec")
```

**確認ポイント：**
- 2本の動画がエラーなく読み込まれること
- FPSが両カメラで一致していること（異なる場合は注意）

## 手順 A-2：フレーム数の確認と削除量の計算

```python
# ============================================================
# 簡易尺合わせクリップ — A-2: 削除量の計算
# ============================================================
n_frames_list = [info["n_frames"] for info in video_infos]
fps = video_infos[0]["fps"]

# 短い方のフレーム数 = 共通フレーム数
common_frames = min(n_frames_list)
short_cam_idx  = n_frames_list.index(common_frames)   # 短い方のカメラ番号（0始まり）
long_cam_idx   = 1 - short_cam_idx                    # 長い方のカメラ番号（2台前提）

skip_frames = n_frames_list[long_cam_idx] - common_frames  # 長い方の先頭から削るフレーム数

print("=== 尺合わせ計算結果 ===")
for i, n in enumerate(n_frames_list):
    label = "← 短い（基準）" if i == short_cam_idx else f"← 先頭 {skip_frames} frames を削除"
    print(f"  Camera {i+1}: {n} frames ({n/fps:.1f} sec)  {label}")

print(f"\n  共通フレーム数: {common_frames} frames = {common_frames/fps:.1f} sec")
print(f"  長い動画（Cam{long_cam_idx+1}）の削除量: {skip_frames} frames = {skip_frames/fps:.2f} sec")

if abs(n_frames_list[0] - n_frames_list[1]) / fps > 10:
    print("\n  ⚠ 注意: 2本の動画の長さが 10秒以上 異なります。")
    print("    録画停止タイミングが大きくずれている可能性があります。")
    print("    「末尾が揃っている」という前提が成立しているか確認してください。")
else:
    print("\n  ✅ 長さの差は小さく、末尾合わせとして適切です。")
```

**確認ポイント：**
- `skip_frames`（先頭削除量）が妥当な秒数であること
- 長さの差が 10 秒を大幅に超える場合は本手法の適用に注意

## 手順 A-3：クリップ・保存の実行

```python
# ============================================================
# 簡易尺合わせクリップ — A-3: クリップと保存
# ============================================================
#@title 出力設定 { display-mode: "form" }
output_prefix = "cam"  #@param {type:"string"}

def clip_to_common_length(video_paths, video_infos, common_frames, skip_frames_list,
                           output_prefix="cam"):
    """
    各カメラについて、先頭の skip_frames_list[i] フレームを削除し、
    common_frames フレーム分だけ書き出す。

    Args:
        video_paths        : 動画ファイルパスのリスト
        video_infos        : get_video_info() の結果リスト
        common_frames      : 出力する共通フレーム数
        skip_frames_list   : 各カメラの先頭から削除するフレーム数のリスト
        output_prefix      : 出力ファイル名の接頭辞

    Returns:
        output_paths: 出力ファイルパスのリスト
    """
    fps    = video_infos[0]["fps"]
    width  = video_infos[0]["width"]
    height = video_infos[0]["height"]
    fourcc = cv2.VideoWriter_fourcc(*"mp4v")

    output_paths = []
    for i, (path, skip) in enumerate(zip(video_paths, skip_frames_list)):
        out_path = f"{output_prefix}{i+1}_clipped.mp4"
        output_paths.append(out_path)

        cap = cv2.VideoCapture(path)
        out = cv2.VideoWriter(out_path, fourcc, fps, (width, height))

        # 先頭スキップ
        cap.set(cv2.CAP_PROP_POS_FRAMES, skip)

        print(f"\nCamera {i+1}: 先頭 {skip} frames をスキップして書き込み開始...")
        report_interval = max(1, common_frames // 10)

        for f in range(common_frames):
            ret, frame = cap.read()
            if not ret:
                print(f"  ⚠ Camera {i+1}: フレーム {skip + f} で読み込み失敗。終端に達した可能性があります。")
                break
            out.write(frame)
            if (f + 1) % report_interval == 0:
                pct = (f + 1) / common_frames * 100
                print(f"  Camera {i+1}: {pct:.0f}% ({f+1}/{common_frames})")

        cap.release()
        out.release()
        print(f"  ✅ Camera {i+1}: {out_path} を保存しました ({common_frames} frames)")

    return output_paths

# --- skip_frames_list を組み立て ---
# 短い方: 0 frames スキップ、長い方: skip_frames スキップ
skip_frames_list = [0, 0]
skip_frames_list[long_cam_idx] = skip_frames   # 長い方だけ先頭を削る

print("=== クリップ開始 ===")
for i, sk in enumerate(skip_frames_list):
    print(f"  Camera {i+1}: 先頭 {sk} frames ({sk/fps:.2f} sec) 削除")

output_paths = clip_to_common_length(
    video_paths, video_infos,
    common_frames, skip_frames_list,
    output_prefix=output_prefix
)
```

**確認ポイント：**
- 進捗が 10% ごとに表示され、100% まで到達すること
- エラーメッセージが出ていないこと
- ⏱ 処理時間の目安: 240fps × 53秒 ≈ 12,700フレーム → Colab で約 3〜10 分

## 手順 A-4：結果の確認

```python
# ============================================================
# 簡易尺合わせクリップ — A-4: 結果確認
# ============================================================
import matplotlib.pyplot as plt

print("=== 出力ファイル情報 ===")
for p in output_paths:
    if os.path.exists(p):
        size_mb = os.path.getsize(p) / (1024 * 1024)
        info = get_video_info(p)
        print(f"  {p}: {info['n_frames']} frames, {info['duration_sec']:.1f} sec, {size_mb:.1f} MB")
    else:
        print(f"  ⚠ {p} が見つかりません")

# 先頭フレームと末尾フレームを並べて表示（ずれの目視確認）
print("\n=== 先頭・末尾フレームの目視確認 ===")
positions = {"先頭 (Frame 0)": 0, "末尾 (最終Frame)": common_frames - 1}
fig, axes = plt.subplots(len(positions), len(output_paths),
                          figsize=(7 * len(output_paths), 5 * len(positions)))

for row, (label, frame_no) in enumerate(positions.items()):
    for col, path in enumerate(output_paths):
        cap = cv2.VideoCapture(path)
        cap.set(cv2.CAP_PROP_POS_FRAMES, frame_no)
        ret, frame = cap.read()
        cap.release()
        if ret:
            frame_rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
            axes[row][col].imshow(cv2.resize(frame_rgb, None, fx=0.3, fy=0.3))
        axes[row][col].set_title(f"Cam{col+1} — {label}")
        axes[row][col].axis("off")

plt.suptitle("先頭・末尾フレームの比較\n"
             "同じシーンが映っていれば概ね同期OK（誤差は数秒以内）",
             fontsize=13)
plt.tight_layout()
plt.show()

print("\n次のステップ:")
print("  → ソフト2（キャリブレーション画像取得）に進む場合は")
print("     cam1_clipped.mp4 / cam2_clipped.mp4 を入力として使用してください")
```

**確認ポイント：**
- 2本のファイルのフレーム数が完全に一致していること
- 先頭フレームで両カメラが概ね同じ場面を映していること
- 末尾フレームが揃っていること（末尾合わせが前提なので末尾の一致を優先確認）

## 本手法の限界と次のステップ

| 状況 | 対応 |
|:---|:---|
| 先頭・末尾フレームの場面が数秒ズレている | worklist.md の TODO「LED同期のずれ原因究明」を解決してからソフト1（実装ステップ.md）に差し替える |
| FPSが異なる | 本手法は使用不可。FPSを統一して撮影しなおすか、リサンプリング処理を追加 |
| ズレが許容範囲（チェスボードキャリブや動作解析の目的であれば ±1〜2秒以内） | 本手法のまま継続して問題なし |
