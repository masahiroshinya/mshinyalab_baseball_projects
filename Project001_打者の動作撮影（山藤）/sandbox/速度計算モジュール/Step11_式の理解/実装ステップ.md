# Step11 式の理解

この Step では、速度計算モジュールの中で出てくる式を「何をしているのか説明できる」レベルまで分解する。
先行研究で速度、角度、セグメント、関節中心、バット先端速度が出てきたときに、コードと対応づけて読めるようにする。

## 1. 3次元座標

姿勢推定や三次元復元で得られる1点は、次のように表す。

```text
P = (X, Y, Z)
```

例:

```text
left_wrist = (left_wrist_X, left_wrist_Y, left_wrist_Z)
bat        = (bat_X, bat_Y, bat_Z)
```

ここで大事なのは、1フレームにおける関節やバット位置は「空間上の点」だということ。
速度は、この点が次のフレームでどれだけ動いたかから計算する。

## 2. 三平方の定理と3次元距離

2点 A, B があるとする。

```text
A = (Ax, Ay, Az)
B = (Bx, By, Bz)
```

それぞれの方向の差は次の通り。

```text
dx = Bx - Ax
dy = By - Ay
dz = Bz - Az
```

3次元での距離は、三平方の定理を3方向に拡張したもの。

```text
distance = sqrt(dx^2 + dy^2 + dz^2)
```

Python では、式をそのまま書くと次のようになる。

```python
distance = math.sqrt(dx * dx + dy * dy + dz * dz)
```

NumPy を使う場合は次の1行でも書ける。

```python
distance = np.linalg.norm(point_curr - point_prev)
```

意味:

```text
今の点と前の点の差ベクトルの長さを求めている
```

先行研究で「変位」「displacement」「trajectory length」「3D distance」が出てきたら、この式が基本になる。

## 3. ベクトル

点 A から点 B に向かう矢印をベクトル AB と呼ぶ。

```text
AB = B - A
```

コードではこうなる。

```python
vector_ab = point_b - point_a
```

このベクトルは、次のような場面で使う。

- 関節同士を線でつなぐ
- バットの向きを推定する
- 体幹、肩、骨盤、腕の向きを見る
- 角度を計算する
- 速度の向きを見る

## 4. ジョイント同士をつなぐ線

線を描くという処理は、数学的には「2点を結ぶ」だけ。

例として、左肩と右肩をつなぐ。

```text
left_shoulder  = (Lx, Ly, Lz)
right_shoulder = (Rx, Ry, Rz)
```

3Dプロットでは次のように書く。

```python
ax.plot([Lx, Rx], [Ly, Ry], [Lz, Rz])
```

OpenCVで2D画像上に描く場合はこうなる。

```python
cv2.line(image, (x1, y1), (x2, y2), color, thickness)
```

違い:

- 3D座標では `(X, Y, Z)` を使う
- 画像上では `(x, y)` を使う
- 画像上の y は下向きに増えることが多い

## 5. 打撃で重要な線

打撃動作を見るとき、まず以下の線を理解できると読みやすい。

| 線         | つなぐ点                       | 見たいこと     |
| ---------- | ------------------------------ | -------------- |
| 肩ライン   | left_shoulder - right_shoulder | 体幹上部の向き |
| 骨盤ライン | left_hip - right_hip           | 骨盤の向き     |
| 上腕       | shoulder - elbow               | 腕の振り出し   |
| 前腕       | elbow - wrist                  | 手首への伝達   |
| バット線   | grip - bat / bat_tip           | バットの向き   |

先行研究の kinetic chain は、こうした体の各部位が順番に回転・加速していくことを扱っている。
つまり、関節同士の線や角度は「どこが先に動き、どこへ伝わったか」を見るための材料になる。

## 6. 速度

速度は、移動距離を時間で割ったもの。

```text
speed = distance / time
```

fps が分かっている場合、1フレームの時間は次のように求める。

```text
dt = 1 / fps
```

ただし、フレーム番号が飛ぶ可能性があるので、実装ではこちらを使う方が安全。

```text
dt = (current_frame - previous_frame) / fps
```

例えば 240 fps なら、1フレームは約 0.00417 秒。

```text
1 / 240 = 0.00417 s
```

距離がメートルなら、速度は m/s で出る。

```text
speed_mps = distance_m / dt
```

km/h に直すには 3.6 をかける。

```text
speed_kmph = speed_mps * 3.6
```

## 7. 角度

3点 A, B, C があるとき、B を中心にした角度を出したい場合がある。

例:

```text
肩 - 肘 - 手首
```

このとき、使うベクトルは次の2つ。

```text
BA = A - B
BC = C - B
```

角度は内積から計算できる。

```text
cos(theta) = dot(BA, BC) / (|BA| |BC|)
theta = arccos(cos(theta))
```

Python ではこの形になる。

```python
cos_theta = np.dot(ba, bc) / (np.linalg.norm(ba) * np.linalg.norm(bc))
theta_deg = np.degrees(np.arccos(cos_theta))
```

これは Step12 の速度計にはまだ必須ではない。
ただし、今後「肘角度」「肩角度」「体幹回旋角度」を出すときに必ず使う。

## 8. 研究発表での説明文

発表では、次のように言える。

```text
本研究では、姿勢推定によって得られた関節点やバット位置を3次元座標として扱います。
連続するフレーム間で同じ点の移動距離を三平方の定理に基づいて求め、
その距離をフレーム間の時間で割ることで速度を算出します。
また、関節同士を線で結ぶことで、肩、骨盤、腕、バットの向きを可視化し、
打撃動作における運動連鎖を確認できるようにします。
```

## 9. ここで理解したい最小セット

- 3D座標は `(X, Y, Z)` の点
- 距離は `sqrt(dx^2 + dy^2 + dz^2)`
- `np.linalg.norm()` はベクトルの長さ
- 速度は `距離 / 時間`
- fps から `dt` を作る
- 関節線は2点を結ぶだけ
- 角度は2本のベクトルの内積から出す
