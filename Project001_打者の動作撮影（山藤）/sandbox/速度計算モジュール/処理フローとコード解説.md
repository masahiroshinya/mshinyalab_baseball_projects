# 速度計算の処理フローとコード解説

本ドキュメントでは、2台のカメラを用いた動画から姿勢推定・バット検出を行い、キャリブレーションと三角測量（Triangulation）を経て3次元座標（実空間の座標）を算出し、そこから物体の速度を求める一連の流れを解説します。

合わせて、Pythonの基本的な構文（`for`ループや`if`条件分岐など）が各プロセスでどのように使われているかを細かく解説します。

---

## 全体の処理フロー

1.  **データの準備（読み込みとFPS取得）**
    *   2つのカメラの動画を読み込み、フレームレート（fps）を取得します。
    *   YOLOによる姿勢推定・バット検出を行い、画像上の2次元座標（ピクセル）を取得します。
2.  **3次元座標の復元（三角測量）**
    *   カメラのキャリブレーションパラメータを用いて、2台のカメラの2次元座標から、実世界と同じスケールの3次元座標（X, Y, Z）を計算します。これにより、ピクセルからメートル等の実際の長さに変換されます。
3.  **速度の計算（フレーム間の差分）**
    *   フレーム $t$ と フレーム $t-1$ の3次元座標の距離を求め、経過時間（1フレームあたりの時間）で割ることで速度を計算します。
4.  **平滑化（スムージング）と可視化**
    *   検出のブレによるノイズを取り除くため、移動平均などを用いて速度データを滑らかにし、グラフや動画に描画します。

---

## コード実装の流れとPython基礎解説

ここでは、上記のフローをプログラムでどのように書くか、基本的なコードを用いて解説します。
※実際の細かいOpenCVの三角測量関数等は簡略化し、Pythonの論理構造を学ぶことに焦点を当てています。

### フェーズ1: データの準備とFPSの計算

```python
import numpy as np

# 動画のフレームレート (動画インポート時に取得する想定)
# 例: 270fps で撮影された場合
fps = 270

# 1フレームあたりの時間（秒）を計算します。
# 1秒間に270コマあるなら、1コマにかかる時間は 1 / 270 秒です。
time_per_frame = 1.0 / fps

# 架空の3次元座標データ（メートル単位）のリスト
# [X座標, Y座標, Z座標] のリストがフレームごとに格納されているとします。
# フェーズ2（三角測量）が終わった後のデータという想定です。
# None は「そのフレームではバットが検出できなかった」ことを意味します。
points_3d = [
    [0.0, 1.0, 0.0],   # 0フレーム目
    [0.1, 1.0, 0.1],   # 1フレーム目
    [0.2, 1.05, 0.2],  # 2フレーム目
    None,              # 3フレーム目 (検出失敗!)
    [0.4, 1.1, 0.4],   # 4フレーム目
    [0.5, 1.1, 0.5]    # 5フレーム目
]
```

### フェーズ2 & 3: 速度の計算（`for` と `if` の使い方）

ここからが速度計算のメインロジックです。配列の最初から最後まで順番に見ていくために `for` ループを使い、データが存在するかどうかを `if` で判定します。

```python
# 速度を保存するための空のリストを作成します
velocities = []

# 【forループの解説】
# range(1, len(points_3d)) は、「1からデータの総数(この場合は6)-1まで順番に数字を出す」という意味です。
# i には 1, 2, 3, 4, 5 が順番に入りながら、下の字下げされたブロックが繰り返し実行されます。
# i=0(最初のフレーム)は、比較する「前のフレーム」がないので 1 から始めます。
for i in range(1, len(points_3d)):
    
    current_point = points_3d[i]      # 今のフレームの座標 (例: i=1なら [0.1, 1.0, 0.1])
    previous_point = points_3d[i-1]   # 1つ前のフレームの座標 (例: i=1なら [0.0, 1.0, 0.0])

    # 【if条件分岐の解説】
    # 「現在の座標が存在する」かつ「前の座標も存在する」場合のみ計算をしたいです。
    # is not None は「空っぽ(None)ではない」という意味です。
    # and は「かつ」です。
    if current_point is not None and previous_point is not None:
        
        # 座標を計算しやすいようにnumpy配列に変換します
        p_curr = np.array(current_point)
        p_prev = np.array(previous_point)
        
        # 3次元の距離を計算します（三平方の定理の3D版）
        # np.linalg.norm は、ベクトル(p_curr - p_prev)の長さを一発で計算してくれる便利な関数です。
        # 単位はメートルです。
        distance = np.linalg.norm(p_curr - p_prev)
        
        # 速度（秒速: m/s）の計算
        # 速度 = 距離 / 時間
        velocity_mps = distance / time_per_frame
        
        # 秒速(m/s)を時速(km/h)に変換するには、3.6を掛けます。
        # (3600秒 / 1000メートル = 3.6)
        velocity_kmph = velocity_mps * 3.6
        
        # 計算した速度をリストに追加(append)します。
        velocities.append(velocity_kmph)
        
    else:
        # 【elseの解説】
        # ifの条件が満たされなかった場合（どちらかがNoneで検出失敗していた場合）の処理です。
        # 速度が計算できないので、とりあえず None (空) を追加しておきます。
        velocities.append(None)

# 結果の確認
print("各フレームの速度 (km/h):", velocities)
```

### 処理のポイントのまとめ

*   **`for`**: 膨大なフレーム数の動画データを、1コマずつ順番に処理するためのベルトコンベアのような役割です。
*   **`if`**: YOLOの検出は完璧ではないため、必ず「検出できなかったコマ（`None`や空の配列）」が存在します。これらを無理に計算しようとするとプログラムがエラーで止まってしまうため、「データがある場合だけ計算する」という安全装置として働きます。
*   **スケールの問題**: 2台のカメラを使った三角測量によって3次元座標（実寸ベース）を出力できるため、このコードのように単純に「距離 ÷ フレーム間の時間」とするだけで、現実の物理的な速度が求まります。
