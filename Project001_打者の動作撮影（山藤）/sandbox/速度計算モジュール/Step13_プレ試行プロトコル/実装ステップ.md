# Step13 プレ試行プロトコル

次の発表までの軸を、実装と研究作業に接続する。

## 1. 次回までの3本柱

| 軸 | やること | 成果物 |
|---|---|---|
| 背景を補強する先行研究を増やす | マーカー式、マーカレス、打撃動作分析の研究を追加で読む | `research_comp` の先行研究ノート |
| 最新の動作解析を追いかける | 現場利用されるマーカレス、スマホ・単眼・複数カメラ解析を調べる | 発表スライド用の比較表 |
| 自分の研究のプレ試行を行う | 自分の撮影環境で3D座標と速度を出す | サンプル動画、3D座標CSV、速度CSV、簡単なグラフ |

## 2. プレ試行の目的

プレ試行では、いきなり完璧な解析を目指さない。
まず次の4つを確認する。

- 打者の関節点を安定して検出できるか
- バット位置をある程度追えるか
- 3D座標として出力できるか
- 速度計でバット、手首、肩の速度を計算できるか

この4つが通れば、先行研究で行われている「動作を測り、速度や角度として評価する」という流れに近づける。

## 3. 撮影条件

最初のプレ試行では、条件を増やしすぎない。

| 項目 | 推奨 |
|---|---|
| カメラ数 | 2台 |
| fps | 120 fps 以上。可能なら 240 fps |
| 試技 | 素振り、ティー打撃 |
| 本数 | 3から5本 |
| カメラ位置 | 正面斜め、側面斜め |
| キャリブレーション | ChArUco board または既知寸法の物体 |
| 記録 | 撮影条件、距離、高さ、fps、解像度をメモ |

## 4. 処理フロー

```text
撮影
  ↓
動画同期
  ↓
Step09: 姿勢推定・バット検出・3D座標CSV出力
  ↓
Step12: 速度計プロトタイプで速度CSV出力
  ↓
速度グラフ作成
  ↓
先行研究の指標と比較する
```

## 5. Step12の実行例

```powershell
python velocity_meter.py `
  --input batting_3d_tracking.csv `
  --fps 240 `
  --output batting_3d_tracking_with_speed.csv `
  --make-bat-tip `
  --smooth-window 5
```

まず見る列:

```text
bat_speed_kmph
bat_tip_speed_kmph
left_wrist_speed_kmph
right_wrist_speed_kmph
left_shoulder_speed_kmph
right_shoulder_speed_kmph
```

## 6. グラフにするもの

最初は折れ線グラフでよい。

| グラフ | 意味 |
|---|---|
| frame_number - bat_tip_speed_kmph | スイング中のバット先端速度の変化 |
| frame_number - left_wrist_speed_kmph | 手の加速 |
| frame_number - right_wrist_speed_kmph | 手の加速 |
| frame_number - shoulder speed | 体幹上部の動き |

見たいこと:

- バット速度がどのタイミングで最大になるか
- 手首速度とバット速度のピークが近いか
- 座標の飛びによる異常値がないか
- ノイズなのか、本当に速く動いたのかを動画と照合できるか

## 7. 先行研究に近づけるために必要な追加

次に足すべき解析は以下。

| 追加項目 | 使う式 | 目的 |
|---|---|---|
| 肘角度 | 内積と arccos | 腕の使い方 |
| 肩ライン角度 | atan2 またはベクトル角度 | 体幹上部の回旋 |
| 骨盤ライン角度 | atan2 またはベクトル角度 | 骨盤の回旋 |
| 肩と骨盤の角度差 | 角度差 | 体幹のひねり |
| バット角度 | グリップとバット先端のベクトル | バット軌道 |

## 8. 発表での説明文

```text
次回までに、背景を補強する先行研究の追加、最新のマーカレス動作解析の調査、
そして自分の撮影環境でのプレ試行を進めます。
実装面では、姿勢推定で得られた3次元座標から、関節点やバットの移動距離を求め、
フレーム間時間で割ることで速度を算出する速度計を作成します。
これにより、先行研究で扱われているバット速度や手首速度などの指標を、
自分のデータから再現できるかを検証します。
```
