# 04_presentations

発表資料を、発表日・発表単位で管理する場所。

## 構成

- `2026-05_seminar/`: 5月ゼミ発表資料
- `2026-07-08_progress/`: 2026-07-08時点の進捗発表資料

## 発表フォルダ内のルール

- `draft_ai/`: AI作成の下書き、生成pptx、Markdown原稿
- `final_human/`: 人間が確認・編集した完成版
- `tools/`: PowerPoint生成など、その発表資料専用の補助スクリプト

AI作成物を完成版にする場合は、`final_human/` にコピーしてから人間が確認・編集する。
