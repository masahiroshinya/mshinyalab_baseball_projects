### 8. HT の中で 2 度目の RT を消化しているという考え方

**指示・質問：**
Go／Stop条件では、Onsetから2度目の刺激まで判断のための空白の時間が110msほどあり、その後改めて2度目の刺激が来たら他条件と同じ程度のRTをかけて振り出す？でもその理論でいくと、RTの中にHTが含まれてしまうよね。てことは、2度目の刺激でもう一度降り出してるというよりは、HTをできるだけ短縮したような状態で2度目のRTを消化しているようなイメージ説？

**AIの対応：**
- 「振り直し」ではないという点に同意した。振り直しなら、2 回目の刺激のあとに RT（239）＋ HT（273）＝ 約 510 ms かかるはずだが、実際は 242 ms で LT に入っている。HT は 2 回目の刺激の処理と並行して進み、処理が終わると LT に入る（重ねている）

### 24. 2 回目の刺激が HT の中に来ることと、RT の延長の関係

**指示・質問：**
HookTime中に2度目の刺激を迎えていることについてですが、この結果はRTの延長とも生合成があると考えられますよね？

**AIの対応：**
- x8 の SubjectTable で条件ごとの平均を確認した（10 名）
  - RT：Free 324・Simple 202・Go/No-go 217・Go/Stop 239 ms。Go/Stop − Simple +38 ms（p < .001）、Go/Stop − Go/No-go +23 ms（p = .041）、Go/No-go − Simple +15 ms（p = .035）
  - HT：Simple 273・Go/No-go 308・Go/Stop 353 ms
- 説明：整合する。ただし RT の延長だけでは 2 回目の刺激に届かない
  - RT が 38 ms 延びても、振り始めは 239 ms で、2 回目の刺激（350 ms）の 111 ms 前。動く前に刺激を見てから判断するには、振り始めを約 590 ms まで遅らせる必要があり、スイングに間に合わない
  - Go cue からの HT の終わりは Simple 475 ms → Go/Stop 592 ms で 117 ms 遅い。内訳は RT +38 ms（約 1/3）と HT +80 ms（約 2/3）。「少し遅く動き出して、フックを引き延ばす」の 2 つで時間をかせいでいると読める
  - Go/No-go より RT が 23 ms 長い分は、2 回目の刺激（止まるかもしれない）への備えの可能性がある。止まる可能性があると Go の RT が延びる「proactive slowing」は stop-signal 課題で知られているとされている（文献は References の検索結果で確認する）
  - 注意：試行ごとには、RT が長い試行で HT が短くなるわけではない（傾き ≈ 0、やり取り 21）。RT と HT は、その場で互いに調整されているのではなく、条件ごとに前もって両方が長くなっていると考えられる

### 25. プロアクティブかリアクティブか

**指示・質問：**

### 26. 文献 [2]（Pickavance et al., 2022）はプロアクティブとリアクティブの両方に触れているか

**指示・質問：**
（`Manuscript/References/文献検索_GoStop条件と動作の時間的特性/GoStop条件と動作の時間的特性_文献検索結果.md` を示して）この2の文献では、プロアクティブな判断様式とリアクティブな判断様式がどちらも用いられている可能性について言及されていますよね

**AIの対応：**
- 文献検索結果の [2] と、bioRxiv の全文（https://www.biorxiv.org/content/10.1101/2022.06.01.494317v1.full）の抄録・序論・考察を確認した
- 説明：少し違う
  - 抄録の冒頭と序論では、抑制の 2 つのしかたとして reactive（停止信号に反応して動作を差し控える）と proactive（停止信号を予期して動作の計画を変える）を**定義として**挙げている。序論では「reactive は自動的、proactive は意図的・戦略的」とされている
  - 結果として「両方が使われている」と言っているのは、**proactive inhibition の中身**のこと。「proactive inhibition は response suppression（反応の抑制）と delayed facilitation（促進を遅らせる＝"waiting" strategy）の両方からなる」（抄録）。開始の遅れはこの 2 つの組み合わせで起きている、とも考察している
  - 比べたのは Certain と Uncertain の Go 試行どうしで、Stop 試行での reactive な停止は分析の中心ではない
- 本研究への使い方の案：定義（reactive / proactive）は、やり取り 25 の「時間の組み立てはプロアクティブ、進むか止まるかはリアクティブ」の説明に使える。「waiting strategy」は本研究の「RT と HT を前もって延ばす」と対応づけられる。ただし [2] は MT が短くなり、本研究は HT が長くなる点が違う
- 考察は全体の約 85% までしか読めていない（ページが長く、残りは未確認）
