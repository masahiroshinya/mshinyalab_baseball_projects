### 4. ガウス関数の1行の解説

**指示・質問：**
vel     = peakVel * exp( -(t - tPeak).^2 / (2*0.08^2) ) ;

この１行に説明を加えてください。

**AIの対応：**
ガウス関数 $A \exp(-(t-\mu)^2/2\sigma^2)$ として分解し、`peakVel`＝山の高さ、`tPeak`＝山の中心、`0.08`＝山の幅（σ）であることを説明した。指数の中身が $t=\mu$ で 0（`exp(0)=1`）、離れるほど負に大きくなって 0 に急減するため山型になる、という順で示し、ピークからの隔たりごとの数値表（1σ で 3.03 m/s、2σ で 0.68 m/s など）を付けた。

さらに、`.^` が要素ごとの2乗である理由（`t` は `[750×1]` なのでドットなしだと行列のべき乗になる）と、**`tOnset = tPeak - 0.20` とノイズ `0.02*randn` の組み合わせが「動作開始時点の速度 0.22 m/s ≒ ベースライン 10 SD（0.2 m/s）」となるよう仕込んである**ことを示した。実データの `Prm.RT.FzK = 10` と同じ基準で検出すれば正解 0.45 s 付近が得られる設計である。

**決定事項・結果：**
- `0.08` を `0.15` に変えると立ち上がりが緩やかになり、閾値を横切る時刻が早まって RT が短く出る。段階3 でこれを操作し、実データの「RT が極端に短い試行」の原因を体感する、という学習の筋道を立てた。

### 5. 段階2 の実装案

**指示・質問：**
4-1の段階２に進みます

**AIの対応：**
`d2_plot_basic.m` の実装案を提示した。

1. 疑似データの生成（`d1` と同じ）
2. キュー基準の時間軸 `tRel = t - tCue`
3. ベースライン区間（`tRel >= -0.5 & tRel < 0`）の平均・SD から閾値 `thr = baseMean + 10*baseSD` を算出
4. `plot` → `set(ax,'XLim',...)` → `xline`/`yline` の順で描画

確認事項として、(1) キュー線が x = 0 に立つこと、(2) `XLim` を変えても線が端まで伸びること、(3) 閾値線と波形の交点が真の onset（0.45 s）とほぼ一致すること、の3点を挙げた。

**★ 軸範囲を先に確定させる理由**：実データで使う `lineplot.m` は `xline` と異なり、呼ばれた時点の `XLim`/`YLim` を読んでその範囲ぶんの線分を `plot` で描く実装（`lineplot.m` 38〜39行目）。後から軸範囲を広げると線が途中で切れる。したがって「波形 → 軸範囲の設定 → 縦線・横線」の順序を守る必要がある。合成データの段階からこの順序に慣れるため、`xline` を使う場合でも `set` を先に置いた。

**決定事項・結果：**
- 新出命令（論理インデックス、`&`、`std`、`fprintf`、`xline`/`yline`）を用語表に追加することにした。
