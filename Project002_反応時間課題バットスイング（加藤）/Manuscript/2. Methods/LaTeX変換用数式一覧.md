## 1. ディスプレイ数式（独立した式として表示）

### 1-1. 手部速度（体幹の並進成分の除去）― 2-4-1 反応時間

手部セグメントの投手–捕手方向速度から、腰部セグメントの同方向速度を減じる。

```
v(t) = v_{\mathrm{hand},x}(t) - v_{\mathrm{pelvis},x}(t)
```

### 1-2. 動作開始時刻（閾値超過の最初の時点）― 2-4-1 反応時間

閾値は参加者ごとの平均ピーク速度の 10 %（Nasu et al., 2020 準拠）。

```
t_{\mathrm{onset}} = \min\{\, t \mid v(t) > 0.10\,\overline{v_{\mathrm{peak}}} \,\}
```

> **Word での注意**：`\min\{\,` と `\,\}` の `\,` は細い空白の指定。Word の LaTeX 入力で崩れる場合は
> `\min\{ t \mid v(t) > 0.10 \overline{v_{peak}} \}` と簡略化してよい。
> また `\mid`（条件を区切る縦棒）が細く表示される場合は `:` に置き換える書き方もある。

### 1-3. 中心差分（速度ベクトルの算出）― 2-4-2 スイングスピード

```
\mathbf{v}(t_i) = \frac{\mathbf{p}(t_{i+1}) - \mathbf{p}(t_{i-1})}{2\,\Delta t}
```

### 1-4. 合成速度（速度ベクトルのノルム）― 2-4-2 スイングスピード

```
|\mathbf{v}(t)| = \sqrt{v_x(t)^2 + v_y(t)^2 + v_z(t)^2}
```
