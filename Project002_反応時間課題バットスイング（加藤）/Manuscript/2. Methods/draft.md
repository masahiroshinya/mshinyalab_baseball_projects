### 文章

　本実験では、光学式モーションキャプチャシステム、フォースプレート、およびLED刺激呈示装置を使用した。

　身体およびバットに貼付した反射マーカーの三次元位置座標の計測には、光学式モーションキャプチャシステムQualisys（Qualisys社）を用い、サンプリング周波数は250 Hzとした。座標系は、X軸を投手–捕手方向（正が投手方向）、Y軸を左右方向、Z軸を鉛直方向と定義した。

　打撃動作には900 gの木製バット（SO Sports社製）を用い、計5個の反射マーカーを貼付した。バット先端の上面をtop、グリップエンドの底面をbottomとし、その間には、長軸に沿ってtop側からbarrel、knob、gripの順に並ぶよう、残る3個を配置した。身体には計7個の反射マーカーを貼付し、捕手側の手背に貼付した3個で手部セグメントを、左右の上前腸骨棘（ASIS）および後上腸骨棘（PSIS）に貼付した4個で腰部セグメントを構成した。

　床反力の計測には、フォースプレート（Bertec社製）2枚を用い、サンプリング周波数は1000 Hzとした。2枚のうち、後ろ足側に位置するものをForce1、前足（踏み込み足）側に位置するものをForce2とした。

　視覚刺激の呈示には、自作のLED基板およびNational Instruments社製DAQボードから構成されるLED刺激呈示装置を用いた。呈示可能な白色・緑色・赤色の3色のうち、白色をReady cue、緑色をGo cueとして用い、赤色はGo/No-Go課題ではNo-Go cue、Go/Stop課題ではStop cueとして用いた。

## 2-3. 課題構成

### 構成　条件・試行数確定（`技術説明.md` 2026-08-08版準拠） ／ 【要確認】所要時間は再見積もり中 ／ 【要確認】ランダムデザイン追加実施は検討中

**実験条件（4条件）**

| 条件             | 内容                                                                                                         | 認知的負荷 |
| :--------------- | :----------------------------------------------------------------------------------------------------------- | :--------- |
| 自由スイング条件 | Ready cue（白色LED）点灯後、任意のタイミングで全力スイング                                                   | なし       |
| 単純反応課題     | Ready cue（白色LED）点灯後、Go cue（緑色LED）でできるだけ素早く全力スイング                                  | 低         |
| Go/No-Go課題     | Go cue（緑色LED）→全力スイング／No-Go cue（赤色LED）→スイングをできる限り実行しない                        | 高         |
| Go/Stop課題      | 1回目のGo cue（緑色LED）でスイング開始→0.25秒後の2回目の刺激がGoなら継続、Stop cue（赤色LED）なら途中で中止 | 最高       |

> No-Go 試行の教示は「できる限り実行しない」という**抑制の努力を求める**形とし、「スイングせず構えを保持する」のような**完全な抑制を前提とする**書き方はしない（2026-08-14 決定）。理由：実際には動作が部分的に開始される試行が生じうるためであり、Go/Stop課題の「途中で中止する」との連続性も保たれる。

**デザイン・カウンターバランス**

- 全参加者が4条件すべてを実施する**参加者内反復測定デザイン**。
- 条件の実施順序は、**ラテン方格法（Williams design、4×4）**により参加者間でカウンターバランスをとる。

> 本文では、順序をカウンターバランスした事実のみを記述し、手法名（ラテン方格法・Williams design）には触れない（2026-08-14 決定）。理由：統制した事実が示されていれば妥当性の担保としては足りるため。実施に用いる手法自体は本表のとおり変更しない。査読等で順序の割り付け方法を問われた場合は、本文に手法名を戻す。

**試行数**

| 項目                       | 値                      |
| :------------------------- | :---------------------- |
| 条件数                     | 4条件                   |
| 各条件の試行数             | 15試行                  |
| 総試行数                   | 60試行（4条件×15試行） |
| Go/No-Go課題のGo:No-Go比率 | 10:5                    |
| Go/Stop課題のGo:Stop比率   | 10:5                    |

> 各条件15試行のうち3試行は練習を兼ねるが、**解析対象に含める**ことを 2026-08-15 に決定した。したがって本文では練習・本試行を区別せず15試行として扱う（2-5 統計処理も同じ扱い）。

**Foreperiod（刺激呈示までの予告時間）**

| 条件                                                | Foreperiod           |
| :-------------------------------------------------- | :------------------- |
| 自由スイング条件                                    | 1.5秒固定            |
| 単純反応課題・Go/No-Go課題・Go/Stop課題             | 1.2〜1.8秒のランダム |
| Go/Stop課題：1回目Go cueから2回目刺激呈示までの間隔 | 0.25秒固定           |

> 1.2〜1.8秒のForeperiodの範囲は、大学・社会人レベルの投手の投球動作時間を模擬して設定したもの。
>
> 出典：`Experiments/Main experiments/倫理書類/研究の詳細.docx`（pdf同一）§3.5「刺激呈示のタイミング」／`Experiments/Main experiments/Protocol/技術説明.md` §3〜§5.3、§6（`go_to_branch_off_duration` = 0.25秒、2026-08-08版）

**要確認**

- [ ] 実験全体・実験本体の所要時間（`技術説明.md` §4.1・§4.3 参照、要見直し）
- [ ] ランダムデザイン（条件混在）の追加実施：実施タイミング・順序・練習試行等の詳細設計は未確定（`技術説明.md` §8 参照）

### 文章

　本研究では、認知的負荷の程度が異なる自由スイング条件、単純反応課題、Go/No-Go課題、およびGo/Stop課題の4条件を設定した。自由スイング条件では、Ready cueの点灯後、任意のタイミングで全力スイングを行うよう教示した。単純反応課題では、Ready cueに続いて呈示されるGo cueに対して、できるだけ素早く全力スイングを行うことを求めた。Go/No-Go課題では、Go cueに対しては同様に全力スイングを行い、No-Go cueに対してはスイング動作をできる限り実行しないよう教示した。Go/Stop課題では、1回目のGo cueでスイングを開始させたうえで、続いて呈示される2回目の刺激がGo cueであればスイングをそのまま継続し、Stop cueであればスイングを途中で中止することを求めた。

　これら4条件は全参加者が実施する参加者内反復測定デザインとし、条件の実施順序は参加者間でカウンターバランスをとった。試行数は1条件あたり15試行、4条件で計60試行であり、このうちGo/No-Go課題およびGo/Stop課題では、Go試行とNo-Go試行（Stop試行）との比率をいずれも10:5とした。刺激呈示までの時間（Foreperiod）は、自由スイング条件では1.5秒に固定し、残る3条件では、大学・社会人レベルの投手の投球動作時間を模擬して1.2〜1.8秒の範囲でランダムに変化させた。また、Go/Stop課題において1回目のGo cueから2回目の刺激が呈示されるまでの間隔は、0.25秒に固定した。

### ［2-4-1］反応時間の算出（Nasu et al., 2020 準拠）

| 要素           | 本研究                                                                                   | Nasu et al. (2020)                                    |

| 速度の方向     | 投手–捕手方向（X 軸）の1次元                                                            | 投手–捕手方向の1次元                                 |
| 体幹補正       | 腰部セグメント（ASIS・PSIS）の同方向速度を減算                                           | 骨盤セグメント速度を減算                              |
| 閾値           | 参加者ごとの平均ピーク速度の**10 %**                                               | 平均ピーク速度の10 %（0.61 ± 0.09 m/s）              |

### ［2-4-2］スイングスピードの算出フロー

```
定義：バット先端（top）の並進速度
  │
  ├─ 前処理 (1) 欠損値の線形補間 → (2) ローパス 30 Hz → (3) mm→m（微分の前）
  │
  ├─ (4) 中心差分（3点差分法）→ 速度ベクトル v(t)
  │
  └─ 従属変数 (5) 合成速度 |v|（ノルム）／ (6) 投手方向速度 v_x（X成分）
```

**前処理**（すべて微分の前に実施）

|     手順     | 内容                                                                                 |
| :----------: | :----------------------------------------------------------------------------------- |
| (1) 欠損補間 | 線形補間（`interp1`, `'linear'`・`'extrap'`）                                  |
| (2) フィルタ | 2 次 Butterworth ローパス**30 Hz**、`filtfilt` 双方向（ゼロ位相・実効 4 次） |
| (3) 単位変換 | mm → m（以降すべて m/s）                                                            |

- **30 Hz の根拠**：感度分析（5〜50 Hz）で 30 Hz 以上はピーク変化 < 0.04 m/s（約 0.15 %）のプラトー。全被験者・全条件で共通。

**速度算出**　中心差分（3 点差分法・`diff3p`）。前進差分より打ち切り誤差が 1 桁小さく、時間遅れが無い。端点は片側 3 点式。出典＝バイオメカニクス 20 講 p.166。

**従属変数**

| 指標               | 定義                             | 位置づけ           |
| :----------------- | :------------------------------- | :----------------- |
| ピーク合成速度     | max\|v\|（速度ベクトルのノルム） | 主要指標【要確認】 |
| ピーク投手方向速度 | max v_x（X 成分・符号あり）      | 副次指標           |

> 定義は 1 つ（先端の並進速度）、そこから値を 2 つ導出。

> 座標系の定義は 2-2 実験機器を参照（X 軸正方向＝投手方向）。ピーク時の v_x は合成速度の約 90 %（0.90〜0.93、内部メモ）。

### 文章

　本研究では、反応時間、スイングスピード、および床反力を分析の対象とした。このうちスイングスピードおよび床反力については、Go/No-Go課題のNo-Go試行およびGo/Stop課題のStop試行は、スイングを抑制すること自体が課題であるため集計の対象から除外し、両課題ともにGo試行10試行を分析に用いた。

#### 2-4-1. 反応時間

　反応時間は、Go cueの点灯から動作開始までの時間と定義した。動作開始の検出はNasu et al. (2020) の手法を参考とした。

　手部セグメントおよび腰部セグメントの位置は、それぞれを構成するマーカーの重心として定義した。これらの位置座標には、計測欠損の線形補間と、遮断周波数30 Hzの2次のButterworth型ローパスフィルタの双方向適用を施したうえで、中心差分により速度を算出した。

　動作開始の判定には、投手–捕手方向（X軸）の速度成分を用いた。手部セグメントの速度には体幹の並進運動が含まれるため、次式のとおり、腰部セグメントの同方向の速度を減じた値を手部速度 v(t) とした。

$$
v(t) = v_{\mathrm{hand},x}(t) - v_{\mathrm{pelvis},x}(t)
$$

　動作開始は、この手部速度が閾値を超えた最初の時点とした。閾値には、参加者ごとに全試行の手部速度のピーク値を平均し、その10%にあたる値を用いた。

$$
t_{\mathrm{onset}} = \min\{\, t \mid v(t) > 0.10\,\overline{v_{\mathrm{peak}}} \,\}
$$

　反応時間は、この動作開始時刻とGo cueの点灯時刻との差として算出した。動作開始時刻はマーカー座標（250 Hz）から、Go cueの点灯時刻はアナログ信号（1000 Hz）から得られるため、両者を同一の時間軸上に換算したうえで差を求めた。なお、自由スイング条件はGo cueを呈示しないため、反応時間を算出したのは単純反応課題、Go/No-Go課題、およびGo/Stop課題の3条件である。

#### 2-4-2. スイングスピード

　スイングスピードは、バット先端に貼付したtopマーカーの並進速度と定義し、以下の手順で算出した。

　位置座標の数値微分は高周波ノイズを増幅するため、微分に先立って前処理を行った。まず、計測欠損を線形補間により補完し、続いて、遮断周波数30 Hzの2次のButterworth型ローパスフィルタを順方向・逆方向の双方向に適用することで、位相のずれを伴わない平滑化を行った。

　前処理を施した位置座標から、次式に示す中心差分（3点差分法）により速度ベクトルを算出した。ここで、先端マーカーの位置ベクトルを **p**(t) = (x(t), y(t), z(t))（単位 m）、速度ベクトルを **v**(t)、サンプリング間隔を Δt（＝1/250 s、250 Hz）とする。

$$
\mathbf{v}(t_i) = \frac{\mathbf{p}(t_{i+1}) - \mathbf{p}(t_{i-1})}{2\,\Delta t}
$$

なお、系列の両端については、片側3点の差分式を用いて処理した。

　算出した速度ベクトルからは、2つの従属変数を取り出した。第1は、次式に示す速度ベクトルのノルム（速さ）のピーク値であるピーク合成速度であり、これは野球の現場で一般に「スイングスピード」と呼ばれる指標に対応する。

$$
|\mathbf{v}(t)| = \sqrt{v_x(t)^2 + v_y(t)^2 + v_z(t)^2}
$$

第2は、速度ベクトルのX成分 v_x(t) のピーク値であるピーク投手方向速度であり、X成分は正が投手方向、負が捕手方向を表す（座標系は2-2 実験機器を参照）。いずれの指標も、各試行内における最大値として算出した。

#### 2-4-3. 床反力

　床反力は、後ろ足および前足（踏み込み足）の下に設置した2枚のフォースプレートによって計測し、その鉛直成分のピーク値を指標とした。

　ピーク値の抽出に先立ち、遮断周波数30 Hzの2次のButterworth型ローパスフィルタを順方向・逆方向の双方向に適用した。

　ピーク値の探索範囲は、Orishimoらの手法にならい、踏み込み足の接地からスイングスピードがピークに達する時点までとした。踏み込み足の接地は、同研究の定義に従い、踏み込み足が離地した後に前足側のフォースプレートの鉛直成分が10 Nを超えた最初の時点とした。なお、同研究は区間の終点をボールコンタクトとしているが、本研究は素振りを対象とするため、これに代えてスイングスピードのピーク時点を用いた。

　ピーク床反力は、この区間における鉛直成分の最大値として後ろ足と前足のそれぞれについて算出した。得られた値は参加者間の体格差の影響を除くため、実験当日に測定した体重に対するパーセンテージ（%BW）として表した。

**手続き**

| 段階         | 内容                                                                                                  |
| :----------- | :---------------------------------------------------------------------------------------------------- |
| (1) 代表値   | 参加者ごと・条件ごとに、**対象試行すべて**の平均値を1つの代表値とする（練習を兼ねる3試行も含める）     |

### 文章

　統計処理では、参加者ごとに、各条件の対象試行すべての平均値を求め、これを代表値とした。

　各従属変数について、条件を要因とする一元配置の反復測定分散分析を行った。これに先立ち、Shapiro-Wilk検定により代表値の正規性を確認した。球面性の仮定はMauchlyの検定により確認し、仮定が満たされない場合にはGreenhouse-Geisser法によって自由度を補正した。条件の主効果が認められた場合には、事後検定としてBonferroni補正を施した対応のあるt検定による対比較を行った。効果量は、分散分析については偏イータ二乗を、対比較についてはCohen's dを算出した。

　正規性が満たされなかった従属変数については、反復測定分散分析に代えてFriedman検定を行い、主効果が認められた場合には、Bonferroni補正を施したWilcoxonの符号付順位検定による対比較を行った。

　なお、自由スイング条件はGo cueを呈示せず反応時間を算出できないため、反応時間についてのみ、単純反応課題、Go/No-Go課題、およびGo/Stop課題の3条件を水準とする分散分析を行った。

　有意水準はいずれも5%とし、統計処理にはR（バージョン4.3.1、R Core Team）を用いた。
