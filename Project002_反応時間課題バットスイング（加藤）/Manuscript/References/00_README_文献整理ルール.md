# 文献整理ルール (Instruction for References)

このフォルダ（`References`）に新しく文献（論文等）を追加する際は、以下の統一ルールに従って整理・配置を行ってください。AI（Antigravityなど）に作業を依頼する際にも、このルールが基準となります。

## 1. 論文ごとにサブフォルダを作成し、本文の引用番号をつける
文献ごとに専用のフォルダを作成し、その番号は **`Manuscript/引用番号対応表.md` の引用番号（原稿本文中の初出順）と一致**させます。

- フォルダ名の命名規則: `[引用番号]_[内容を示す簡単な言葉]_[第一著者名]_et_al_[発行年]`
- 「内容を示す簡単な言葉」は、その論文が扱うテーマを一目で示せる短い日本語（例：床反力とバットスピード、EEGと知覚行動結合）とする
- 例1: `01_単純反応時間と選択反応時間の比較_Wadoo_et_al_2019`（引用番号 1)）
- 例2: `09_認知運動統合バッティング課題_Nasu_et_al_2020`（引用番号 9)）
- **欠番は詰めない**。本文で引用しているが原典が未収集の文献は、番号を確保したまま `NN_未収集_...` というフォルダ名にし、中に `00_未収集メモ.md` のみを置く
- 本文に文献を追加して初出順が変わった場合の手順は `Manuscript/引用番号対応表.md` の「番号が変わった場合の手順」に従う

> **2026-08-16 の変更**　従来このフォルダは「プロジェクトに集めた順（収集順）」で採番しており、引用番号順の `Manuscript/1. Introduction/references/` と二重管理になっていた。現在は本フォルダに一本化し、採番も引用番号順に統一している。

### 引用番号を持たない文献の置き場所
- `90_未引用_本文で引用していない文献/`：収集済みだが本文でまだ引用していない文献。引用番号を持たないため**通し番号を付けない**（詳細は同フォルダの `00_README_未引用文献について.md`）
- `試行数/`：Methods の試行数の設定根拠として参照している資料。本文の引用番号体系の外に置く

## 2. ファイルの順序を固定する（01_, 02_, 03_ の付与）
各サブフォルダ内において、「1. 本文」「2. 和訳」「3. ノート」が常にこの順序でエディタ上に並ぶよう、ファイル名の先頭にナンバリング（プレフィックス）を追加します。

**構成イメージ：**
1. `01_<原著論文のファイル名>.pdf`
2. `02_<和訳論文のファイル名>.pdf` （※和訳が存在する場合のみ）
3. `03_notes.md` （メモ帳ファイル）

## 3. notes.md のテンプレート
新規に `03_notes.md` を作成する場合は、以下のテンプレートをコピーして使用してください。

```markdown
# 論文メモ: [第一著者名] et al. ([発行年])

## 文献情報
- **タイトル**: [論文のタイトル]
- **著者**: [著者一覧]
- **発行年**: [発行年]

## 概要
(論文のアブストラクトや全文をもとに、研究の背景・目的・実験方法・主要結果・結論を日本語でまとめてください)

## 大事な部分・要点
(その論文が主に述べていること・主張・結論を簡潔な箇条書きで示してください)
- 
- 

## 自身のプロジェクトへの応用・検証したいこと
- 
```

## 4. 論文追加時に概要を必ず記述する
新規に `03_notes.md` を作成した際は、アブストラクト・和訳・本文等をもとに、**概要セクションに日本語で論文の概要を記述**してください。

- 概要には「背景・目的」「実験・方法」「主要な結果」「結論・意義」を含めることを基本とします
- AIに作業を依頼する場合は、アブストラクト（和訳）を提供するか、その旨を指示してください
- 概要が未記入のまま（テンプレートのプレースホルダー文言のまま）にならないよう注意してください

## 5. 「大事な部分・要点」には論文の主要な主張を簡潔に示す
`## 大事な部分・要点` セクションには、**その論文が主に述べていること（主張・発見・結論）を簡潔な箇条書きで記述**してください。

- 論文のキーメッセージが一目でわかる内容にまとめます
- 詳細な手続きや数値の羅列ではなく、「何がわかったか・何を主張しているか」を中心に記述します
- 各項目は太字（`**〜**`）で主張のキーワードを示したうえで、その補足を続けると読みやすくなります
- AIに作業を依頼する場合は、アブストラクトや結果・考察部分を提供するか、その旨を指示してください
