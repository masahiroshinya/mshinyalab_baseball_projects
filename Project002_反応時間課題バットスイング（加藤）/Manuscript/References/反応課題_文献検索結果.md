> **用語について**　依頼メモの「Go Stop task」は、本プロジェクトの Methods（Go:Stop = 10:5）と同じく、**Go 刺激のあとに一定の遅れで停止信号が出る「停止信号課題（stop-signal task: SST）」**と解釈した。なお、名前の似た **"GoStop Impulsivity Paradigm"**（Dougherty ら、衝動性の臨床評価用）という別の課題もあるが、本ファイルでは扱っていない。

## 0. 要約

- **3課題の違いは「刺激が出たあとに何を決めるか」にある。**
  - 単純反応課題（SRT）：決めることはない（刺激が出たら必ず反応する）。
  - Go/No-Go 課題（GNG）：刺激を見て「反応するか、しないか」を決める（**行動の差し控え：action restraint**）。
  - 停止信号課題（SST）：いったん始めた反応を、あとから来た信号で取り消す（**行動の取り消し：action cancellation**）。
- **RT の大小は、おおむね SRT ＜ GNG の Go 反応 ＜ 選択反応（CRT）** となる。Donders（1868）以来この順序は繰り返し確認されている。同じ参加者20名で3課題を比べた研究では **SRT 235 ms、GNG 461 ms、CRT 516〜527 ms** だった［文献[10](#ref-10)］。
- **停止信号課題では、停止信号が出る可能性があるだけで Go 反応が遅くなる**（408 ms → 501 ms など［文献[13](#ref-13)］）。止めるのに要する時間（**SSRT**）は健常成人でおよそ **190〜270 ms** である［文献[5](#ref-5)・[11](#ref-11)・[12](#ref-12)・[13](#ref-13)・[18](#ref-18)］。
- **脳の処理**：GNG と SST はどちらも「抑制課題」と呼ばれるが、メタ分析と脳波・筋電図の研究は**両者の仕組みは同じではない**と結論している［文献[4](#ref-4)・[5](#ref-5)］。共通部位は右前部島皮質・内側上前頭皮質（pre-SMA）など。GNG では右背外側前頭前野と頭頂葉、SST では右下前頭回－視床下核（ハイパーダイレクト経路）の役割が強調される。末梢の筋で抑制が始まる時刻は **GNG で約316 ms、SST で約140 ms**（刺激からの時間）［文献[5](#ref-5)］。
- **野球との関係**：野球選手は SRT では非競技者と差がないが、GNG の Go 反応が速い［文献[17](#ref-17)］。SST でも、テニスなどの「オープンスキル」の競技者は SSRT が短い［文献[9](#ref-9)・[18](#ref-18)］。

### 2-2. 課題ごとの処理の流れ

**(a) 単純反応課題（SRT）**

- 処理は「刺激の検出 → あらかじめ用意した反応の実行」だけ。反応する手指も決まっているので、刺激が出る前に運動の準備をすべて済ませておける。
- Woods ら（2015）は SRT（約213〜231 ms）を、**刺激の検出時間（約131 ms）と運動の開始時間**に分けて推定した。加齢で SRT が遅くなるのは主に運動出力が遅くなるためで、刺激の検出時間は年齢で変わらなかった［文献[16](#ref-16)］。
- 刺激前の脳波では、SRT は視覚野の準備活動が大きく、前頭前野の準備活動（pN）は小さい［文献[10](#ref-10)］。

**(b) Go/No-Go 課題（GNG）**

- 処理は「刺激の識別 → 反応するかどうかの判断 → 反応する／しない」。
- Donders の減算法では「識別」の時間を測る課題と位置づけられた（c 反応）。しかし Wundt の時代から「反応するかどうかを決めるのも一種の選択ではないか」という批判があり、Roelofs（2018）は Donders の未発表データからこの批判を支持している［文献[14](#ref-14)］。
- 刺激前に前頭前野の準備活動が3課題の中で最も大きい。反応するかどうか分からない不確かさを反映すると考えられている［文献[10](#ref-10)］。
- No-Go 刺激のあとには前頭部の陰性電位（**No-Go N2**、刺激後約200〜300 ms）が出る。Falkenstein ら（1999）は、これは運動レベルではなく**運動の手前（前運動レベル）での抑制**を反映すると解釈した［文献[20](#ref-20)］。
- Danek & Mordkoff（2011）は、運動準備電位（LRP）が始まってから反応するまでの時間が SRT より GNG で長いことを示した。GNG では運動の段階にも「抑制のための部品」が加わっている可能性がある［文献[21](#ref-21)］。一方、Miller & Low（2001）は3課題で運動段階の時間はほぼ一定と報告しており［文献[22](#ref-22)］、結論はまだ一致していない。

**(c) 停止信号課題（SST）**

- 処理は「Go 刺激で反応を始める → 遅れて停止信号が来る → 始めた反応を取り消す」。
- **競馬モデル（horse-race model）**：Go の処理と Stop の処理が競争し、Stop が先にゴールすれば反応は止まる。この考え方から、直接は見えない「止めるのに要する時間」＝ **SSRT** を推定する［文献[2](#ref-2)・[3](#ref-3)・[23](#ref-23)］。
- 脳では、右下前頭回（rIFG）と pre-SMA が停止信号を検出し、視床下核（STN）を経て視床から運動野への出力を止める（**ハイパーダイレクト経路**）と考えられている［文献[1](#ref-1)・[24](#ref-24)］。Aron & Poldrack（2006）では、止めるのが速い人ほど rIFG と STN の活動が大きかった［文献[24](#ref-24)］。
- 停止信号が出る可能性があると分かっているだけで、参加者は Go 反応を慎重にする（**事前的な調整：proactive control**）［文献[13](#ref-13)］。

### 2-3. 各課題における処理の違い（まとめ）

| 観点 | 単純反応（SRT） | Go/No-Go（GNG） | 停止信号（SST） |
| :--- | :--- | :--- | :--- |
| 刺激後に決めること | なし | 反応する／しない | 始めた反応を取り消すか |
| 抑制の種類 | なし | 行動の差し控え（restraint） | 行動の取り消し（cancellation） |
| 抑制が必要になる時点 | — | 反応を始める**前** | 反応を始めた**後** |
| 刺激前の準備 | 運動の準備を完全に済ませられる | 前頭前野の準備が最大 | 停止に備えて感覚運動系を構える |
| 筋で抑制が見える時刻 | — | 約316 ms（No-Go 刺激から）［[5](#ref-5)］ | 約140 ms（停止信号から）［[5](#ref-5)］ |
| 主な脳部位 | 視覚野、運動前野・運動野 | pre-SMA、右背外側前頭前野、頭頂葉（課題の難しさによる） | rIFG、pre-SMA、STN、右前部島皮質 |
| 測る指標 | RT | Go RT、誤反応（コミッションエラー）率 | Go RT、SSRT、停止成功率 |
| 注意点 | 計測機器の遅延が RT に影響する［[16](#ref-16)］ | No-Go の割合と試行テンポで抑制の要求が変わる［[8](#ref-8)］ | 停止信号の割合で Go RT が延びる［[13](#ref-13)］。SSRT は推定法で変わる［[3](#ref-3)・[12](#ref-12)］ |

### 3-2. 課題間の関係（どちらが速いか・有利／不利）

1. **SRT が最も速い（約210〜250 ms）。** 判断が不要で、運動の準備をすべて事前に済ませられるため。
2. **GNG の Go 反応は SRT より遅く、CRT より速い。** Berchicci ら（2023）の同一参加者の比較では、SRT より約230 ms 遅く、CRT より約55〜65 ms 速かった［[10](#ref-10)］。Gomez ら（2007）も、判断に使う情報は2選択課題と同じで、違うのは反応の基準と判断以外の成分だけ、と拡散モデルで示した［[28](#ref-28)］。GNG が CRT より速いのは、**反応する手指を選ぶ必要がない**ためと考えられる。
3. **SST の Go 反応は、停止信号が出ないときでも遅くなる。** 停止の可能性を知っているだけで慎重になるため［[13](#ref-13)］。停止信号の割合が高いほど遅くなる（0% 395 ms → 70% 574 ms）。Raud ら（2020）でも、同じ Go 課題を使っても GNG より SST のほうが Go RT が遅かった［[5](#ref-5)］。
4. **止める速さは、SST（取り消し）のほうが GNG（差し控え）より速いように見える**（筋での抑制開始 140 ms 対 316 ms［[5](#ref-5)］）。ただし基準となる時刻が違う（停止信号の時刻と No-Go 刺激の時刻）ため、単純には比べられない。SST では、停止信号が来る前から止める準備をしている点が大きい。
5. **「有利／不利」は何を測るかで変わる。**
   - 反応を始める速さ：SRT ＞ GNG ＞ CRT ≒ SST の Go。
   - 誤反応の起こりやすさ：GNG は No-Go が少ないほど誤反応が増える［[8](#ref-8)］。SST は停止成功率が約50%になるよう遅延を調整するのが標準なので、半分は止められない［[3](#ref-3)］。
   - 競技経験の効果：SRT には現れにくく、GNG［[17](#ref-17)・[27](#ref-27)］と SSRT［[9](#ref-9)・[18](#ref-18)］には現れやすい。

### 3-3. 数値を比べるときの注意

- **機器の遅延**：コンピュータでの計測では数十 ms の遅延が加わることがある（Woods らの補正は 18 ms）［[16](#ref-16)］。
- **代表値の取り方**：平均値・中央値・最速値で値が変わる（Wadoo らは10試行中の最速値、Berchicci らは中央値）。
- **SSRT の推定法**：平均法・積分法などで値が変わる。外れ値の除外基準によっても変わる［[3](#ref-3)・[12](#ref-12)］。
- **反応の種類**：上の数値はすべて指によるボタン押し（Donders は声）。**バットスイングのような全身運動では、運動の開始・実行に必要な時間が加わる**ので、そのまま当てはめることはできない。

## 4. 本プロジェクトとの関係（メモ）

- 本研究の Go/Stop 条件（Go:Stop = 10:5、Stop 試行 ≒ 33%）は、Verbruggen ら（2009）の実験1（Stop 1/3）や実験5の30%文脈に近い。この文献では、30% 文脈で 0% 文脈より **Go RT が約94 ms 延びた**［[13](#ref-13)］。本研究でも、Go/Stop 条件の Go 試行でスイング開始が遅れることが予想される。
- GNG と SST は脳の仕組みが異なる［[4](#ref-4)・[5](#ref-5)］ので、Introduction で「抑制課題」とまとめて書く場合は、本研究がどちら（差し控えか取り消しか）を扱っているかを明記するとよい。
- 野球の打撃は「振るか振らないか（GNG 的）」と「振り始めてから止める（チェックスイング、SST 的）」の両方を含む。Kida ら（2005）は GNG の側面を、本研究の Stop 条件は SST の側面を扱っていると整理できる。
