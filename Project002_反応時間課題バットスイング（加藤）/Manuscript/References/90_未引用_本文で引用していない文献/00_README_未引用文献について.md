# 未引用の文献について

このフォルダには、**収集済みだが原稿本文でまだ引用していない**文献を置いている。

`Manuscript/References/` 直下の `01_`〜`11_` は `Manuscript/引用番号対応表.md` の**引用番号と一致**させているため、引用番号を持たない文献をそこに置くと番号が食い違う。そのため、番号を付けずにこのフォルダへ退避している。

## 運用ルール

- このフォルダ内のサブフォルダには**通し番号を付けない**（引用番号を持たないことを明示するため）。
- 本文で引用することが決まったら、`Manuscript/引用番号対応表.md` に行を追加して引用番号を確定させたうえで、その番号を接頭辞にして `References/` 直下へ移すこと。
- フォルダ内のファイル構成（`01_` 原著・`02_` 和訳・`03_notes.md`）は `00_README_文献整理ルール.md` のとおり維持する。
