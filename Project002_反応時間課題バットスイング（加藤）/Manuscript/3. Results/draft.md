## ［保留］課題遂行の確認

### 構成　【要確認】Methodsに未記載 ／ 【要確認】節の採否

**趣旨**　条件間の比較に先立ち、参加者が各課題の教示どおりに反応していたことを示す。すなわち、Go/No-Go課題のNo-Go試行でスイングを抑制できていたか、Go/Stop課題のStop試行で動作を中止できていたかである。これが担保されて初めて、Go試行を条件間で比較することの意味が成り立つ。

| 指標                 | 定義                                                    |
| :------------------- | :------------------------------------------------------ |
| No-Go試行の誤反応率  | No-Go試行（5試行）のうち、スイングを開始した試行の割合  |
| Stop試行の中止成功率 | Stop試行（5試行）のうち、スイングを中止できた試行の割合 |

> 【要確認・優先度高】**この節を設けるかどうかはMethods 2-4・2-5の改訂を伴う**。現行のMethodsはNo-Go試行・Stop試行を「集計対象から除外」とのみ規定しており、誤反応・中止成功の判定基準（何をもって「スイングを開始した」「中止できた」とするか）を定義していない。本節を残す場合は、2-4に判定基準を追記する必要がある。
>
> 判定基準の候補：動作開始の検出（2-4-1の手部速度の閾値超え）をそのまま流用し、閾値を超えた試行を「スイングを開始した」とみなす。この方式なら新たな定義を導入せずに済む。
>
> 本節を設けない場合、Go/No-Go課題・Go/Stop課題が意図した認知的負荷を与えられていたかを示す材料がResultsから失われる。抑制課題を用いる研究では通例報告される情報であるため、設ける方向で検討したい（2026-08-15 提案）。

## 3-1. 反応時間

### 構成　【確定】報告項目 ／ 【要確認】数値

**対象**　単純反応課題・Go/No-Go課題・Go/Stop課題の3条件のGo試行（自由スイング条件はGo cueを呈示しないため対象外。Methods 2-4-1）。

**表2a　条件別の反応時間**（平均 ± 標準偏差、n = 20）【仮数値】

| 条件         | 反応時間（ms） |
| :----------- | :------------- |
| 単純反応課題 | 258 ± 28       |
| Go/No-Go課題 | 331 ± 35       |
| Go/Stop課題  | 352 ± 41       |

**検定結果**【仮数値】

| 段階     | 結果                                                                                                                                      |
| :------- | :---------------------------------------------------------------------------------------------------------------------------------------- |
| 正規性   | Shapiro-Wilk検定：3条件とも正規性は棄却されず（*p* > .05）                                                                                |
| 球面性   | Mauchlyの検定で違反は認められず（*p* > .05）、自由度の補正は行わない                                                                      |
| 主検定   | 一元配置反復測定分散分析　*F*(2, 38) = 24.60, *p* < .001, 偏η² = .564                                                                     |
| 事後検定 | 単純反応 < Go/No-Go（*p* < .001, *d* = 1.45）／単純反応 < Go/Stop（*p* < .001, *d* = 1.82）／Go/No-Go < Go/Stop（*p* = .043, *d* = 0.55） |

> 【仮数値】仮の数値であるため、球面性の違反は生じなかったものとして自由度をそのまま*F*(2, 38)と表記している。実データでMauchlyの検定が有意となった場合は、Greenhouse-Geisser法で補正した自由度を小数第2位まで（例：*F*(1.56, 29.64)）と書き改め、本文にも補正を行った旨を加えること。表記の規則は［共通］統計値の表記ルールを参照。

> 【留意】Go/Stop課題の反応時間は、**1回目のGo cueに対する反応時間**である。Go/Stop課題ではStop試行であっても1回目にGo cueが呈示される設計であり（`03_Analysis/技術説明.md` §3.2に記録されたLED出力波形の仕様）、1回目の刺激は常に「スイングを開始せよ」を意味する。したがって刺激と反応の対応関係そのものは単純反応課題と同一であり、Go/No-Go課題のような刺激弁別を含まない。この点はResultsの記述とDiscussionの解釈の双方に関わるため、本文でも1回目のGo cueに対する値であることを明記する。

### 文章【仮数値】

　各条件の反応時間を表2aおよび図1に示す。反応時間は、単純反応課題で258 ± 28 ms、Go/No-Go課題で331 ± 35 ms、Go/Stop課題で352 ± 41 msであった。なお、Go/Stop課題の反応時間は、1回目のGo cueに対する値である。

　条件を要因とする一元配置反復測定分散分析の結果、条件の主効果が認められた（*F*(2, 38) = 24.60, *p* < .001, 偏イータ二乗 = .564）。事後検定の結果、Go/No-Go課題およびGo/Stop課題の反応時間は、いずれも単純反応課題より有意に長く（それぞれ*p* < .001, *d* = 1.45／*p* < .001, *d* = 1.82）、Go/Stop課題はGo/No-Go課題よりも有意に長かった（*p* = .043, *d* = 0.55）。

## 3-2. スイングスピード

### 構成　【確定】報告項目 ／ 【要確認】数値

**対象**　4条件すべて。Go/No-Go課題・Go/Stop課題はGo試行10試行（Methods 2-4 共通）。

**表2b　条件別のスイングスピード**（平均 ± 標準偏差、n = 20）【仮数値】

| 条件             | ピーク合成速度（m/s） | ピーク投手方向速度（m/s） |
| :--------------- | :-------------------- | :------------------------ |
| 自由スイング条件 | 32.5 ± 3.2            | 29.6 ± 3.0                |
| 単純反応課題     | 31.8 ± 3.1            | 28.8 ± 2.9                |
| Go/No-Go課題     | 30.6 ± 3.3            | 27.7 ± 3.1                |
| Go/Stop課題      | 29.4 ± 3.5            | 26.6 ± 3.2                |

**検定結果**【仮数値】

| 指標               | 正規性     | 主検定                                     | 事後検定（有意な対のみ）                                                                                                      |
| :----------------- | :--------- | :----------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| ピーク合成速度     | 棄却されず | *F*(3, 57) = 8.42, *p* < .001, 偏η² = .307 | 自由 > Go/No-Go（*p* = .012, *d* = 0.58）／自由 > Go/Stop（*p* < .001, *d* = 0.92）／単純 > Go/Stop（*p* = .004, *d* = 0.72） |
| ピーク投手方向速度 | 棄却されず | *F*(3, 57) = 7.86, *p* < .001, 偏η² = .293 | 自由 > Go/Stop（*p* < .001, *d* = 0.97）／単純 > Go/Stop（*p* = .007, *d* = 0.71）                                            |

> 【仮数値】自由スイング条件と単純反応課題の間には有意差が生じない想定とした（*p* = .48）。仮説は負荷の段階に沿った単調な低下を予測するが、隣接する条件間の差は小さく、20名では検出されない対が残ると見込まれるため。

**報告の順序**　主要指標であるピーク合成速度を先に述べ、副次指標であるピーク投手方向速度を後に述べる（Methods 2-4-2の位置づけに従う）。

> 【要確認】副次指標であるピーク投手方向速度について、主要指標と同じ粒度で検定結果まで報告するか、傾向が主要指標と一致する旨を述べるにとどめるかは、値が出た段階で判断する。両指標はピーク時に約0.90〜0.93の比を示す（Methods 2-4-2の内部メモ）ため、結果がほぼ平行に動くことが見込まれ、同じ記述を2度繰り返すことになりかねない。

### 文章【仮数値】

　各条件のスイングスピードを表2bおよび図2に示す。ピーク合成速度は、自由スイング条件で32.5 ± 3.2 m/s、単純反応課題で31.8 ± 3.1 m/s、Go/No-Go課題で30.6 ± 3.3 m/s、Go/Stop課題で29.4 ± 3.5 m/sであり、認知的負荷の高い条件ほど低い値を示した。

　条件を要因とする一元配置反復測定分散分析の結果、条件の主効果が認められた（*F*(3, 57) = 8.42, *p* < .001, 偏イータ二乗 = .307）。事後検定の結果、Go/No-Go課題およびGo/Stop課題のピーク合成速度は、自由スイング条件より有意に低く（それぞれ*p* = .012, *d* = 0.58／*p* < .001, *d* = 0.92）、Go/Stop課題は単純反応課題よりも有意に低かった（*p* = .004, *d* = 0.72）。自由スイング条件と単純反応課題との間に有意差は認められなかった（*p* = .48）。

　ピーク投手方向速度についても同様の傾向がみられ、条件の主効果が認められた（*F*(3, 57) = 7.86, *p* < .001, 偏イータ二乗 = .293）。事後検定では、Go/Stop課題が自由スイング条件および単純反応課題より有意に低い値を示した（それぞれ*p* < .001, *d* = 0.97／*p* = .007, *d* = 0.71）。

> 【要確認】表の列は解析コードの並び（Force1＝後ろ足、Force2＝前足）に合わせて後ろ足を左に置いているが、本文の記述順（前足が先）と食い違う。表の列順を本文に合わせて入れ替えるか、本文を表の順に合わせるかを統一すること。

### 文章【仮数値】

　各条件のピーク鉛直床反力を表2cおよび図3に示す。前足（踏み込み足）のピーク鉛直床反力は、自由スイング条件で158 ± 28 %BW、単純反応課題で154 ± 27 %BW、Go/No-Go課題で148 ± 29 %BW、Go/Stop課題で142 ± 30 %BWであった。

　一方、後ろ足のピーク鉛直床反力は、自由スイング条件で92 ± 15 %BW、単純反応課題で91 ± 16 %BW、Go/No-Go課題で89 ± 16 %BW、Go/Stop課題で87 ± 17 %BWであり、条件の主効果は認められなかった（*F*(3, 57) = 1.32, *p* = .277, 偏イータ二乗 = .065）。

**反応時間の予測についての補足**　Go/Stop課題の1回目の刺激は常にGo cueであり、刺激弁別を含まない点で単純反応課題と同型である。したがって単純に「認知的負荷の順に反応時間が延びる」とは予測できず、次の2つの結果がありうる。

| 想定                                     | 予測される順序                            | 含意                                                        |
| :--------------------------------------- | :---------------------------------------- | :---------------------------------------------------------- |
| 刺激弁別の有無のみが反応時間を決める     | 単純反応課題 ≒ Go/Stop課題 < Go/No-Go課題 | Go/Stop課題の負荷は反応時間ではなくスイング動作の側に現れる |
| 中止への備えが反応の立ち上がりを遅らせる | 単純反応課題 < Go/No-Go課題 ≦ Go/Stop課題 | 中止に備える構えが、動作開始そのものを抑制する              |

> いずれになるかは実データを待つほかない。Discussionでは、この分岐自体がGo/Stop課題という新しい条件から得られる知見となりうる。

**【リスク】予備実験の傾向と逆向きである点**　予備実験（Subject 01・02）では「認知課題があるほどスイングスピードが高い」という、仮説と逆向きの傾向が観察されている（`log/2026-08-13_03.md`・`log/2026-08-14_01.md`）。本実験でも同様の結果が得られた場合、Introduction 1-4の仮説は棄却される。その場合に備え、覚醒水準の上昇（Yerkes-Dodson則）やEasterbrookの注意狭窄仮説による説明の枠組みをDiscussion側で準備しておく必要がある（`log/2026-08-14_01.md`に記録済み）。

### 文章

　本研究では、認知的負荷の高い条件ほどスイングスピードおよび床反力が低下すると予想される。すなわち、判断を伴わない自由スイング条件で最も高い値を示し、単純反応課題、Go/No-Go課題、Go/Stop課題の順に低下すると考えられる。とりわけGo/Stop課題では、スイングの開始後に中止の可能性が残されているため、動作を最後まで加速しきることへの制約が最も強くはたらくと予想される。床反力についても、踏み込み脚の床反力がスイングスピードと正の関係にあることから、スイングスピードと同方向の変化を示すと予想される。

　反応時間については、刺激の種類に応じた弁別を要するGo/No-Go課題が、単純反応課題よりも長い値を示すと予想される。ただしGo/Stop課題の反応時間は、1回目のGo cueに対する反応であり刺激の弁別を伴わないため、単純反応課題と同程度にとどまる可能性と、動作の中止に備えることで延長する可能性の双方が考えられる。
