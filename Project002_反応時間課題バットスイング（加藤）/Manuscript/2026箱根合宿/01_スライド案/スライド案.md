## 1. 全体の流れ（ストーリー）

1. 打撃は「知覚・判断・動作」の統合課題だが、これまでの研究は**成績（反応時間・タイミング誤差）**を見てきた
2. 判断を伴うとき**スイング動作そのもの（バット速度・床反力）**がどう変わるかは分かっていない
3. LED 刺激で判断の種類を変えた 4 条件のスイングを、モーションキャプチャ＋フォースプレートで測った
4. 結果：**最大バット速度は条件間でほぼ同じ**。一方で、**反応して振ると同じ速度をより短い時間で出していた**。Go/Stop では動作の開始と力の立ち上がりが遅くなった
5. 結論：自由スイング（素振り）で観察した動作は、反応を伴う場面の動作を代表するとは限らない

> 仮説（負荷が高いほど速度・床反力が下がる）は、**速度については支持されなかった**。ここを隠さず、「下がらなかった代わりに**時間の使い方**が変わった」を発表の主張にするのが自然。

### Slide 2　Backgrounds

**主張**：打撃は、ごく短い時間で「知覚・判断・動作」を統合する課題である。

- 150 km/h の投球はリリースからホームベース到達まで約 400 ms
- スイング所要時間を除くと、判断に使える猶予は 250〜350 ms 程度
- 視覚刺激への反応時間は単純反応で約 250 ms、選択反応で約 370 ms（Wadoo & Syeed, 2019）
- TTC が 400〜425 ms を下回るとコンタクト率が急低下する（Hayashi et al., 2026）

**図の案**：投球の時間軸（リリース → 判断 → スイング開始 → インパクト）を 1 本の帯で示し、各区間の ms を書き込む

### Slide 4　References（2）動作・床反力の研究

### Slide 5　Problem Statements

**主張**：判断を伴うとき、**バットスイングの動作そのもの**がどう変わるかは分かっていない。

1. 打撃の研究の指標は、反応時間・タイミング誤差・打撃結果といった**成績**が中心
2. 二重課題で床反力が変わることは、着地・ジャンプでは示されているが、**判断と全身の加速を数百 ms で両立させるスイング**では未検討
3. 練習現場では素振り・ティー打撃など**判断を伴わない練習**が多い。素振りで見ている動作が、実戦の（判断を伴う）動作と同じかは確かめられていない

---

### Slide 6　Solutions

**主張**：判断の種類を段階的に変えた 4 条件で、スイングを運動学・運動力学的に測る。

- LED 刺激で「振る／振らない／止める」の判断を課す
- 判断の**有無・内容・タイミング**が異なる 4 条件を設定

| 条件 | 判断 | 判断の時点 |
| :--- | :--- | :--- |
| 自由スイング（free） | なし（任意のタイミング） | ― |
| 単純反応（simple） | 刺激に反応して開始 | 開始前 |
| Go/No-Go | 振る／振らない | 開始前 |
| Go/Stop | 続ける／止める | **開始後** |

- モーションキャプチャ（バット速度）＋フォースプレート（床反力）で同時計測

**図の案**：4 条件の LED 呈示タイミング図（白 → 緑／赤、Go/Stop は 0.25 s 後に2回目の刺激）

### Slide 7　Purpose / Hypothesis

- **Purpose**：判断の種類が異なる 4 条件で、反応時間・動作時間・バット速度・床反力を比較し、判断がバットスイングに及ぼす影響を明らかにする
- **Hypothesis**：認知的負荷の高い条件（free < simple < Go/No-Go < Go/Stop）ほど、バット速度・床反力は低下する

> 仮説は Introduction 1-4 の記述のまま。結果スライドで「速度は下がらなかった」と対比させる。

### Slide 10　Methods：統計解析・解析指標

**解析指標**（図で示すと分かりやすい：1 試行の Fx・Fz2・バット速度の波形に時点を書き込む）

| 指標 | 定義 |
| :--- | :--- |
| 動作開始（onset） | 前後方向の合成床反力 Fx が、cue 前 0.5 s の中央値＋（窓内ピーク − 中央値）× 0.20 を 20 ms 継続して超えた時点 |
| 反応時間（RT） | Go cue → onset |
| 動作時間（MT, Fz） | onset → 踏み込み足 Fz のピーク |
| 動作時間（MT, バット） | onset → バット先端速度のピーク |
| 最大バット速度 | バット先端（top マーカー）の合成速度のピーク |
| ピーク鉛直床反力 | 踏み込み足 Fz のピーク（%BW） |
| 力の立ち上がり速度 | （Fz ピーク − onset 時の Fz）÷ 体重 ÷（onset → ピークの秒数）[%BW/s] |

**解析**

- 対象は Go 試行のみ（No-Go・Stop 試行は除外）
- 条件別の中央値と四分位範囲、被験者ごとの中央値を示す（記述統計のみ）
- 除外：床反力の欠損・Fz2 のゼロ点ずれ、フライング、top マーカーの欠損（バット速度のみ）

> 【要確認】`Manuscript/2. Methods/draft.md` では動作開始を**手部速度の閾値**（Nasu et al., 2020 準拠）で定義しているが、実際の解析（5.6・5.8）は**Fx の閾値**を使っている。スライドは実際の解析に合わせた。Methods 原稿をどちらに合わせるかは別途決める。
>
> 【要確認】「なぜ 20%・20 ms か」は必ず聞かれる。グリッド探索で選んだ値（生理的下限 150 ms 未満の試行が最少・被験者内 SD が最小・条件順が単調）であることを口頭で説明できるようにしておく（`Manuscript/技術説明.md` §3-4）。

### Slide 13　Discussion：Free condition VS Reaction Time Tasks

**主張**：刺激に反応して振るとき、打者は**同じバット速度をより短い時間で**出している。

| | free | 反応課題（simple） |
| :--- | ---: | ---: |
| MT（Onset → Fz ピーク） | 616 ms | 465 ms（約 25% 短い） |
| 最大バット速度 | 32.1 m/s | 32.3 m/s（ほぼ同じ） |
| 力の立ち上がり速度 | 210 %BW/s | 261 %BW/s（約 25% 大きい） |
| ピーク床反力 | 131.9 %BW | 126.6 %BW |

**解釈（案）**

- free は時間をかけて大きめの力を出し、反応課題は**ピークを少し抑えて速く立ち上げる**。到達するバット速度は同じ
- 時間的な制約があると、打者は「力の大きさ」より「力を出す速さ」で速度を確保している可能性
- 実践への示唆：素振り（自己ペース）で観察・評価した動作は、反応を伴う場面の動作を代表するとは限らない

**想定される質問への備え**

- 「free は動作開始の検出が甘いだけでは？」→ 2026-08-26 に検証済み。free の長い MT は検出のアーティファクトではなく、実際に運動がゆっくり始まっている（抄録 draft §5「動作開始の検出の妥当性」）
- 踏み込み足は cue の時点で全員がすでに浮かせている（5.8 技術説明 §3-2）。構えの準備は条件間でそろっている

### Slide 14　Discussion：Go/Stop task VS Simple Reaction Task

**主張**：Go/Stop では、**止める可能性に備えて**動作の開始と力の立ち上がりが遅くなるが、最大バット速度は保たれる。

| | simple | Go/Stop | 差 |
| :--- | ---: | ---: | ---: |
| RT | 196 ms | 239 ms | +43 ms |
| MT（Onset → Fz ピーク） | 465 ms | 522 ms | +57 ms |
| 力の立ち上がり速度 | 261 %BW/s | 233 %BW/s | −28 |
| 最大バット速度 | 32.3 m/s | 32.2 m/s | ほぼ同じ |

**解釈（案）**

1. **1 回目の刺激は simple と同じ Go cue なのに RT が 43 ms 長い。** 刺激と反応の対応は同じなので、刺激の弁別では説明できない。停止信号に備えると Go 反応が遅くなるという**事前的な調整**（Verbruggen & Logan, 2009）と整合する
2. **2 回目の刺激は 1 回目の 250 ms 後に出る。** Go/Stop の RT（239 ms）はこれにほぼ重なる。参加者は**2 回目の刺激を見てから動き出そうとしている**可能性がある（意図した「開始後の判断」になっていない可能性）
3. 開始後も力の立ち上がりが緩やかで、止める余地を残した動作になっている可能性。それでも最終的なバット速度は落ちていない

> 【要確認】解釈 2 は発表で言うと必ず突っ込まれる点。RT の分布で 250 ms 付近に試行が集まっているか、Stop 試行で実際にスイングが途中で止まっているか（onset が 2 回目の刺激より前か後か）を確かめてから話すかどうか決める。確認できないなら「課題設計上の課題」として Conclusion の今後の展望に回す。

---

### Slide 15　Conclusion

1. 刺激に反応して振ると、自由スイングと**同じバット速度を、より短い動作時間・より速い力の立ち上がりで**達成していた
2. Go/Stop 課題では、止める準備によって動作の開始と力の立ち上がりが遅くなったが、最大バット速度は保たれていた
3. 自由スイング（素振り）で観察した動作は、判断を伴う場面の動作を代表するとは限らない

**限界と今後**

- 10 名・検定なしの途中経過。参加者を追加し、統計的に検討する
- Go/Stop の 2 回目刺激のタイミング（0.25 s）が課題として妥当かを再検討する
- 関節角度など運動学的な指標を加え、「時間の短縮」がどこで生じているかを調べる
