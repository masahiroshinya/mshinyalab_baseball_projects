# bottom も使える試行の抽出（技術説明）

作成：2026-11-12　加藤 和太郎（student）、Claude Code

## 1. 目的

今 top を使っている試行のうち、**bottom（バットの握り側の端）のマーカーも使える試行だけを抜き出す**。bottom → top でバットの向き（バットのベクトル）を使う解析の準備にする。

## 2. 試行の選び方

### 2.1 「top を使っている試行」

x8（`x8_make_stat_table.m`）で top の指標が残っている試行。x8 と同じ式で決める。

```
UseTop = ~( (IsBadTop & ~KeepTop) | IsBadOnset | ExclTop )
```

| 列 | 意味 |
|---|---|
| `IsBadTop` | 解析窓（合図から 2 s）の中に、top の欠損が残っている（除外基準①） |
| `KeepTop` | 目視で残した（code_exclusion_list.csv の Mark = k、Target = top）。「top を使う」の印ではない |
| `IsBadOnset` | Go 試行で Onset が見つからない（除外基準③、試行ごと外す） |
| `ExclTop` | 目視で外した（Mark = exclude、Target = top または all） |

NoGo・Stop 試行も含める（Onset がないのが正常なので `IsBadOnset` は付かない）。Go 試行だけを使うときは `CueText == "Go"` でさらに絞る。

### 2.2 「bottom も使える」

top の除外基準①と同じ基準を bottom にあてはめる。

- 解析窓：合図の時点（`TCueMarker`、マーカーのフレーム番号）から `Prm.Excl.WinSec`（2.0 s）まで
- その窓の中に、bottom の欠損（x, y, z のどれかが NaN）が **1 フレームもない**試行を「使える」とする
- x3 の `DataArray` のマーカーは、x2 で `Prm.MaxNumNans`（10 フレーム）以下の欠損が補間済み。残っている NaN は、それより長い欠損（と記録の端の欠損）だけなので、実質の閾値は top と同じ 10 フレーム
- bottom がラベル付けされていない試行は「使えない」とする

## 3. 使うデータ

| データ | 場所 | 使う列・変数 |
|---|---|---|
| 試行の表 | `Experiments/Main experiments/03_Analysis/x8_StatTable/StatTable.mat` の `TrialTable` | `Subject`、`Condition`、`Trial`、`CueText`、`TCueMarker`、`IsBadTop`、`KeepTop`、`IsBadOnset`、`ExclTop` |
| マーカー | `Experiments/Main experiments/03_Analysis/x3_DataChecked/DataXX.mat` の `DataArray` | `Markers.bottom`、`FrameRate` |
| パラメータ | `Experiments/Main experiments/03_Analysis/parameters.m` | `Prm.Excl.WinSec` |

`TrialTable.Trial` は `DataArray` の行番号（x6 の `iTrial`）、条件の列は `{'free', 'simple', 'gonogo', 'gostop'}` の順。`DataArray(Trial, 条件の番号)` で同じ試行のマーカーが取れる。

## 4. 処理の流れ

1. `parameters.m` と `StatTable.mat` を読み、`TrialTable` に `UseTop` の列を作る
2. 被験者ごとに `DataXX.mat` を読む
3. 各試行で `DataArray(Trial, 条件)` の `Markers.bottom` を取り、解析窓の中の NaN のフレーム数（`NNanInWinBottom`）を数える
4. `BottomOK = HasBottom & NNanInWinBottom == 0` とする
5. `UseTop & BottomOK` の試行を抜き出して保存する（出力は 5 節）

### 4.1 コード案（`extract_bottom_trials.m`）

このフォルダに `extract_bottom_trials.m` として置く想定。2026-11-12 に作業用フォルダで同じコードを実行し、6 節と同じ数（551 試行中 506 試行）になることを確かめた。

#### ① パスと設定

```matlab
%% extract_bottom_trials.m
%  top を使っている試行のうち、bottom も使える試行を抜き出す
clear ; clc

here    = fileparts(mfilename('fullpath')) ;          % このファイルのフォルダ
projDir = fullfile(here, '..', '..') ;                % Project002 のフォルダ
anaDir  = fullfile(projDir, 'Experiments', 'Main experiments', '03_Analysis') ;
outDir  = fullfile(here, 'output') ;
if ~exist(outDir, 'dir'), mkdir(outDir) ; end

addpath(anaDir) ;          % parameters.m を使うため
Prm = parameters ;         % Prm.Excl.WinSec（解析窓 2.0 s）を使う

ConditionOrder = {'free', 'simple', 'gonogo', 'gostop'} ;   % DataArray の列の順
```

- `mfilename('fullpath')` で、このファイルの場所からの相対パスでデータを探す。7.1 の README の決まり（自分のフォルダからの相対パス）と同じ。`sandbox/7.2_.../` の深さを変えると動かなくなる
- `ConditionOrder` は x6・x8 と同じ順。`DataArray` の列番号を決めるのに使う

#### ② top を使っている試行（x8 と同じ式）

```matlab
S  = load(fullfile(anaDir, 'x8_StatTable', 'StatTable.mat'), 'TrialTable') ;
TT = S.TrialTable ;

TT.UseTop = ~( (TT.IsBadTop & ~TT.KeepTop) | TT.IsBadOnset | TT.ExclTop ) ;
```

- x8 の `isOutTop` の否定。x8 は top の指標を NaN にするだけで、`UseTop` の列は持っていないので、ここで作る
- `PeakVelTop` が NaN かどうかで選ぶ方法もあるが、ピーク自体が求まらなかった試行と区別がつかないので、x8 と同じ式で選ぶ

##### ② をくわしく

**1 行目・2 行目：表を読み込む**

```matlab
S  = load(fullfile(anaDir, 'x8_StatTable', 'StatTable.mat'), 'TrialTable') ;
TT = S.TrialTable ;
```

- `load(ファイル, 'TrialTable')` は、mat ファイルの中から `TrialTable` という変数だけを読む。結果は構造体 `S` に入るので、`S.TrialTable` で取り出す
- `TT` は x8 の試行の表（1 行 = 1 試行、全 598 試行）。名前を短くするために `TT` に入れ直している

**3 行目：「top を使う」かどうかの列を作る**

```matlab
TT.UseTop = ~( (TT.IsBadTop & ~TT.KeepTop) | TT.IsBadOnset | TT.ExclTop ) ;
```

`TT.UseTop = ...` と書くと、表に `UseTop` という新しい列ができる。中身は試行ごとの true / false。

使っている記号：

| 記号 | 読み方 | 意味 |
|---|---|---|
| `&` | かつ | 両方 true のときだけ true |
| `\|` | または | どちらか 1 つでも true なら true |
| `~` | ではない | true と false をひっくり返す |

式を日本語にすると、次のようになる。かっこの中は「**top を使わない理由**」で、どれか 1 つでも当てはまれば使わない。最後の `~` でひっくり返して「使う」にしている。

```
使わない理由 =  ( top が欠けている  かつ  目視で残していない )   … 理由 1
              または  Onset が見つからない                     … 理由 2
              または  目視で外した                             … 理由 3

UseTop = 使わない理由が 1 つもない
```

**4 つの列の意味**

| 列 | true のとき |
|---|---|
| `IsBadTop` | 合図から 2 s の間に、top の欠損が残っている（コードの自動の判定） |
| `KeepTop` | top が欠けているが、目視で見て「使える」と判断した（Mark = k） |
| `IsBadOnset` | Go 試行で、スイングの開始（Onset）が見つからない |
| `ExclTop` | 目視で見て「使えない」と判断した（Mark = exclude） |

理由 1 が `IsBadTop` だけでなく `& ~KeepTop` になっているのは、欠けていても目視で残した試行は使うため。

**実際の試行で確かめる（全 598 試行）**

| パターン | 例 | IsBadTop | KeepTop | IsBadOnset | ExclTop | UseTop | 試行数 |
|---|---|---|---|---|---|---|---|
| A. 問題なし | S01 free T1 | false | false | false | false | **true** | 520 |
| B. top が欠けている | S04 free T3（欠損 86 フレーム） | true | false | false | false | false | 24 |
| C. 欠けているが目視で残した | S01 free T5（欠損 46 フレーム） | true | true | false | false | **true** | 31 |
| D. Onset が見つからない | S01 gonogo T3 | false | false | true | false | false | 21 |
| E. 目視で外した | S04 simple T2 | false | false | false | true | false | 2 |

- A：理由が 1 つもない → 使う
- B：`IsBadTop & ~KeepTop` = true & true = true → 理由 1 に当たる → 使わない
- C：`IsBadTop & ~KeepTop` = true & false = false → 理由 1 に当たらない → 使う
- D：理由 2 に当たる → 使わない（top がきれいでも、スイングの開始が取れないので試行ごと外す）
- E：理由 3 に当たる → 使わない

使うのは A と C で、520 + 31 = **551 試行**。

#### ③ bottom の欠損を数える

```matlab
TT.HasBottom       = false(height(TT), 1) ;
TT.NNanInWinBottom = nan(height(TT), 1) ;

for iSubject = unique(TT.Subject)'
    D = load(fullfile(anaDir, 'x3_DataChecked', sprintf('Data%02d.mat', iSubject)), 'DataArray') ;

    for i = find(TT.Subject == iSubject)'
        iCondition = find(strcmp(ConditionOrder, TT.Condition(i))) ;
        X    = D.DataArray(TT.Trial(i), iCondition) ;   % この試行のデータ
        tCue = TT.TCueMarker(i) ;                       % 合図のフレーム番号

        if ~isfield(X.Markers, 'bottom') || isnan(tCue)
            continue        % bottom がない、または合図が取れていない → 使えない
        end

        isNanBottom = any(isnan(X.Markers.bottom), 2) ;      % x, y, z のどれかが NaN
        w = max(1, tCue) : ...
            min(tCue + round(Prm.Excl.WinSec * X.FrameRate), numel(isNanBottom)) ;

        TT.HasBottom(i)       = true ;
        TT.NNanInWinBottom(i) = sum(isNanBottom(w)) ;
    end
end

TT.BottomOK = TT.HasBottom & TT.NNanInWinBottom == 0 ;
```

- データの読み込みは被験者ごとに 1 回だけ（試行ごとに読むと遅い）
- `TrialTable.Trial` は `DataArray` の行番号なので、`DataArray(Trial, 条件の番号)` で同じ試行が取れる
- 窓 `w` の作り方は `m3_analyze_single_trial.m` の除外基準①（`wTop`）と同じ。合図の時点から 2 s、記録の終わりを超えないように `min` で切る
- x3 のマーカーは x2 で 10 フレーム以下の欠損が補間済みなので、ここで数える NaN は 10 フレームより長い欠損だけ
- `HasBottom` が false の試行は `NNanInWinBottom` が NaN のまま。`NaN == 0` は false なので、`BottomOK` も false になる

#### ④ 抜き出す・数を確かめる・保存する

```matlab
UseTrials = TT(TT.UseTop & TT.BottomOK, :) ;

fprintf('top を使う試行 %d、そのうち bottom も使える %d\n', ...
    sum(TT.UseTop), height(UseTrials)) ;

% 被験者 × 条件 × CueText ごとの数
Summary = groupsummary(TT(TT.UseTop, :), {'Subject', 'Condition', 'CueText'}, 'sum', 'BottomOK') ;
Summary = renamevars(Summary, {'GroupCount', 'sum_BottomOK'}, {'nTop', 'nBottomOK'}) ;

cols = {'Subject', 'Condition', 'Trial', 'CueText', 'UseTop', 'IsBadTop', 'KeepTop', ...
        'NNanInWinTop', 'HasBottom', 'NNanInWinBottom', 'BottomOK'} ;
writetable(TT(:, cols), fullfile(outDir, 'top_bottom_trials.csv')) ;
writetable(Summary,     fullfile(outDir, 'top_bottom_summary.csv')) ;
save(fullfile(outDir, 'UseTrials.mat'), 'UseTrials') ;
```

- `UseTrials` は `TrialTable` の全部の列を持ったまま行だけを絞った表。下流の解析では `load('output/UseTrials.mat')` で読み、`Subject`・`Condition`・`Trial` で x3 のマーカーを取り出す
- `groupsummary` の `sum` で、論理値の `BottomOK` の true の数を数える。`GroupCount` がそのグループの top を使う試行数になる
- 実行すると「top を使う試行 551、そのうち bottom も使える 506」と出る（6 節と同じ）

## 6. 事前の確認の結果（2026-11-12）

作業用フォルダで、2 節の基準で数えた結果（プロジェクトのファイルは変えていない）。コードを書いたら、同じ数になるかで確かめる。

| 項目 | 値 |
|---|---|
| top を使っている試行 | 551 試行 |
| そのうち bottom も使える | **506 試行（91.8%）** |
| 目視で残した（k）試行 | 31 試行、そのうち bottom も使える 4 試行 |

bottom が使えない 45 試行の内訳：

- **S01**：free 13 試行中 12、gonogo 14 試行中 11（Go 6・NoGo 5）、gostop 2（Go T3、Stop T14）、simple 1（T9）
- **S04**：simple 4 試行すべて、free 7 試行中 5、gostop の Go 8 試行中 5、gostop の Stop 1（T12）、gonogo の Go 1（T2）
- **S02**：3 試行（free T15、gostop T5・T14）
- **S03、S05〜S10**：すべて使える

top が欠けて目視で残した（k）試行では、bottom も欠けていることが多い。S04 の Simple は bottom を使うと 0 試行になる。

## 7. 注意

- 窓の中の欠損を 1 フレームでも許さない基準なので、少しの欠損で外れる試行もある（S01 free T4 は 5 フレーム、S02 gostop T14 は 3 フレーム）。基準をゆるめるかは、使う解析に合わせて決める
- x8 の `IsShortRT`（RT < 150 ms）は Go 試行にしか付かない。Stop 試行の RT を使うときは別に除く（2026-11-11 のログ）
