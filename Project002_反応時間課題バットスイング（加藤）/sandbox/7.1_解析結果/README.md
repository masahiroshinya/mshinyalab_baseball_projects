## 置き場所の決まり

- スクリプトは、自分のフォルダからの相対パスで Project002 のフォルダやデータを探す。`<指標>/<ツール>/xxx.m` の深さ（`plot_by_condition.m` だけは `<指標>/xxx.m`）を変えると動かなくなるので、移すときは深さをそろえる。
- `top_phase_viewer` は `top_trajectory_3d` のキャッシュを読むので、2 つは同じフォルダに置く。
- 2026-10-29 以前のログ（`log/`）に書かれたパスは、並べ替える前の日付フォルダのもの。
