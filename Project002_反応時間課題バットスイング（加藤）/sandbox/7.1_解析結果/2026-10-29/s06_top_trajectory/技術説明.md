# S06 の top 軌道（各条件の代表 1 試行）を Affinity で仕上げた図（技術説明）

作成：2026-10-29　加藤 和太郎（student）、Claude Code

## 1. 目的

S06 のバット先端（top マーカー）の軌道を、各条件 1 試行ずつ重ねて描き、Affinity で見やすく仕上げて書き出す（発表・論文の図の下書き）。

## 2. 成果物（`figure/`）

| ファイル | 中身 |
| --- | --- |
| `s06_top_trajectory.af` | Affinity の文書（レイヤー名付き。文字・線・印は個別に編集できる） |
| `s06_top_trajectory.pdf` | ベクターの PDF（Affinity のプリセット「PDF(書き出し用)」） |
| `s06_top_trajectory.png` | PNG（300 dpi、2056 × 2032 px） |
| `s06_top_trajectory_src.svg` | Affinity に読み込んだ元の SVG（Python で作図） |

大きさは 174 × 172 mm（A4 の本文幅に近い）。文字はヒラギノ角ゴシック。

`data/s06_data.json` は、MATLAB で選んだ 4 試行の軌道と時点（5 節のコード 1 の出力）。

## 3. 図の内容

| パネル | 何を描くか |
| --- | --- |
| A | 上から見た軌道（X：投手方向、Y：左右）。Onset の位置を原点にした |
| B | 横から見た軌道（X：投手方向、Z：上下） |
| C | 投手方向の位置 X と時間（Onset を 0 s） |
| D | 局面の時間（ms）の積み上げ棒。① Onset → 引き始め、② 引き始め → 最も捕手側、③ 最も捕手側 → ピーク速度。右の数は ①+②+③（MT） |

- 印：○ Onset、▲ 引き始め、● 最も捕手側、★ ピーク速度（決め方は [top_phase_viewer](../../2026-10-28/top_phase_viewer/技術説明.md) の 2 節と同じ）
- 太い線は Onset → ピーク速度、細い薄い線はピーク速度から 0.1 s 後まで
- 色：Free 灰、Simple 青、Go/No-go 橙、Go/Stop 赤（これまでのツールと同じ）
- 局面の名前は、「フック」などの呼び方を使わず、区切りの出来事で書いた（[top_phase_viewer](../../2026-10-28/top_phase_viewer/技術説明.md) の 9 節）

### 3.1 代表試行の選び方

各条件で、S06 の試行（x8 の除外のあと。Free 15・Simple 15・Go/No-go 10・Go/Stop 9 試行）の ①②③ の時間を z 得点にし、条件平均からの距離（3 つの z の二乗和の平方根）が最も小さい試行を選んだ。x3 の top に欠損（NaN）がある試行は選ばない（S06 には該当なし）。

| 条件 | Trial | ① | ② | ③ | MT（①+②+③） | S06 の条件平均（① / ② / ③ / MT） |
| --- | --- | --- | --- | --- | --- | --- |
| Free | 8 | 580 | 192 | 52 | 824 | 569 / 193 / 54 / 815 |
| Simple | 10 | 324 | 192 | 56 | 572 | 327 / 197 / 54 / 578 |
| Go/No-go | 3 | 356 | 188 | 52 | 596 | 338 / 188 / 54 / 579 |
| Go/Stop | 5 | 436 | 176 | 52 | 664 | 476 / 172 / 52 / 701 |

（ms。マーカーのフレーム 250 Hz から求めたので 4 ms 刻み。x8 の MT_ms とは 1〜2 ms 違う）

## 4. 図から読み取れること（S06）

- **① の長さだけが条件で違う**：① は Free 580・Go/Stop 436・Go/No-go 356・Simple 324 ms。② は 176〜192 ms、③ は 52〜56 ms でほぼ同じ（D）。全体の傾向（top_phase_viewer の 3.1 節）と同じ
- **Free と Go/Stop は ▲ が投手側に遠い**：引き始めの X は Free 0.30・Go/Stop 0.31 m、Simple 0.17・Go/No-go 0.20 m（A・C）
- **Free は ● が浅い**：最も捕手側の X は Free −0.50 m、Simple −0.66 m（A・B）
- ★（ピーク速度）の位置と、そこまでの軌道の形（B の下側の弧）は 4 条件でよく似ている

1 名・各 1 試行の図なので、条件差の根拠にはしない（例を見せる図として使う）。

## 5. 作り方

1. **MATLAB**（コード 1）：top_trajectory_3d のキャッシュから S06 の試行を取り出し、①②③ を計算して代表試行を選ぶ。`s06_data.json` に書き出す
2. **Python**（コード 2）：`python3 make_svg.py s06_data.json s06_top_trajectory_src.svg` で SVG を作る。`<g id="...">` がそのまま Affinity のレイヤー名になる（「A_上から見た軌道」→「A_上から見た軌道_Free」など）
3. **Affinity**（コード 3）：SVG を読み込み、解像度を 300 dpi にして、.af で保存、PDF・PNG で書き出す。AI が Affinity の MCP サーバー（6 節）からスクリプトを実行した
4. デスクトップにできたファイルを `figure/` にコピーした

手で直したいとき（文字の位置・色など）は、`figure/s06_top_trajectory.af` を Affinity で開いて直し、PDF・PNG を書き出し直す。データを変えたときは 1 からやり直す。

## 6. Affinity を AI から操作する方法（MCP）

Affinity（by Canva、3.3.1）には MCP サーバーが入っていて、起動していると `http://[::1]:6767/sse`（SSE 方式）で待ち受ける。Claude Code には MCP として登録していないので、コード 4 の小さなクライアントで接続した。

- ツール：`execute_script`（JavaScript を実行）、`render_spread`（画面を JPEG で返す）、`read_sdk_documentation_topic` など。最初に `preamble` を読まないとスクリプトを実行できない
- SDK は `/Applications/Affinity.app/Contents/Resources/JSLib/` にある（`require('/document.js')` の形で読む）
- **ファイルの読み書きはデスクトップだけ**。プロジェクトのフォルダには直接保存できないので、デスクトップに書き出してからコピーする

## 7. トラブルシューティング

| 起きたこと | 原因 | 対処 |
| --- | --- | --- |
| `Application.getUserDesktopPath is not a function` | 古い名前（getter で、関数ではない） | `Application.userDesktopPath` を使う |
| `Cannot read properties of undefined (reading 'allPresetNames')` | `FileExportOptions` は `exportconfig.js` ではなく `document.js` にある | `require('/document.js')` から読む |
| `Cannot read properties of undefined (reading 'create')`（DocumentProperties） | `DocumentProperties` は `document.js` ではなく `documentproperties.js` にある | `require('/documentproperties.js')` から読む |
| SVG を開くと 72 dpi（PNG が 493 px 幅と小さい） | SVG の読み込みの既定値 | `DocumentProperties` の `dpi = 300` を `setDocumentProperties` で当てる。寸法（mm）は変わらず、ピクセル数だけが増える |
| D の凡例が下の注記と重なった・注記が右にはみ出した | 図の高さが足りない、1 行が長い | 高さを 166 → 172 mm にし、注記を 2 行に分けた（`render_spread` で確かめた） |

### コード 1：代表試行を選ぶ（s06_pick.m、MATLAB）

```matlab
root = '/Users/watarokato/mshinyalab_baseball_projects/Project002_反応時間課題バットスイング（加藤）' ;
ana  = fullfile(root, 'Experiments', 'Main experiments', '03_Analysis') ;
C = load(fullfile(root, 'sandbox/7.1_解析結果/2026-10-28/top_trajectory_3d/cache/top_trajectory_cache.mat')) ;
Tr = C.Traj([C.Traj.Subject] == 6) ;
S = load(fullfile(ana, 'x3_DataChecked', 'Data06.mat'), 'DataArray') ;
load(fullfile(ana, 'x8_StatTable', 'StatTable.mat'), 'TrialTable') ;
conds = {'free','simple','gonogo','gostop'} ;
fs = 250 ;
out = struct() ;
for jc = 1:4
    idx = find(strcmp({Tr.Condition}, conds{jc})) ;
    n = numel(idx) ; R = nan(n, 8) ;
    for m = 1:n
        k = idx(m) ; P = Tr(k).XYZ - Tr(k).XYZ(1,:) ; ip = Tr(k).IPeak ;
        [~, iMin] = min(P(1:ip,1)) ; [~, iMax] = max(P(1:iMin,1)) ;
        % x3 の生データの欠損（Onset 〜 ピーク + 0.1 s）
        row = TrialTable(TrialTable.Subject==6 & strcmp(string(TrialTable.Condition),conds{jc}) & TrialTable.Trial==Tr(k).Trial, :) ;
        D = S.DataArray(Tr(k).Trial, jc) ;
        i0 = max(1, round(row.SwingOnsetForce / D.AnalogFs * fs)) ;
        raw = D.Markers.top(i0:i0+size(P,1)-1, 1) ;
        R(m,:) = [Tr(k).Trial, (iMax-1)/fs*1000, (iMin-iMax)/fs*1000, (ip-iMin)/fs*1000, (ip-1)/fs*1000, sum(isnan(raw)), row.RTForce_ms, row.MT_ms] ;
    end
    fprintf('\n== %s (n=%d)  Trial ①  ②  ③  MT(top)  NaN  RT  MT(x8)\n', conds{jc}, n) ;
    disp(R)
    mu = mean(R(:,2:4), 1) ; sd = std(R(:,2:4), 0, 1) ;
    fprintf('mean ①②③ = %.0f %.0f %.0f, MT = %.0f\n', mu, mean(R(:,5))) ;
    z = (R(:,2:4) - mu) ./ sd ; dist = sqrt(sum(z.^2, 2)) ; dist(R(:,6) > 0) = Inf ;
    [~, b] = min(dist) ; fprintf('→ 代表：Trial %d（距離 %.2f）\n', R(b,1), dist(b)) ;
    k = idx(b) ; P = Tr(k).XYZ - Tr(k).XYZ(1,:) ; ip = Tr(k).IPeak ;
    [~, iMin] = min(P(1:ip,1)) ; [~, iMax] = max(P(1:iMin,1)) ;
    out.(conds{jc}) = struct('trial', R(b,1), 'xyz', P, 'iPeak', ip, 'iPull', iMax, 'iBack', iMin, ...
        'rt', R(b,7), 'mt', R(b,8), 'phase', R(b,2:4), 'n', n, 'condMean', [mu mean(R(:,5))]) ;
end
fid = fopen('s06_data.json', 'w') ; fprintf(fid, '%s', jsonencode(out)) ; fclose(fid) ;
```

import json, math, sys

def a(s): S.append(s)
def txt(x, y, s, size=2.6, anchor='start', weight='normal', fill='#000000', extra=''):
    a(f'<text x="{x:.2f}" y="{y:.2f}" font-family="{FONT}" font-size="{size}" font-weight="{weight}" '
      f'text-anchor="{anchor}" fill="{fill}" {extra}>{s}</text>')
def line(x1, y1, x2, y2, col='#000000', w=0.2, dash=None):
    ds = f' stroke-dasharray="{dash}"' if dash else ''
    a(f'<line x1="{x1:.2f}" y1="{y1:.2f}" x2="{x2:.2f}" y2="{y2:.2f}" stroke="{col}" stroke-width="{w}"{ds}/>')
def path(pts, col, w=0.35, op=1.0):
    s = 'M' + ' L'.join(f'{x:.2f},{y:.2f}' for x, y in pts)
    a(f'<path d="{s}" fill="none" stroke="{col}" stroke-width="{w}" stroke-opacity="{op}" stroke-linejoin="round" stroke-linecap="round"/>')
def marker(kind, x, y, col, r=1.0):
    st = f'fill="{col}" stroke="#FFFFFF" stroke-width="0.2"'
    if kind == 'tri':
        p = [(x, y - 1.25*r), (x + 1.1*r, y + 0.7*r), (x - 1.1*r, y + 0.7*r)]
        a(f'<path d="M{p[0][0]:.2f},{p[0][1]:.2f} L{p[1][0]:.2f},{p[1][1]:.2f} L{p[2][0]:.2f},{p[2][1]:.2f} Z" {st}/>')
    elif kind == 'dot':
        a(f'<circle cx="{x:.2f}" cy="{y:.2f}" r="{0.9*r:.2f}" {st}/>')
    elif kind == 'star':
        p = []
        for i in range(10):
            rr = 1.45*r if i % 2 == 0 else 0.6*r
            th = -math.pi/2 + i*math.pi/5
            p.append((x + rr*math.cos(th), y + rr*math.sin(th)))
        a('<path d="M' + ' L'.join(f'{u:.2f},{v:.2f}' for u, v in p) + f' Z" {st}/>')
    elif kind == 'onset':
        a(f'<circle cx="{x:.2f}" cy="{y:.2f}" r="{0.85*r:.2f}" fill="#FFFFFF" stroke="#000000" stroke-width="0.25"/>')

class Ax:
    def __init__(s, x0, y0, w, h, xr, yr):
        s.x0, s.y0, s.w, s.h, s.xr, s.yr = x0, y0, w, h, xr, yr
    def X(s, v): return s.x0 + (v - s.xr[0]) / (s.xr[1] - s.xr[0]) * s.w
    def Y(s, v): return s.y0 + s.h - (v - s.yr[0]) / (s.yr[1] - s.yr[0]) * s.h
    def axes(s, xt, yt, xl, yl, xfmt='{:g}', yfmt='{:g}', zero=True):
        a('<g id="軸">')
        if zero:
            if s.xr[0] < 0 < s.xr[1]: line(s.X(0), s.y0, s.X(0), s.y0 + s.h, '#C8C8C8', 0.15, '0.8,0.6')
            if s.yr[0] < 0 < s.yr[1]: line(s.x0, s.Y(0), s.x0 + s.w, s.Y(0), '#C8C8C8', 0.15, '0.8,0.6')
        yb = s.y0 + s.h

### コード 4：Affinity の MCP サーバーに接続する（mcp_client.py、Python 3）

`calls.json` に呼ぶツールを並べて `python3 mcp_client.py calls.json` で実行する。例：`[{"tool":"read_sdk_documentation_topic","args":{"filename":"preamble"}}, {"tool":"execute_script","args":{},"args_file":"affinity_finish.js","args_key":"script"}]`

```python
"""Affinity MCP (SSE) 最小クライアント: python3 mcp_client.py calls.json
calls.json = [{"method": "tools/list"} | {"tool": name, "args": {...}}, ...]"""
import sys, json, threading, queue, http.client

HOST, PORT = '::1', 6767
q = queue.Queue()
endpoint = queue.Queue()

def reader():
    c = http.client.HTTPConnection(HOST, PORT, timeout=600)
    c.request('GET', '/sse', headers={'Accept': 'text/event-stream'})
    r = c.getresponse()
    ev, data = None, []
    while True:
        line = r.readline()
        if not line:
            break
        line = line.decode('utf-8').rstrip('\r\n')
        if line.startswith('event:'):
            ev = line[6:].strip()
        elif line.startswith('data:'):
            data.append(line[5:].lstrip())
        elif line == '':
            if data:
                d = '\n'.join(data)
                if ev == 'endpoint':
                    endpoint.put(d)
                else:
                    try: q.put(json.loads(d))
                    except Exception: pass
            ev, data = None, []

threading.Thread(target=reader, daemon=True).start()
ep = endpoint.get(timeout=10)
nid = [0]
def send(method, params=None, notify=False):
    msg = {'jsonrpc': '2.0', 'method': method}
    if params is not None: msg['params'] = params
    if not notify:
        nid[0] += 1; msg['id'] = nid[0]
    c = http.client.HTTPConnection(HOST, PORT, timeout=30)
    c.request('POST', ep, body=json.dumps(msg), headers={'Content-Type': 'application/json'})
    c.getresponse().read()
    if notify: return None
    while True:
        m = q.get(timeout=600)
        if m.get('id') == msg['id']: return m

send('initialize', {'protocolVersion': '2024-11-05', 'capabilities': {}, 'clientInfo': {'name': 'claude-code', 'version': '1'}})
send('notifications/initialized', notify=True)
for call in json.load(open(sys.argv[1])):
    if 'method' in call:
        res = send(call['method'], call.get('params', {}))
    else:
        args = call['args']
        if 'args_file' in call:   # JS を別ファイルから読む
            args = dict(args); args[call['args_key']] = open(call['args_file']).read()
        res = send('tools/call', {'name': call['tool'], 'arguments': args})
    out = res.get('result', res)
    if isinstance(out, dict) and 'content' in out:
        for c in out['content']:
            if c.get('type') == 'image':
                import base64, os
                fn = os.environ.get('IMG', 'render') + '.jpg'
                open(fn, 'wb').write(base64.b64decode(c['data'])); print('saved', fn)
            else:
                print(c.get('text', c))
        if out.get('isError'): print('[isError]')
    else:
        print(json.dumps(out, ensure_ascii=False, indent=1))
    print('-----')
```
