## 1. 依頼

学会のポスター発表の後に、次の依頼を受けた。

> フリー条件のヘッドスピードを基準に他の条件のヘッドスピードを正規化し、対応なしで検定を行った場合の結果も拝見できればと思います。（フリー条件に対する変化率をもとに検定を行うイメージです。）

ヘッドスピードは、ポスターと修士論文の PeakVelTop（バット先端 top のピーク合成速度、m/s）とする。

## 2. 方法

### 2.1 変化率

変化率（%）＝（その条件のヘッドスピード ÷ その被験者のフリー条件の平均 − 1）× 100

- データ：`Experiments/Main experiments/03_Analysis/x8_StatTable/stat_table_trial.csv`。除外の後の Go 試行（PeakVelTop が NaN でない 455 試行。Free 140、Simple 128、Go/No-go 98、Go/Stop 89）
- 被験者 × 条件の平均は `stat_table_subject.csv` の PeakVelTop と一致する（差は 10⁻¹³ 以下）。つまり、RM-ANOVA_2026-1103 と同じ値から変化率を作っている

### 2.2 2 つの単位で検定した理由

依頼の「対応なし」には 2 通りの読み方がある。どちらを指すかが分からないので、両方を計算した。

| | A. 被験者単位 | B. 試行単位 |
|---|---|---|
| 値 | 被験者ごとの条件平均を変化率にする（1 人 1 条件 1 値、n = 10） | 試行ごとの値を、その被験者のフリーの平均で割る（455 試行） |
| フリー条件 | 全員 0%（ばらつきがない）ので、比較に入れられない。代わりに「変化率が 0 と違うか」を調べる | フリーの試行にもばらつきが残るので、4 条件を比べられる |
| 検定 | A1：1 標本 t 検定（変化率 ≠ 0）、Holm 3 組。確認用に Wilcoxon の符号付順位検定<br>A2：3 条件を対応なしで比較（一元配置分散分析、Kruskal-Wallis、対応のない t 検定 Holm 3 組）<br>A3：参考に、対応ありで比較（対応のある t 検定 Holm 3 組） | 一元配置分散分析、Kruskal-Wallis、Levene 検定、Welch の t 検定 Holm 6 組（Levene で等分散が否定されたため） |

### 2.3 正規化と「対応なし」についての注意

- **正規化で消えるのは、被験者の間の速さの違い（スケール）だけ**。各条件の値は同じ 10 人から出ているという対応は残る。実際、変化率の条件の間の相関は r = .32〜.80 と正で、対応ありで検定するほうが検出力が高い（A2 と A3 の比較）
- **B（試行単位）は、同じ人の試行を独立とみなす（擬似反復）**。被験者の数（10）ではなく試行の数（455）で自由度が決まるため、p 値が小さく出やすい。また、試行の多い被験者の重みが大きくなる（S04 は 25 試行、ほかは 41〜50 試行）
- A でフリーを比較に入れると、フリーの群は分散 0 になり t 検定が成り立たない。そのため A1 の「0 との比較」で代える（これは、フリーとの対応のある比較を比で行うことに近い）

### 3.3 試行単位の差は、被験者の数に戻すと残らない

- 同じ「Go/Stop − Simple」の比較は、被験者単位では対応ありで p = .134（p_holm = .403）、対応なしで p = .258（p_holm = .775）
- 参考に、試行単位のまま被験者を考える線形混合モデル（scratchpad の Python、statsmodels）を当てた。被験者ごとの切片だけを入れると Go/Stop − Simple は +0.89%（p_holm = .015）だが、条件の効果が被験者ごとに違うこと（ランダム傾き）を入れると p = .15 ほどになった（ただしモデルは収束しきらなかったので、値は目安）
- つまり、B の有意差は「Go/Stop で速くなる人もいれば遅くなる人もいる」（3.1 の表、図 A の線）という被験者の間のばらつきを、試行の数で打ち消した結果と考えられる

### 指標の計算の説明（先方に渡す用、案。2026-11-16）

図（6 節）の A・B・C の値の求め方を、統計の分かる読み手に向けて書いた。回答の本文か、図に添えて送る。値は 3 節と同じ。

PDF にした版（図と式を入れたもの）：`計算の説明/ヘッドスピード変化率_計算の説明.pdf`。原稿は `計算の説明/draft.md`（md を正とする）、`./convert.sh` で docx にし、Word で PDF に保存した（sandbox/6.1_Pandoc の方式）。下の文を直したときは、draft.md も合わせて直す。

> **図の各パネルの指標の計算**
>
> **共通**
> - ヘッドスピード：バット先端のマーカーの合成速度の、1 試行の中での最大値（m/s）。
> - 対象：除外の後の、スイングを最後まで行う試行（各条件の Go 試行）455 試行（参加者 10 名。Free 140、Simple 128、Go/No-go 98、Go/Stop 89 試行）。参加者あたり 41〜50 試行（1 名だけ 25 試行）。
> - 基準：参加者 s ごとの、フリー条件の全試行の平均 F_s。どの変化率も、その参加者自身の F_s で割って求めた。
> - 記号：v(s, c, i) = 参加者 s・条件 c・試行 i のヘッドスピード、V(s, c) = 参加者 s・条件 c の試行の平均。
>
> **A　参加者単位の変化率（n = 10）**
> - R(s, c) =（V(s, c) ÷ F_s − 1）× 100［%］
> - 1 名・1 条件につき 1 値。フリー条件は定義から全員 0%（分散 0）になるので比較に含めず、各条件の R が 0 と異なるかを 1 標本 t 検定で調べた（Holm 補正、3 条件）。
> - 3 条件の比較は、各条件の 10 値を独立な群とみなす一元配置分散分析（F(2, 27)）で行った（ご依頼の「対応なし」）。参考に、同じ参加者の対応を考える対応のある t 検定（Holm 補正、3 組）も行った。
> - 図：灰色の線が各参加者の R、黒丸と誤差棒が 10 名の平均 ± SD。
>
> **B　試行単位の変化率（n = 455）**
> - r(s, c, i) =（v(s, c, i) ÷ F_s − 1）× 100［%］
> - 分母は A と同じ F_s で、試行ごとに割った。フリー条件の試行も含めた（平均は定義から 0% だが、試行の間のばらつきは残る。SD 1.85%）。
> - 全参加者の試行をまとめ、試行を独立な観測とみなして、4 条件を一元配置分散分析（F(3, 451)）で比べた。Levene 検定で等分散が棄却された（p < .001）ので、対ごとの比較は Welch の t 検定（Holm 補正、6 組）で行った。
> - 図：点が各試行、黒丸と誤差棒が試行全体の平均 ± SD。
> - 注：分母は参加者の中で一定なので、参加者 s・条件 c の r の平均は、A の R(s, c) と一致する。B の条件の平均は、A の値を試行数で重みづけした平均にあたる。一方、同じ参加者の試行は独立ではない（擬似反復）。自由度が参加者の数ではなく試行の数で決まるので、p 値は小さく出やすい。
>
> **C　Go/Stop − Simple の差**
> - 参加者ごとの差：d_s =（Go/Stop の r の平均）−（Simple の r の平均）= R(s, Go/Stop) − R(s, Simple)。誤差棒は、その参加者の Go/Stop と Simple の試行から求めた Welch の t の 95% 信頼区間。試行数は参加者・条件で異なり、試行が少ないほど区間は広い（例：参加者 4 は Simple が 4 試行）。
> - T（試行単位・対応なし）：全参加者の Go/Stop の試行の平均 − Simple の試行の平均と、その Welch の 95% 信頼区間。1.00%（0.27〜1.73）。B の対ごとの比較と同じ計算で、区間には多重比較の補正をしていない。
> - P（参加者単位・対応あり）：10 名の d_s の平均と、t 分布（自由度 9）による 95% 信頼区間。1.11%（−0.42〜2.63）。A の参考の対応のある t 検定と同じ計算。
> - T と P で、差の大きさはほぼ同じだった。T の区間は試行の間のばらつきだけから求めるため、参加者によって差の向きが違うこと（d_s は −1.65〜5.67%）が区間に入らない。P の区間はこのばらつきを含むので、0 をまたいだ。
>
> 計算には MATLAB R2026a（Statistics and Machine Learning Toolbox）を用いた。

## 5. コードの案（MATLAB）

置き場所の案：`sandbox/7.1_解析結果/01_主要指標_条件別/headspeed_normalized/headspeed_normalized_stats.m`（`subject_mean_by_condition` と同じ深さ。中のパスはこの深さを前提にしている）。実行すると、コマンドウィンドウに 3 節の値が出て、`output/` に変化率の CSV 2 つ、C の差の CSV（`headspeed_diff_gostop_simple.csv`）、確認用の図（`headspeed_rate.png`：A＝被験者ごとの変化率、B＝試行ごとの変化率、C＝Go/Stop − Simple の差。横軸に被験者、右端に 2 つのまとめ方の T＝試行単位・対応なし、P＝被験者単位・対応あり）を書き出す。この図を原案として、先方に渡す図（figure-toolkit）を作る。

2026-11-16 に C の計算と図、B の点の横のずらし方を毎回同じにする `rng(0)` を加えた（先方に渡す図の原案にするため）。

2026-11-16 に、AI がこの案を scratchpad に置いた写しで（データのパスだけを書き換えて）MATLAB R2026a で実行し、3 節の値（Python で計算した値）と一致することを確かめた。Levene の p だけ、A2 で .839（MATLAB、平均からの偏差）と .841（Python の scipy、中央値からの偏差）とわずかに違うが、方法の違いで、結論は変わらない。

処理の流れ：

1. `stat_table_trial.csv` を読み、Go 試行で PeakVelTop がある試行だけを残す
2. 被験者 × 条件の平均 `V` を作り、1 列目（Free）を基準にする
3. A：`Rate = (V(:,2:4)./freeMean - 1)*100` で変化率を作り、`ttest`（0 との比較）、`anova1`・`kruskalwallis`・`ttest2`（対応なし）、`ttest`（2 条件、対応あり）を行う。p 値は最後の関数 `holm` で補正する
4. B：試行ごとに、その被験者の `freeMean` で割って変化率にし、`anova1`・`kruskalwallis`・`vartestn`（Levene）・`ttest2(..., 'Vartype', 'unequal')`（Welch）を行う
5. C：被験者ごとに Go/Stop と Simple の試行の変化率を `ttest2(..., 'Vartype', 'unequal')` で比べて差と 95% 信頼区間を求め、全試行をまとめた差（同じく Welch）と、被験者ごとの差の平均（`ttest`、対応あり）の区間も求める
6. CSV と図を書き出す

```matlab

% フリー条件に対する変化率（%）で条件を比べる。学会のポスター発表の後に受けた依頼
% 「フリー条件のヘッドスピードを基準に他の条件を正規化し、対応なしで検定した結果」への回答用。
%
% 変化率 = (その条件のヘッドスピード / その被験者のフリー条件の平均 − 1) × 100
%
% 2 つの単位で計算する（依頼の「対応なし」がどちらを指すかが分からないため）：
%   A. 被験者単位（n = 10）：被験者ごとの条件平均を変化率にする。フリーは全員 0% になるので比較に入れず、
%      A1 = 各条件の変化率が 0 と違うか（1 標本 t 検定、Holm 3 組。確認用に Wilcoxon の符号付順位検定）
%      A2 = 反応課題 3 条件の変化率の比較を対応なしで（一元配置分散分析・Kruskal-Wallis、対応のない t 検定 Holm 3 組）
%      A3 = 参考：同じ比較を対応ありで（対応のある t 検定 Holm 3 組）
%   B. 試行単位（455 試行）：試行ごとの値をその被験者のフリーの平均で割る。フリーの試行にもばらつきが残るので 4 条件を比べる。
%      一元配置分散分析・Kruskal-Wallis、Levene 検定、Welch の t 検定 Holm 6 組
%      （試行を独立とみなすので、被験者の中の試行の似かよい（擬似反復）を無視することに注意）
%
% データ：x8_StatTable/stat_table_trial.csv（x8_make_stat_table.m の出力）。除外の後の Go 試行（PeakVelTop が NaN でない試行）を使う。
%   被験者 × 条件の平均は stat_table_subject.csv の PeakVelTop と一致する。
% C. Go/Stop − Simple の差を、被験者ごと（試行から、95% 信頼区間）と、2 つのまとめ方（試行単位・対応なし／被験者単位・対応あり）で求める。
%   B の有意差が被験者単位で残らない理由（差の向きが被験者で違う）を示すため（2026-11-16 に追加）。
% 出力：output/ に変化率の CSV（被験者単位・試行単位）、C の差の CSV、図（PNG。A・B・C）

%% 準備
toolFolder = fileparts(mfilename('fullpath')) ;

outDir = fullfile(toolFolder, 'output') ;
if ~exist(outDir, 'dir'), mkdir(outDir) ; end

CondArray  = {'free', 'simple', 'gonogo', 'gostop'} ;
CondLabel  = {'Free', 'Simple', 'Go/No-go', 'Go/Stop'} ;

    for ic = 1:numel(CondArray)
        V(iS,ic) = mean(T.PeakVelTop(T.Subject == SubjectArray(iS) & T.Condition == CondArray{ic})) ;
    end
end
freeMean = V(:,1) ;

%% A. 被験者単位の変化率（n = 10）
Rate = (V(:,2:4)./freeMean - 1)*100 ; % 列 = ReactArray
fprintf('\n== A. 被験者単位の変化率（%%）、n = %d ==\n', nS) ;
for ic = 1:3
    fprintf('  %-7s %6.2f ± %.2f（最小 %.2f、最大 %.2f）\n', ReactArray{ic}, mean(Rate(:,ic)), std(Rate(:,ic)), min(Rate(:,ic)), max(Rate(:,ic))) ;
end

% A1：変化率が 0 と違うか（1 標本 t 検定、Holm 3 組）
p = zeros(3,1) ; t = zeros(3,1) ; pW = zeros(3,1) ;
for ic = 1:3
    [~, p(ic), ~, st] = ttest(Rate(:,ic)) ; t(ic) = st.tstat ;
    pW(ic) = signrank(Rate(:,ic)) ;
end
pH = holm(p) ;
fprintf('A1 変化率 ≠ 0（1 標本 t 検定、Holm 3 組）\n') ;
for ic = 1:3
    fprintf('  %-7s t(%d) = %5.2f, p = %.3f, pHolm = %.3f, d = %5.2f（Wilcoxon p = %.3f）\n', ...
        ReactArray{ic}, nS - 1, t(ic), p(ic), pH(ic), mean(Rate(:,ic))/std(Rate(:,ic)), pW(ic)) ;
end

y = Rate(:) ; g = repelem(ReactArray(:), nS) ;

    tbl{2,3}, tbl{3,3}, tbl{2,5}, pA, tblK{2,3}, tblK{2,5}, pK, pL) ;
Pairs = nchoosek(1:3, 2) ;
p = zeros(3,1) ; t = zeros(3,1) ; df = zeros(3,1) ;
for k = 1:3
    [~, p(k), ~, st] = ttest2(Rate(:,Pairs(k,1)), Rate(:,Pairs(k,2))) ; t(k) = st.tstat ; df(k) = st.df ;
end

end

% A3：参考、対応あり
fprintf('A3 参考：対応のある t 検定（Holm 3 組）\n') ;
for k = 1:3
    [~, p(k), ~, st] = ttest(Rate(:,Pairs(k,1)), Rate(:,Pairs(k,2))) ; t(k) = st.tstat ;
end
pH = holm(p) ;
for k = 1:3
    fprintf('  %s - %s：t(%d) = %5.2f, p = %.3f, pHolm = %.3f\n', ReactArray{Pairs(k,:)}, nS - 1, t(k), p(k), pH(k)) ;
end

%% B. 試行単位の変化率（全試行）
[~, iSubj] = ismember(T.Subject, SubjectArray) ;
T.Rate = (T.PeakVelTop./freeMean(iSubj) - 1)*100 ;
fprintf('\n== B. 試行単位の変化率（%%）==\n') ;
for ic = 1:4
    r = T.Rate(T.Condition == CondArray{ic}) ;
    fprintf('  %-7s n = %3d, %5.2f ± %.2f\n', CondArray{ic}, numel(r), mean(r), std(r)) ;
end
[pA, tbl] = anova1(T.Rate, T.Condition, 'off') ;
[pK, tblK] = kruskalwallis(T.Rate, T.Condition, 'off') ;
pL = vartestn(T.Rate, T.Condition, 'TestType', 'LeveneAbsolute', 'Display', 'off') ;
fprintf('  一元配置分散分析 F(%d, %d) = %.2f, p = %.3f ／ Kruskal-Wallis χ²(%d) = %.2f, p = %.3f ／ Levene p = %.3f\n', ...
    tbl{2,3}, tbl{3,3}, tbl{2,5}, pA, tblK{2,3}, tblK{2,5}, pK, pL) ;
Pairs = nchoosek(1:4, 2) ;
nP = size(Pairs, 1) ;
p = zeros(nP,1) ; t = zeros(nP,1) ; df = zeros(nP,1) ;
for k = 1:nP
    [~, p(k), ~, st] = ttest2(T.Rate(T.Condition == CondArray{Pairs(k,1)}), T.Rate(T.Condition == CondArray{Pairs(k,2)}), 'Vartype', 'unequal') ;
    t(k) = st.tstat ; df(k) = st.df ;
end
pH = holm(p) ;
for k = 1:nP
    fprintf('  Welch の t 検定 %s - %s：t(%.1f) = %5.2f, p = %.3f, pHolm = %.3f\n', CondArray{Pairs(k,:)}, df(k), t(k), p(k), pH(k)) ;
end

%% C. Go/Stop − Simple の差：被験者ごとと、2 つのまとめ方
% 被験者ごと：その被験者の Go/Stop の試行と Simple の試行の変化率の平均の差と、95% 信頼区間（Welch の t 検定の区間）。
%   差は A の Rate(:,3) − Rate(:,1) と同じ値になる。

% まとめ②（被験者単位・対応あり）：被験者ごとの差の平均と 95% 信頼区間（A3 の対応のある t 検定と同じ、n = 10）

for iS = 1:nS
    xG = T.Rate(T.Subject == SubjectArray(iS) & T.Condition == "gostop") ;

    [~, ~, ci] = ttest2(xG, xS, 'Vartype', 'unequal') ;

end
xG = T.Rate(T.Condition == "gostop") ;
xS = T.Rate(T.Condition == "simple") ;
[~, ~, ci] = ttest2(xG, xS, 'Vartype', 'unequal') ;
DiffTrial = [mean(xG) - mean(xS), ci'] ;
[~, ~, ci] = ttest(Rate(:,3) - Rate(:,1)) ;
DiffPaired = [mean(Rate(:,3) - Rate(:,1)), ci'] ;

fprintf('  被験者単位・対応あり %5.2f [%5.2f, %5.2f]\n', DiffPaired) ;

%% 書き出し：変化率の CSV
RateTable = array2table([SubjectArray(:), V, Rate], 'VariableNames', ...
    [{'Subject'}, strcat('PeakVelTop_', CondArray), strcat('Rate_', ReactArray)]) ;

writetable(T, fullfile(outDir, 'headspeed_rate_trial.csv')) ;

%% Holm の方法で p 値を補正する
function pH = holm(p)
    m = numel(p) ;
    [ps, ix] = sort(p(:)) ;
    adj = min(cummax((m - (1:m)' + 1).*ps), 1) ;
    pH = zeros(m, 1) ;
    pH(ix) = adj ;
end
```

## 9. Holm 補正のせいで差が見えにくくなっていないか（2026-11-17）

「RM-ANOVA の後の Holm 補正で、差が検出しにくくなっているのでは」という指摘への確認。新しい S04 の `stat_table_subject.csv` の PeakVelTop（生の値、m/s、n = 10）で、補正をしない p と並べた（scratchpad の Python、scipy。対応のある t 検定、RM-ANOVA は Greenhouse-Geisser 補正）。

| | 主効果（RM-ANOVA） | 差が最大の組 | 補正なしの p | p_holm |
|---|---|---|---|---|
| 4 条件（Free を含む、6 組） | F(2.48, 22.35) = 0.69、p = .542、ηp² = .07 | Go/No-go − Go/Stop（−0.26 m/s） | .123 | .738 |
| 3 条件（反応課題だけ、3 組） | F(1.96, 17.67) = 1.36、p = .281、ηp² = .13 | 同上 | .123 | .369 |

- Holm 補正は事後の対比較の p にかけるもので、**RM-ANOVA の主効果の p には関係しない**。主効果がすでに有意でない（p = .54）
- **補正をしなくても、どの組も p < .05 にならない**（最小 .123）。Holm を外しても、比べる組を減らしても結論は変わらない
- 差が出ない主な理由は補正ではなく、条件の間の差（最大 0.26 m/s、1% 未満）が被験者の間の差のばらつき（差の SD 約 0.47 m/s）より小さいこと。n = 10 の対応のある t 検定で検出力 80% にするには dz ≈ 1（ここでは約 0.47 m/s、1.5% ほど）の差が必要
