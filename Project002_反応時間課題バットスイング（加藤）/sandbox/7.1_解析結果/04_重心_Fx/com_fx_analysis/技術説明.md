# 床反力から重心の前後の移動を求め、top の「最も捕手側」と比べる（技術説明）

作成：2026-11-03　加藤 和太郎（student）、Claude Code

## 1. 目的

Free・Go/Stop では、バット先端（top）が「最も捕手側（●）」に来たときの X が浅い（[top_phase_viewer](../../03_top軌道_MT局面/top_phase_viewer/技術説明.md) の 3.1 節、[s06_top_trajectory](../../03_top軌道_MT局面/s06_top_trajectory/技術説明.md) の 4 節）。浅い理由として、次の 2 つが考えられる（2026-11-03 のログ、やり取り 3）。

1. 体が投手方向へ突っ込んでいる（体ごと前に出ている）
2. バットが体の近くを回っている（体に対するバットの位置が違う）

身体マーカー（手部・腰部）は、これまでの 10 名ではうまく取れておらず信用できないので、**床反力**から重心の前後の動きを求めて、2 つを分ける。

## 2. 考え方

● の時点の top の X（Onset の位置を 0）を、2 つに分ける。

> top の X ＝ 重心の移動量 ＋ 重心に対する top の X（top − 重心）

| 浅い理由 | 重心の移動量 | top − 重心 |
| --- | --- | --- |
| 1. 体が突っ込む | Free・Go/Stop で大きい | 条件で変わらない |
| 2. バットが体の近くを回る | 条件で変わらない | Free・Go/Stop で浅い |

## 3. 計算の方法

### 3.1 重心の前後の位置（床反力）

| 手順 | 内容 |
| --- | --- |
| Fx | `Force1(:,1) + Force2(:,1)`（2 枚の板の前後方向の和）を 50 Hz の 2 次 Butterworth で filtfilt（m3・fx_onset_viewer と同じ） |
| 加速度 | （Fx − キュー前 0.5 s の Fx の中央値）÷ 質量。質量は x8 の `BWest_N` ÷ 9.81（バットを持った体重） |
| 速度・位置 | キューの時点を速度 0・位置 0 として、`cumtrapz` で 2 回積分する |
| Onset を 0 | top と同じく、Onset の時点の重心の位置を引く |

静止して立っているとき、体にかかる前後の力の合計は 0 なので、キュー前の Fx の中央値は板のずれ（オフセット）とみなして引く。

### 3.2 top の 3 つの時点

[top_phase_viewer](../../03_top軌道_MT局面/top_phase_viewer/技術説明.md) の 2 節と同じ決め方。top・knob の前処理（NaN の線形補間 → 30 Hz の filtfilt）は top_trajectory_3d と同じ。

| 時点 | 決め方 |
| --- | --- |
| ▲ 引き始め | Onset 〜 最も捕手側の間で、top の X が最も大きい時点 |
| ● 最も捕手側 | Onset 〜 ピーク速度の間で、top の X が最も小さい時点 |
| ★ ピーク速度 | x8 の `TPeakVelTop` |

マーカー（250 Hz）のフレームを床反力（1000 Hz）のサンプルに直すときは、`round(フレーム ÷ 250 × 1000)` とする（top_trajectory_3d の Onset の直し方の逆）。

### 3.3 試行の選び方

x8 で残った Go 試行（`PeakVelTop` と `SwingOnsetForce` がある）。x8 の除外のあとなので、除外基準に引っかかっても目視で残した試行（Mark = k）は入る。

**S04 は、すべての解析に含める**（2026-11-03 の決定）。S04 は x8 と同じく、問題のない試行と k の試行をどちらも使う（Free 7・Simple 4・Go/No-go 6・Go/Stop 8 試行。うち k は 5・4・3・5 試行で、Simple はすべて k）。S03 は 2026-11-03 に再測定するので、それまでは除外基準に引っかかった試行を目視の判断に関係なく外す（`StrictSubjects = 3`）。top_trajectory_3d・top_phase_viewer は `StrictSubjects = [3 4]` で S04 の k の試行を外しているので、S04 の試行はこれらと違う。

### 3.4 出す値（1 行 1 試行）

| 列 | 内容 |
| --- | --- |
| `TPull_ms`・`TBack_ms`・`TPeak_ms` | ▲●★ の時刻（Onset から）[ms] |
| `TopX_Pull`・`TopX_Back`・`TopX_Peak` | ▲●★ の top の X（Onset を 0）[m] |
| `ComX_Pull`・`ComX_Back`・`ComX_Peak` | ▲●★ の重心の X（Onset を 0）[m] |
| `KnobX_Pull` | ▲ の knob の X（Onset を 0）[m]。Fx の向きの確認に使う |
| `ComV_Back` | ● の重心の前後の速度 [m/s] |
| `TopRelCom_Back` | ● の top − 重心（`TopX_Back − ComX_Back`）[m] |
| `ComX_Pre` | キュー前 0.5 s を同じように積分したときの移動量 [m]。積分の誤差の目安 |
| `Brake_BWs` | 踏み込み足の接地 → ★ の、負の Fx の力積 [BW·s]。前への動きを止める大きさ |

## 6. 結果（S06、2026-11-03）

作業用フォルダでコード案を実行した結果（49 試行：Free 15・Simple 15・Go/No-go 10・Go/Stop 9）。▲●★ の時刻は [s06_top_trajectory](../../03_top軌道_MT局面/s06_top_trajectory/技術説明.md) の 3.1 節の条件平均と一致した。

| 条件 | ● の top (m) | ● の重心 (m) | ● の top − 重心 (m) | ▲ の重心 (m) | ▲ の knob (m) | ● の重心の速度 (m/s) | ブレーキの力積 (BW·s) |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Free | −0.505 | 0.175 | −0.680 | 0.098 | 0.191 | 0.04 | −0.073 |
| Simple | −0.656 | 0.108 | −0.764 | 0.044 | 0.098 | 0.03 | −0.063 |
| Go/No-go | −0.645 | 0.109 | −0.754 | 0.049 | 0.104 | 0.02 | −0.065 |
| Go/Stop | −0.565 | 0.124 | −0.689 | 0.073 | 0.177 | −0.03 | −0.067 |

- **Fx の向き**：▲ までの重心と knob の移動量は同じ向き（正 = 投手方向）で、相関は r = 0.77。knob のほうが約 2 倍大きい（手は重心より前へ出る）
- **積分の誤差の目安**：キュー前 0.5 s の移動量は、絶対値の中央値 4.5 mm、最大 26.3 mm

### 6.1 読み取れること（S06）

- ● が Simple より浅い分は Free 0.151 m・Go/Stop 0.091 m。このうち重心の移動で説明できるのは、Free 0.067 m（約 4 割）、Go/Stop 0.016 m（約 2 割）。残りは top − 重心 の違い（Free 0.084 m・Go/Stop 0.075 m 浅い）
- Free は、体が前に出ること（1）と、体に対するバットの位置の違い（2）の両方がありそう。Go/Stop は主に 2
- ● の時点の重心の速度は、どの条件もほぼ 0（−0.03〜0.04 m/s）。前への移動は ● までに止まっていて、違うのは止まるまでに前へ出た量
- 接地 → ★ のブレーキの力積は、条件でほぼ同じ（−0.063〜−0.073 BW·s）

1 名の結果なので、全体の傾向とは扱わない。

## 7. 注意すること

- **重心であって、骨盤や手ではない**：top − 重心 には、腕の位置・体幹の回旋・バットの向きがすべて入る。床反力だけでは、これ以上は分けられない
- **積分の誤差は時間の 2 乗で大きくなる**：基準値が δ N ずれると、t 秒後の位置は ½ × δ / 質量 × t² ずれる（75 kg、δ = 1 N で、t = 0.75 s なら 4 mm、1.3 s なら 11 mm）。Free はキュー → ● の時間が長い（S06 で約 1.3 s、Simple は約 0.75 s）ので、**Free にだけ偏った誤差が入りうる**。キュー前の体の揺れ（速度 0 の仮定のずれ）も同じように効く
- **重心にはバットも入る**：BWest_N はバットを持った体重。バット（0.9 kg）が 0.8 m 動いても、重心は約 1 cm しか動かないので、影響は小さい
- **Go/Stop に、重心がほとんど前へ動かない試行が 1 つある**（左の図の一番下の赤い線。▲ の重心 ≈ 0.005 m、knob ≈ 0.18 m）。踏み込み足が板からはみ出していないかなど、床反力の記録を個別に確認する
- **床反力の記録が ★ まで届かない試行は飛ばす**（注意を出す）。S06 では該当なし

## 8. 次の候補

- S04 を含む 9 名（`Subjects = [1 2 4:10]`）で計算し、被験者平均で条件を比べる。S06 で見えた「Free は 1 と 2 の両方、Go/Stop は主に 2」が全体でも言えるかを確かめる
- top − 重心 を、信用できるバットのマーカーで分ける：（knob − 重心：手の位置）＋（top − knob：バットの向き）。「手が体の近くにある」のか「バットの倒れ方が違う」のかを見る

## 9. コード（com_fx_analysis.m）

- **設定・試行を選ぶ**：調べる被験者、色、フォルダ。x8 の TrialTable から試行を選ぶ
- **床反力**：Fx を積分して重心の位置・速度を出す。キュー前 0.5 s の積分（誤差の目安）、踏み込み足の接地も求める
- **マーカー**：top から ▲●★ を決め、その時点の top・重心・knob の X を取り出す
- **集計・図・保存**：条件ごとの平均（被験者ごとの平均の平均）をコマンドウィンドウに出し、3 つの図を描いて、CSV と PNG を `output/` に保存する
- **ローカル関数** `prepMarker`：マーカーの NaN の補間・ローパス・m への換算

```matlab
% com_fx_analysis.m
%
% 前後方向の合成床反力 Fx を 2 回積分して重心の前後（X）の移動量を求め、
% バット先端（top）の 3 つの時点（▲ 引き始め、● 最も捕手側、★ ピーク速度）で比べる。
%   ● の top の X（Onset を 0）＝ 重心の移動量 ＋ 重心に対する top の X
%   体が突っ込むなら前者が、バットの回り方が違うなら後者が、条件で変わるはず
%
% 計算：
%   Fx     = Force1(:,1) + Force2(:,1) を 50 Hz の 2 次 Butterworth で filtfilt（m3 と同じ）
%   加速度 = (Fx − キュー前 0.5 s の中央値) / 質量（BWest_N / g）
%   キューで速度 0・位置 0 として 2 回積分（cumtrapz）
%   top・knob：NaN を線形補間 → 30 Hz で filtfilt（top_trajectory_3d と同じ）
%   ▲●★ の決め方は top_phase_viewer と同じ
% 確かめること：
%   Fx の向き   ① の間の重心の移動量と knob の移動量が同じ向きか（右の図）
%   積分の誤差  キュー前 0.5 s を同じように積分した移動量 ComX_Pre（静止していれば 0 に近い）
%
% 2026-11-03

%% 設定
Subjects       = 6 ;        % 調べる被験者（例：[1 2 4:10]）
StrictSubjects = 3 ;        % 除外基準に引っかかった試行を、目視の判断に関係なく外す被験者（S04 は含める）
g        = 9.81 ;
PostSec  = 0.1 ;            % 図に描く区間：Onset 〜 ピーク速度 + PostSec
ConditionNameArray = {'free', 'simple', 'gonogo', 'gostop'} ;
ConditionLabel     = {'Free', 'Simple', 'Go/No-go', 'Go/Stop'} ;
ConditionColor     = [0.40 0.40 0.40 ;    % free    灰
                      0.00 0.45 0.70 ;    % simple  青
                      0.90 0.62 0.00 ;    % gonogo  橙
                      0.80 0.20 0.20] ;   % gostop  赤

scriptFolder   = fileparts(mfilename('fullpath')) ;
projectFolder  = fullfile(scriptFolder, '..', '..', '..', '..') ;   % Project002 のフォルダ
analysisFolder = fullfile(projectFolder, 'Experiments', 'Main experiments', '03_Analysis') ;
outFolder      = fullfile(scriptFolder, 'output') ;
addpath(analysisFolder) ;   % parameters.m
Prm = parameters ;

%% 試行を選ぶ（x8 の除外のあと。StrictSubjects だけ k の試行も外す）
load(fullfile(analysisFolder, 'x8_StatTable', 'StatTable.mat'), 'TrialTable') ;
T = TrialTable(TrialTable.IsGo & ~isnan(TrialTable.PeakVelTop) & ~isnan(TrialTable.SwingOnsetForce) ...
    & ismember(TrialTable.Subject, Subjects), :) ;
T.IsFlagged = T.IsBadTop | T.IsBadOnset | T.IsShortRT | T.IsBadGRF | T.ExclTop | T.ExclRT | T.ExclGRF ;
T = T(~(T.IsFlagged & ismember(T.Subject, StrictSubjects)), :) ;

%% 試行ごとに計算する
VarNames = {'TPull_ms', 'TBack_ms', 'TPeak_ms', ...            % ▲●★ の時刻（Onset から）
            'TopX_Pull', 'TopX_Back', 'TopX_Peak', ...         % top の X（Onset を 0）[m]
            'ComX_Pull', 'ComX_Back', 'ComX_Peak', ...         % 重心の X（Onset を 0）[m]
            'KnobX_Pull', ...                                  % knob の X（Onset を 0）[m]（向きの確認用）
            'ComV_Back', ...                                   % ● の重心の速度 [m/s]
            'TopRelCom_Back', ...                              % 重心に対する top の X（● の TopX − ComX）[m]
            'ComX_Pre', ...                                    % キュー前 0.5 s の積分の移動量 [m]（誤差の目安）
            'Brake_BWs'} ;                                     % 接地 → ★ の負の Fx の力積 [BW·s]
nT    = height(T) ;
V     = NaN(nT, numel(VarNames)) ;
Curve = cell(nT, 1) ;   % 重心の X（Onset を 0）と ▲●★ の位置。図に使う

for iSubject = unique(T.Subject)'
    fprintf('S%02d の x3 を読み込み中...\n', iSubject) ;
    S = load(fullfile(analysisFolder, 'x3_DataChecked', sprintf('Data%02d.mat', iSubject)), 'DataArray') ;

    for r = find(T.Subject == iSubject)'
        iCondition = find(strcmp(ConditionNameArray, T.Condition(r))) ;
        Data = S.DataArray(T.Trial(r), iCondition) ;
        fsA  = Data.AnalogFs ;
        fsM  = Data.FrameRate ;
        toA  = @(f) round(f / fsM * fsA) ;   % マーカーのフレーム → アナログのサンプル（top_trajectory_3d の逆）

        % ---- 床反力：Fx → 重心の X ----
        tCue      = find(Data.LEDData(:,2) > Prm.Cue.GoThresholdV, 1, 'first') ;
        lastValid = find(~any(isnan(Data.Force1), 2) & ~any(isnan(Data.Force2), 2), 1, 'last') ;
        [bR, aR]  = butter(2, Prm.RT.FxFc/(fsA/2)) ;
        F1f = filtfilt(bR, aR, Data.Force1(1:lastValid, :)) ;
        F2f = filtfilt(bR, aR, Data.Force2(1:lastValid, :)) ;
        fx  = F1f(:,1) + F2f(:,1) ;
        fz2 = F2f(:,3) ;

        iBase  = tCue - round(Prm.RT.BaseSec * fsA) : tCue - 1 ;
        fxBase = median(fx(iBase)) ;
        acc    = (fx - fxBase) / (T.BWest_N(r) / g) ;        % [m/s^2]
        v = NaN(size(acc)) ;  d = NaN(size(acc)) ;
        v(tCue:end) = cumtrapz(acc(tCue:end)) / fsA ;        % キューで速度 0
        d(tCue:end) = cumtrapz(v(tCue:end))   / fsA ;        % キューで位置 0
        dPre = cumtrapz(cumtrapz(acc(iBase)) / fsA) / fsA ;  % キュー前 0.5 s を同じように積分

        fz2Base = median(fz2(iBase)) ;
        tFC = find(fz2(tCue:end) > fz2Base + Prm.RT.FootContactN, 1, 'first') + tCue - 1 ;

        % ---- マーカー：top・knob ----
        top  = prepMarker(Data.Markers.top,  fsM, Prm.Fc) ;
        knob = prepMarker(Data.Markers.knob, fsM, Prm.Fc) ;
        iOn  = max(1, round(T.SwingOnsetForce(r) / fsA * fsM)) ;
        iPk  = T.TPeakVelTop(r) ;
        if iPk <= iOn, continue, end
        P = top(iOn:iPk, 1) - top(iOn, 1) ;
        [~, kBack] = min(P) ;              % 最も捕手側
        [~, kPull] = max(P(1:kBack)) ;     % 引き始め
        ev  = iOn - 1 + [kPull, kBack, iPk - iOn + 1] ;   % ▲ ● ★（フレーム）
        sOn = toA(iOn) ;
        sEv = toA(ev) ;
        if sEv(3) > lastValid
            fprintf(2, '  （注意）S%02d %s Trial %d：床反力の記録がピーク速度まで届かないので飛ばします\n', ...
                iSubject, T.Condition(r), T.Trial(r)) ;
            continue
        end

        topX  = top(ev, 1)' - top(iOn, 1) ;
        comX  = d(sEv)' - d(sOn) ;
        knobX = knob(ev(1), 1) - knob(iOn, 1) ;
        if isempty(tFC), brake = NaN ;
        else, brake = sum(min(fx(tFC:sEv(3)) - fxBase, 0)) / fsA / T.BWest_N(r) ; end

        V(r,:) = [(ev - iOn) / fsM * 1000, topX, comX, knobX, v(sEv(2)), topX(2) - comX(2), dPre(end), brake] ;

        sEnd = min(lastValid, sEv(3) + round(PostSec * fsA)) ;
        Curve{r} = struct('t', (0:sEnd-sOn)' / fsA, 'x', d(sOn:sEnd) - d(sOn), 'iEv', sEv - sOn + 1) ;
    end
    clear S
end

Res = [T(:, {'Subject', 'Condition', 'Trial'}), array2table(V, 'VariableNames', VarNames)] ;
keep  = ~isnan(Res.TPeak_ms) ;
Res   = Res(keep, :) ;
Curve = Curve(keep) ;

%% 条件ごとの平均（被験者ごとの平均の平均）
G = groupsummary(Res, {'Subject', 'Condition'}, 'mean', VarNames) ;
fprintf('\n条件ごとの平均（%s、被験者ごとの平均の平均）。長さは m、時間は ms\n', ...
    strjoin(compose('S%02d', unique(Res.Subject)'), '・')) ;
fprintf('%-9s %3s | %5s %5s %5s | %6s %6s %6s | %6s %6s %6s | %6s %6s | %6s %7s\n', ...
    '条件', 'n', '▲', '●', '★', 'top●', '重心●', '差●', '重心▲', 'knob▲', '重心★', ...
    'v●', '力積', 'Pre', '') ;
for ic = 1:numel(ConditionNameArray)
    Gc = G(string(G.Condition) == ConditionNameArray{ic}, :) ;
    m  = @(c) mean(Gc.(['mean_' c])) ;
    fprintf('%-9s %3d | %5.0f %5.0f %5.0f | %6.3f %6.3f %6.3f | %6.3f %6.3f %6.3f | %6.2f %6.3f | %6.4f\n', ...
        ConditionLabel{ic}, sum(Gc.GroupCount), m('TPull_ms'), m('TBack_ms'), m('TPeak_ms'), ...
        m('TopX_Back'), m('ComX_Back'), m('TopRelCom_Back'), m('ComX_Pull'), m('KnobX_Pull'), m('ComX_Peak'), ...

function x = prepMarker(x, fs, fc)
% NaN を線形補間して、2 次 Butterworth で filtfilt し、m に直す（top_trajectory_3d と同じ）
t = (1:size(x,1))' ;
for col = 1:3
    nanIdx = isnan(x(:,col)) ;
    if any(nanIdx) && any(~nanIdx)
        x(nanIdx,col) = interp1(t(~nanIdx), x(~nanIdx,col), t(nanIdx), 'linear', 'extrap') ;
    end
end
[b, a] = butter(2, fc/(fs/2)) ;
x = filtfilt(b, a, x) / 1000 ;
end
```
