# HT と 2 回目の刺激の関係（技術説明）

作成：2026-11-09　加藤 和太郎（student）、Claude Code

## 1. 目的

「Go/Stop で HT が延びるのは、2 回目の刺激を判断するための時間か」を、x8 の値（RT・HT・LT）だけで調べる。マーカーは読まない。

## 2. 考え方と計算の方法

Go/Stop では、2 回目の刺激は 1 回目の Go の 350 ms 後に点く。振り始め（Onset）は Go の RT ms 後なので、**Onset から 2 回目の刺激までは 350 − RT ms**（以下 Pre）。

```
Go cue        Onset          2回目の刺激                 HT の終わり
  |--- RT ---|---- Pre ----|--------- Post ---------|
             |<------------------ HT --------------->|
```

### 2.1 試行ごと：HT の終わりは 2 回目の刺激に合わせて決まっているか

2 回目の刺激を待ってから HT を終えるなら、振り始めが遅い試行（RT が長い試行）ほど、刺激までの時間が短いので HT が短くなる。つまり、被験者ごとに HT を RT で回帰した傾きが **−1 に近くなる**。また、HT の終わりのばらつき（被験者内 SD）は、Onset 基準より **Go cue 基準のほうが小さくなる**。

比べるために、2 回目の刺激がない Simple・Go/No-go も同じように計算する（傾きは 0 になるはず）。

### 2.2 被験者平均：2 回目の刺激の前と後

Go/Stop の HT を、Pre と Post（= HT − Pre）に分け、次の 3 つと比べる。

| 比べるもの | 意味 |
|---|---|
| Simple の HT | 2 回目の刺激から HT をやり直した場合の、刺激の後の HT |
| Simple の HT − Pre | **Simple と同じペースで HT を進めた**（刺激を待たない）場合に、刺激の後に残る HT |
| Go/Stop の RT | 2 回目の刺激を処理するのにかかる時間の目安 |

```
① Simple と同じペースで進めた（刺激を待たない）
  |---- Pre 111 ----|---- 162 ----|            → HT 273 ms（Simple と同じ）
② 刺激の前は進まず、刺激から HT をやり直した
  |---- Pre 111 ----|-------- 273 --------|    → HT 384 ms
実際
  |---- Pre 111 ----|------- 242 -------|      → HT 353 ms
```

①との差（Post − (Simple の HT − Pre)）は、計算すると Go/Stop と Simple の HT の差と同じになる。新しい情報ではなく、「HT の延長は Pre の何割にあたるか」の言い換え。

## 3. 結果（10 名）

### 3.1 試行ごと

| 条件 | 試行 | HT の終わり（Go cue から） | HT と RT の傾き（中央値） | HT の終わりの SD：Onset 基準 → Go cue 基準 |
|---|---|---|---|---|
| Simple | 119 | 475 ms | 0.04（負の被験者 4/10） | 39 → 47 ms |
| Go/No-go | 91 | 536 ms | 0.03（負の被験者 5/10） | 52 → 60 ms |
| Go/Stop | 85 | 593 ms | 0.09（負の被験者 3/10） | 39 → 55 ms |

Go/Stop でも傾きはほぼ 0 で、SD は Go cue 基準のほうが大きい。**試行ごとには、HT の終わりは 2 回目の刺激に合わせて決まっていない**。ただし、被験者の中での RT のばらつきが小さいので、この方法では差を見つけにくい。

### 3.3 読み取れること

- 刺激の後の HT（Post 242 ms）は、Go/Stop の RT（239 ms）とほぼ同じ。**平均では、2 回目の刺激から RT ほどたったころに LT に入っている**
- 2 回目の刺激で振り直しているわけではない。振り直しなら、刺激のあとに RT + Simple の HT ≈ 510 ms かかるはず。刺激の処理（判断）は HT と重なっている
- Post と LT は Simple より短い傾向（−31 ms、−22 ms）。ただし、刺激の前（Pre）にもフックは少し進んでいるので、短くしようとしなくても Post は短くなりうる。フックの進み具合は [05_hook_progress](../05_hook_progress/技術説明.md) で調べた
- 3.1 の試行ごとの結果と合わせると、「判断が終わったら LT に入る」は平均の上での一致で、試行ごとに刺激に合わせているとまでは言えない
- 測っているものが違う点に注意：RT は床反力 Fx の変化、LT の始まりは top の X の最大で決めている
- S08 は Simple の HT が 111 ms と短く、LT が 341 ms と長い。局面の分け方が他の被験者と合っていない可能性がある

## 4. 使い方

1. 5 節のコードを、このフォルダに `ht_after_cue_analysis.m` という名前で保存する
2. MATLAB の現在のフォルダをこのフォルダにして実行する（x8 の StatTable.mat だけを読むので数秒）
3. 結果はコマンドウィンドウに出る（ファイルは保存しない）

## 5. コード（ht_after_cue_analysis.m）

```matlab
% ht_after_cue_analysis.m
%
% Go/Stop の HT と 2 回目の刺激（1 回目の Go の 350 ms 後）の関係を、x8 の値だけで調べる（マーカーは読まない）。
%
% 1. 試行ごとの関係：HT の終わりが 2 回目の刺激に合わせて決まっているか
%    合わせているなら、RT が長い試行ほど HT が短くなる（HT を RT で回帰した傾きが −1 に近い）。
%    また、HT の終わりのばらつき（被験者内 SD）は、Onset 基準より Go cue 基準のほうが小さくなる。
%    比べるために、2 回目の刺激がない Simple・Go/No-go も同じように計算する。
% 2. 被験者平均：Go/Stop の HT を、2 回目の刺激の前（Pre = 350 − RT）と後（Post = HT − Pre）に分け、
%    Simple の HT、「Simple と同じペースで進めた場合」の残り（Simple の HT − Pre）、Go/Stop の RT と比べる。
%    対応のある t 検定は探索的な確認用。
%
% 2026-11-09

%% 設定
T2ms = 350 ;   % 1 回目の Go → 2 回目の刺激 [ms]

scriptFolder   = fileparts(mfilename('fullpath')) ;
projectFolder  = fullfile(scriptFolder, '..', '..', '..', '..') ;   % Project002 のフォルダ
analysisFolder = fullfile(projectFolder, 'Experiments', 'Main experiments', '03_Analysis') ;
load(fullfile(analysisFolder, 'x8_StatTable', 'StatTable.mat'), 'TrialTable') ;
ok = TrialTable.IsGo & ~isnan(TrialTable.HookTime_ms) & ~isnan(TrialTable.RTForce_ms) ;

%% 1. 試行ごとの関係
fprintf('1. 試行ごと：HT の終わりは 2 回目の刺激に合わせて決まっているか（被験者ごとに計算、4 試行以上）\n') ;
for c = ["simple", "gonogo", "gostop"]
    T = TrialTable(ok & TrialTable.Condition == c, :) ;
    tEnd = T.RTForce_ms + T.HookTime_ms ;   % HT の終わり（Go cue から）
    sl = [] ; sdOn = [] ; sdCue = [] ;
    for s = unique(T.Subject)'
        k = T.Subject == s ;
        if sum(k) < 4, continue, end
        p = polyfit(T.RTForce_ms(k), T.HookTime_ms(k), 1) ;
        sl(end+1)    = p(1) ;                 %#ok<SAGROW>
        sdOn(end+1)  = std(T.HookTime_ms(k)) ; %#ok<SAGROW>
        sdCue(end+1) = std(tEnd(k)) ;          %#ok<SAGROW>
    end
    fprintf('  %-7s %3d 試行 | HT の終わり（Go cue から）%4.0f ms | HT と RT の傾き 中央値 %5.2f（負の被験者 %d/%d）| SD：Onset 基準 %3.0f、Go cue 基準 %3.0f ms\n', ...
        c, height(T), mean(tEnd), median(sl), sum(sl < 0), numel(sl), mean(sdOn), mean(sdCue)) ;
end

%% 2. 被験者平均：2 回目の刺激の前と後
G = TrialTable(ok & TrialTable.Condition == "gostop", :) ;
S = TrialTable(ok & TrialTable.Condition == "simple", :) ;
G.Pre  = T2ms - G.RTForce_ms ;           % Onset → 2 回目の刺激
G.Post = G.HookTime_ms - G.Pre ;         % 2 回目の刺激 → HT の終わり
subs = intersect(unique(G.Subject), unique(S.Subject))' ;
R = NaN(numel(subs), 9) ;
for is = 1:numel(subs)
    g = G(G.Subject == subs(is), :) ;  q = S(S.Subject == subs(is), :) ;
    R(is, :) = [subs(is), mean(g.HookTime_ms), mean(g.Pre), mean(g.Post), mean(q.HookTime_ms), ...
                mean(q.HookTime_ms) - mean(g.Pre), mean(g.LoopTime_ms), mean(q.LoopTime_ms), mean(g.RTForce_ms)] ;
end
fprintf('\n2. 被験者平均（ms）\n') ;
fprintf('   S  HT_GS   Pre  Post | HT_Simple  Simple−Pre | LT_GS  LT_Simple | RT_GS\n') ;
fprintf('  %2d  %5.0f %5.0f %5.0f | %9.0f %11.0f | %5.0f %10.0f | %5.0f\n', R') ;
m = mean(R) ;
fprintf('  平均 %5.0f %5.0f %5.0f | %9.0f %11.0f | %5.0f %10.0f | %5.0f（%d 名）\n', m(2:end), numel(subs)) ;
cmp = {4, 5, 'Post と Simple の HT' ; 4, 6, 'Post と Simple のペースで進めた場合（Simple の HT − Pre）' ; ...
       7, 8, 'LT：Go/Stop と Simple' ; 4, 9, 'Post と Go/Stop の RT'} ;
for i = 1:size(cmp, 1)
    a = R(:, cmp{i,1}) ; b = R(:, cmp{i,2}) ;
    [~, p, ~, st] = ttest(a, b) ;
    fprintf('  %-50s 差 %+4.0f ms、t(%d) = %5.2f、p = %.3f（前が大きい被験者 %d/%d）\n', ...
        cmp{i,3}, mean(a - b), st.df, st.tstat, p, sum(a > b), numel(subs)) ;
end
fprintf('  位置づけ（0 = Simple と同じペース、1 = 2 回目の刺激から HT をやり直した）：平均 %.2f\n', ...
    mean((R(:,4) - R(:,6)) ./ (R(:,5) - R(:,6)))) ;
```
