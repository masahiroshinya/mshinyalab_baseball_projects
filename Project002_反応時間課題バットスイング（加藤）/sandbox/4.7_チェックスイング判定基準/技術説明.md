## 1. フォルダの目的

本実験における「スイングした / しなかった」の二値判定基準を確立する。

MLBがアリゾナ・フォールリーグ（2024年〜）で試験運用中のチェックスイング自動判定システム（Hawk-Eye使用）の定義を採用し、実験室環境で再現可能な形に実装する。

---

## 2. MLB チェックスイング判定システムの定義

### 判定基準

> **バットヘッドがバットノブより45度以上前方に出た場合 → スイング（Strike）**  
> **45度未満で止まった場合 → ノースイング（No swing）**

「前方45度」とは、投手方向（0°）を基準に、右打者では一塁ファールライン方向、左打者では三塁ファールライン方向に相当する。

```
【水平面上の角度定義（右打者・上面図）】

           投手方向 (0°)
                │
   ─────────────┼───────────── 打者に対する垂直線
                │
   三塁方向     │     一塁方向
  (135°)        │        (45°) ← スイング判定閾値
                │
           捕手方向 (180°)

バットヘッドの水平方向角度 > 45° → SWING
バットヘッドの水平方向角度 ≤ 45° → NO SWING
```

### 測定の考え方

- 角度は「バットノブを起点とした、バットヘッドの水平方向ベクトル」と「投手方向ベクトル」のなす角で定義する
- Hawk-Eyeシステムでは複数カメラでバット位置をリアルタイムトラッキングし、最大到達角度を記録する

### 参照

- MLB公式発表（2024年10月）: [mlb.com](https://www.mlb.com/news/mlb-testing-check-swing-challenge-in-arizona-fall-league)
- Wikipedia: [Check Swing Challenge](https://en.wikipedia.org/wiki/Check_Swing_Challenge)

## 3. 実験室環境への実装

### 3.1 必要なマーカー構成

本実験はQualisysによるモーションキャプチャを使用するため、以下のマーカーが必要となる。

| マーカー種別 | 具体的な配置 | 役割 |
|---|---|---|
| バット剛体マーカー（既存） | バット本体に複数貼付 | バットの位置・姿勢の追跡 |
| **ノブマーカー** | バットグリップ端（最下部） | 角度計算の原点（既存の `bottom` マーカーが相当） |
| **ヘッド（バレル）マーカー** | バット先端 | 角度計算の先端点 |
| **ホームベース基準マーカー** | 打者の足元（ホームベース相当位置）| 打者の立ち位置の定義 |
| **投手方向基準マーカー** | ホームベースから投手方向に一定距離 | 0°方向（基準方向）の定義 |

> **注**: ホームベース基準マーカーと投手方向基準マーカーは、実験開始前のキャリブレーション時に配置し、計測開始後は取り外しても構わない（Qualisysの静止セグメント機能を利用）。

---

### 3.2 実験室のセットアップ

```
【実験室レイアウト（上面図）】

  [投手方向基準マーカー]
          ↑
          │  （例：3〜5m離す）
          │
  [ホームベース基準マーカー]  ← 打者はここに立つ
          │
  [Qualisys カメラ群]（周囲に設置）
```

#### 手順

1. **Qualisys の座標系を確認する**  
   - グローバル座標のX軸またはY軸が「投手方向」と一致するように、キャリブレーション時のL字フレームを設置する

2. **ホームベース位置を定義する**  
   - 床にテープ等でホームベース（または打者の足位置）を明示する
   - その位置にマーカーを置いてQualisysで記録し、「打者起点座標」として保存する

3. **投手方向を定義する**  
   - ホームベースから投手方向（正面）に一定距離（例：3m）離れた位置にマーカーを置き、「投手方向ベクトル」を算出する

4. **キャリブレーション完了後、基準マーカーを撤去する**（任意）

---

### 3.3 判定アルゴリズム

Qualisysから取得したデータをもとに、以下の手順で判定する。

#### ステップ1：バットベクトルの算出（水平面に投影）

```
bat_vec = head_pos - knob_pos
bat_vec_h = [bat_vec.x, bat_vec.y, 0]  % Z成分（上下方向）を除去
```

#### ステップ2：投手方向ベクトルの算出（水平面）

```
ref_vec = pitcher_marker_pos - home_marker_pos
ref_vec_h = [ref_vec.x, ref_vec.y, 0]  % Z成分を除去
```

#### ステップ3：角度の計算

```
cos_theta = dot(bat_vec_h, ref_vec_h) / (norm(bat_vec_h) * norm(ref_vec_h))
theta = acosd(cos_theta)   % 度単位に変換
```

#### ステップ4：スイング判定

```
if theta > 45
    result = 'SWING';
else
    result = 'NO SWING';
end
```

> **注意**：この角度計算は「バットがどちら側に回ったか（右打者か左打者か）」を考慮していない。  
> 打者の利き手に応じて、回転方向（符号）を確認する処理が必要。

---

### 3.4 ノブマーカーとヘッドマーカーについて

既存のマーカーセット（`bottom` = グリップ端）はノブ位置として使用可能。ただし、ヘッド位置を直接表すマーカーが現状のセットに含まれているか確認が必要。

| 確認事項 | 内容 |
|---|---|
| ヘッドマーカーの有無 | バット先端にマーカーが貼られているか |
| 剛体から推定できるか | バット剛体の形状定義からヘッド位置を推定できるか |

バット剛体が定義されていれば、**ノブとヘッドの間のローカル座標上の距離（バット長）** をあらかじめ測定しておくことで、ノブ位置のみからヘッド位置を計算することも可能。

## 4. 実装上の注意点

| 項目 | 注意内容 |
|---|---|
| **水平面への投影** | この基準は水平面上の角度のみを使用する。打ち下ろし・打ち上げ方向（仰角）は判定に含まれない |
| **最大角度の使用** | MLBのシステムはスイング中の最大到達角度で判定する。したがって、1試行分の時系列データ全体のピーク値を使用する |
| **左右打者の対応** | 右打者は一塁側（+45°）、左打者は三塁側（−45°）に対して同様の判定を行う |
| **バット長の計測** | ヘッドマーカーがない場合は事前にバット長を計測しておく |
| **基準マーカーの固定** | キャリブレーション中に基準マーカーが動かないよう、重りや固定テープを使用する |
