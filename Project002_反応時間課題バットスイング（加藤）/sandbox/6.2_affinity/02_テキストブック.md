# Affinity テキストブック

03_練習問題.md を解くための手順書。01_技術説明.md で用語を確認し、このテキストブックで操作を覚え、03_練習問題.md で手を動かす。

## 使い方

1. 各節の「使う機能」と「手順」を読む。
2. Affinity で同じ操作をする（作業ファイル .af は ⌘S / Ctrl+S でこまめに保存する）。
3. できたら PNG に書き出し、`04_成果物/practice_問題番号.png`（例：`practice_1-3.png`）として置く。
4. 「確認」の項目を自分でチェックする。AI に確認してもらうときは PNG を渡す（.af は AI が開けない）。

### 表記について

- メニューやツールの名前は日本語表示を基本に、英語表示を括弧で併記する（例：線（Stroke）パネル）。バージョンによって名前が少し違うことがある。
- **Mac と Windows の両方に対応**している。ショートカットは「Mac / Windows」の順に併記する（例：⌘S / Ctrl+S）。
- キーの対応：

| Mac            | Windows      |
| -------------- | ------------ |
| ⌘（Command）   | Ctrl         |
| ⌥（Option）    | Alt          |
| ⇧（Shift）     | Shift        |
| ↩（Return）    | Enter        |
| Delete         | Delete または Backspace |

- Windows では、メニュー（ファイル・編集など）は Affinity のウィンドウ上部にある。Mac では画面最上部のメニューバーにある。

## 第0章 準備

### 0-1. 画面の見方

| 場所                         | 役割                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| 左上のスタジオ切り替え       | ベクター（Vector）/ ピクセル（Pixel）/ レイアウト（Layout）。図を描くときは **ベクター** を使う |
| 左のツールバー               | 移動・ノード・ペン・図形・テキストなどのツール                                             |
| 上のコンテキストツールバー   | **今選んでいるツールやオブジェクトに応じて中身が変わる**。塗り・線・フォントなどをすぐ変えられる |
| 右のパネル                   | レイヤー・カラー・線・変形・スウォッチなど。メニューの **ウィンドウ（Window）** から表示できる |

見当たらないパネルは、**ウィンドウ** メニューから出す。よく使うのは次の5つ。

- **レイヤー（Layers）**：重なり順・ロック・表示/非表示・不透明度
- **カラー（Colour）**：塗りと線の色
- **線（Stroke）**：太さ・破線・矢印
- **変形（Transform）**：位置（X, Y）とサイズ（W, H）を数値で指定
- **スウォッチ（Swatches）**：登録した色のパレット

### 0-2. 単位：pt と mm

- 線の太さや文字サイズは **pt（ポイント）**、図の大きさや位置は **mm** で考えることが多い。
- **1 pt = 1/72 インチ ≒ 0.353 mm**。0.75 pt ≒ 0.26 mm、1 pt ≒ 0.35 mm。
- 単位が mm のドキュメントで線の太さを pt で指定するときは、数値欄に **`0.75pt`** のように単位まで入力する。自動で換算される。

### 0-3. 座標の向き

- 原点はページの **左上**。X は右へ、**Y は下へ** 行くほど大きくなる（グラフの y 軸と逆）。
- 変形パネルの左にある **9つの点（アンカー）** で、X, Y がオブジェクトのどこを指すかを選べる。グラフの棒を描くときは「下中央」にすると、下端の位置を固定したまま高さを変えられる。

### 0-4. 保存と書き出し

| 操作       | メニュー                               | Mac   | Windows          | 結果                                       |
| ---------- | -------------------------------------- | ----- | ---------------- | ------------------------------------------ |
| 保存       | ファイル → 保存（Save）                | ⌘S    | Ctrl+S           | .af（レイヤーなどが残る編集用の元データ）  |
| 別名で保存 | ファイル → 名前を付けて保存（Save As） | ⌘⇧S   | Ctrl+Shift+S     | 別の名前の .af                             |
| 書き出し   | ファイル → 書き出し（Export）          | ⌘⌥⇧W  | Ctrl+Alt+Shift+W | PNG / JPG / PDF / SVG など（見た目の出力） |

- 作業は .af で続け、確認・共有するときだけ書き出す。
- **Affinity でファイルを開いたまま、Finder（Windows ではエクスプローラー）でそのファイルやフォルダを移動・名前変更しない**（「トラブルシューティング」を参照）。

### 0-5. 基本操作のショートカット

| 操作                                   | Mac                          | Windows                      |
| -------------------------------------- | ---------------------------- | ---------------------------- |
| 取り消し                               | ⌘Z                           | Ctrl+Z                       |
| やり直し                               | ⌘⇧Z                          | Ctrl+Shift+Z                 |
| 複製                                   | ⌘J                           | Ctrl+J                       |
| グループ化                             | ⌘G                           | Ctrl+G                       |
| グループ解除                           | ⌘⇧G                          | Ctrl+Shift+G                 |
| 最前面へ                               | ⌘⇧]                          | Ctrl+Shift+]                 |
| 最背面へ                               | ⌘⇧[                          | Ctrl+Shift+[                 |
| カーブに変換                           | ⌘↩                           | Ctrl+Enter                   |
| ページ全体を表示                       | ⌘0                           | Ctrl+0                       |
| 100% 表示                              | ⌘1                           | Ctrl+1                       |
| 拡大 / 縮小                            | ⌘+ / ⌘−                      | Ctrl++ / Ctrl+−              |
| 一時的に手のひら（画面の移動）         | スペースを押しながらドラッグ | スペースを押しながらドラッグ |
| 移動ツール / ノードツール / ペンツール | V / A / P                    | V / A / P                    |

## 第1章 基本操作（Lv.1）

### 1-1. ドキュメントを作る

**使う機能**：新規ドキュメント、ドキュメント設定

**手順**

1. **ファイル → 新規（New）**（⌘N / Ctrl+N）を開く。
2. 次のように設定する。
   - 単位：**ミリメートル**
   - 幅 **180**、高さ **120**
   - DPI：**300**（PNG に書き出したときの解像度になる）
   - カラー形式：**RGB**
3. **作成** を押す。
4. ⌘S / Ctrl+S で `practice_1-1.af` として保存する。

**確認**：**ファイル → ドキュメント設定（Document Setup）**（⌘⌥P / Ctrl+Alt+P）を開き、サイズ・単位・DPI・カラー形式を見る。

**つまずきやすい点**

- 後から ドキュメント設定 でサイズを変えると、中の図形を拡大縮小するかどうか聞かれる。図形の線の太さや文字サイズがずれるので、サイズは最初に決める。

### 1-2. 四角と丸

**使う機能**：矩形ツール、楕円ツール、塗りと線、不透明度

**手順**

1. **矩形ツール**（M）でドラッグして四角を描く。Shift を押しながらだと正方形になる。
2. 四角を選んだまま、**カラーパネル** で塗りを青にする。
   - カラーパネル左上の **2つの丸** のうち、塗りつぶされた丸が「塗り」、輪の形が「線」。クリックしたほうが編集対象になる。
3. 線の丸を選び、**なし**（赤い斜線のアイコン）にする。
4. **楕円ツール**（矩形ツールのボタンを長押しすると出てくる）で丸を描く。Shift で正円になる。
5. 丸の塗りを **なし**、線を **赤** にする。
6. 線の太さを **1pt** にする（コンテキストツールバーの線の太さ、または線パネルの「幅」）。
7. 丸を選び、**レイヤーパネル上部の不透明度** を **50%** にする。
   - 移動ツールを選んだ状態で数字キー **5** を押しても 50% になる（0 で 100%）。
8. 丸を四角の右端に少し重ねる。

**確認**：四角に線がないこと、丸の中が透けていること、重なった部分で四角が透けて見えること。

### 1-3. 線と矢印

**使う機能**：ペンツール、変形パネル、線パネル（太さ・破線・矢印）、複製

**手順**

1. **ペンツール**（P）を選ぶ。
2. 始点で1回クリックし、Shift を押しながら右側で1回クリックする（Shift で水平に固定される）。
3. **Esc** または **↩ / Enter** を押して線を確定する。
4. **変形パネル** で **W を 50 mm** にする（H は 0 のまま）。これで長さがちょうど 50 mm になる。
5. **線パネル** を開き、次のように設定する。
   - 幅：**0.75pt**
   - **矢印（Arrowheads）**：終点（右側）の矢じりを選ぶ。矢じりの大きさは、横の「スケール」で調整する。
6. 線を選んだまま **⌘J / Ctrl+J** で複製し、少し下に移動する（Shift を押しながらドラッグで真下に動く）。
7. 複製した線の線パネルで、スタイルを **破線（Dash）** にする。破線の長さと間隔の数値を変えて、見え方を比べる。

**確認**：太さ 0.75 pt、長さ 50 mm、終点に矢じり、2本目が破線になっていること。

**つまずきやすい点**

- 矢じりが始点に付いたときは、始点と終点の設定を入れ替える。
- 矢じりが大きすぎるときは、線を太くするのではなく矢じりのスケールを下げる。

### 1-4. テキスト

**使う機能**：アーティスティックテキストツール、フレームテキストツール、文字の設定

**手順**

1. **アーティスティックテキストツール**（T）を選び、キャンバスを **クリック** して「Reaction Time」と入力する。
2. 文字を全部選び（⌘A / Ctrl+A）、コンテキストツールバーでフォントを **Arial**、サイズを **12 pt** にする。
3. **Esc** で入力を終えてから、移動ツールで四隅のハンドルをドラッグして拡大する。**文字サイズの数値も変わる** ことを確認する。
4. **フレームテキストツール**（テキストツールのボタンを長押し）で、四角い枠を **ドラッグ** して作る。
5. 3行以上になる文章を入力する（例：「刺激が提示されてから反応が開始されるまでの時間を反応時間と呼ぶ。…」）。枠の右端で自動的に改行される。
6. 枠のハンドルをドラッグして幅を変える。**文字サイズは変わらず、改行位置が変わる** ことを確認する。

**確認**：2種類のテキストの違いを、自分の言葉で説明できること。

| 種類                   | 作り方   | 拡大縮小すると         | 向いている用途         |
| ---------------------- | -------- | ---------------------- | ---------------------- |
| アーティスティック     | クリック | 文字そのものが大きくなる | 軸ラベル・見出し       |
| フレーム               | ドラッグ | 枠だけ変わり、折り返しが変わる | 説明文・キャプション |

**つまずきやすい点**

- 図のラベルは、拡大縮小で文字サイズがずれないよう、最後にサイズを 8〜10 pt などの決めた値に揃え直す。

## 第2章 配置と整理（Lv.2）

### 2-1. 整列と等間隔配置

**使う機能**：複数選択、整列（Align）、等間隔配置（Distribute）

**手順**

1. 矩形ツールで、大きさの違う四角を5つばらばらに描く。
2. 移動ツールで5つを囲むようにドラッグして全部選ぶ（Shift+クリックで1つずつ追加してもよい）。
3. コンテキストツールバーの **整列（Alignment）** ボタンを開く。または **配置（Arrange）→ 整列** メニューを使う。
4. **上揃え（Align Top）** を押す。
5. 同じところで **水平方向に等間隔（Space Horizontally / Distribute Horizontally）** を押す。
6. 次に **下揃え（Align Bottom）** を押す。棒グラフのように下端が揃う。

**確認**：⌘+ / Ctrl++ で大きく拡大し、棒の下端が1本の線に揃っていること。

**つまずきやすい点**

- 整列の基準は「選択範囲全体」「最初に選んだもの」などから選べる。思った位置に揃わないときは基準の設定を見る。

### 2-2. グループ化

**使う機能**：グループ化、グループ内の選択

**手順**

1. 2-1 の5つの四角を全部選んで **⌘G / Ctrl+G**。レイヤーパネルで「グループ」の中に5つが入ったことを確認する。
2. グループをドラッグして移動し、角のハンドルで拡大縮小する。5つが一緒に動く。
3. グループの中の1つを **ダブルクリック** して、それだけを選ぶ。色を変える。
   - レイヤーパネルでグループの左の三角を開き、中の1つをクリックしてもよい。
4. グループを選び直して **⌘⇧G / Ctrl+Shift+G** で解除する。

**確認**：レイヤーパネルでグループの入れ子の様子が分かること。

### 2-3. レイヤー

**使う機能**：レイヤーの追加・名前変更、ロック、表示/非表示、重なり順

**手順**

1. レイヤーパネル下の **レイヤーを追加（Add Layer）** ボタンで、レイヤーを3つ作る。
   - **新しい統合版 Affinity の場合**（2026-10-08 確認）：「レイヤーを追加」ボタンも、メニューの「新規レイヤー」も無い。代わりに、レイヤーパネル下端の右から3番目（ゴミ箱の2つ左）の **フォルダのアイコン（グループ化）**、またはメニューの **レイヤー → 新規グループ** で空のグループを作り、レイヤーとして使う。中身が空のうちは、名前が灰色で左に ⊘ が付く。
2. 名前をダブルクリックして、上から「文字」「図形」「背景」とする（上にあるものほど手前に表示される）。
3. 「背景」レイヤーを選んだ状態で、ページ全体を覆う四角を描き、塗りを薄いグレーにする。
   - 変形パネルでアンカーを「左上」にし、X=0, Y=0, W=180, H=120 にするとぴったり合う。
   - 描いた四角が「背景」の中に入ったか、レイヤーパネルで確認する。外に出ていたら、四角を「背景」の上にドラッグして中に入れる。
4. 「背景」レイヤーの **鍵のアイコン** を押してロックする。
5. これまでの図形はレイヤーパネル上で「図形」レイヤーへ、テキストは「文字」レイヤーへドラッグして移す。
6. 「文字」レイヤーの右端の **チェック（表示）** を外して非表示にし、もう一度入れて表示する。
   - 新しい統合版 Affinity では、チェックではなく **目のアイコン** で切り替える。

**確認**：背景をクリックしても選ばれないこと。図形と文字が背景より手前にあること。

### 2-4. スウォッチ

**使う機能**：スウォッチパネル、ドキュメントパレット、スポイト

**手順**

1. スウォッチパネルの右上のメニューから **ドキュメントパレットを追加（Add Document Palette）** を選ぶ。名前は「Figure」などにする。
2. カラーパネルで1色目（条件A＝青）を作り、スウォッチパネルの **現在の塗りをパレットに追加（Add current fill to palette）** ボタンで登録する。
3. 同じように、オレンジとグレーを登録する。
4. 2-1 の棒を1本ずつ選び、スウォッチの色をクリックして塗り分ける。
5. **スポイト**：色を付けたい図形を選んでおき、カラーパネルのスポイトのアイコンを **押したまま** 色を拾いたい棒の上までドラッグして離す。拾った色がスポイトの横に表示されるので、それをクリックして適用する。

**確認**：棒の色がスウォッチの3色だけでできていること。

**つまずきやすい点**

- 「ドキュメントパレット」はそのファイルに保存される。どのファイルでも使いたい色は「アプリケーションパレット」に登録する。

## 第3章 ペンとノード（Lv.3）

### 3-1. 直線の多角形

**使う機能**：ペンツール（クリックで角のノード）、パスを閉じる

**手順**

1. ペンツールで、頂点の位置を **クリックだけ** で順に打つ（ドラッグしない）。
2. 最後に **始点をクリック** すると、パスが閉じて図形になる。
3. 三角形（3点）、五角形（5点）、星形（外側と内側を交互に10点）を描く。

**確認**：レイヤーパネルで「カーブ」になっていること。塗りを付けると中が塗られること（閉じたパスになっている）。

- 新しい統合版 Affinity では、直線だけでできたパスはレイヤーパネルで「カーブ」ではなく「線」や「ポリライン」と表示される。曲線を含むパス（3-2）は「カーブ」と表示される（2026-10-08 確認）。表示名からは閉じているかどうかが分からないので、**塗りを付けて中が塗られるか** で確認する。

**つまずきやすい点**

- 始点をクリックせずに Esc を押すと、開いたパス（線）になる。閉じたいときは、ノードツールで始点と終点を選び、コンテキストツールバーの **カーブを閉じる（Close Curve）** を押す。

### 3-2. ベジェ曲線

**使う機能**：ペンツール（ドラッグでなめらかなノード）、ノードツール、ハンドル

**手順**

1. ペンツールで、1点目を **クリック**。
2. 2点目で、押したまま **右上へドラッグ** して離す。ノードから2本の **ハンドル** が出て、曲線になる。
3. 3点目で **右下へドラッグ** して離す。S字の波線になる。Esc で確定する。
4. **ノードツール**（A）に持ち替え、ハンドルの先端をドラッグする。
   - ハンドルの **向き** → 曲がる方向が変わる。
   - ハンドルの **長さ** → 曲がり具合（ふくらみ）が変わる。
5. 線の上をクリックしてノードを1つ **追加** する。
6. 別のノードをクリックで選び、**Delete** キー（Windows では Delete または Backspace）で **削除** する。形が崩れたら、ハンドルで整える。

**確認**：ハンドルの向きと長さで曲がり方が変わることを確認できたか。

**つまずきやすい点**

- ハンドルを片側だけ動かしたいときは、⌥ / Alt を押しながらドラッグする。
- コンテキストツールバーで、ノードの種類（シャープ / スムーズ / スマート）を切り替えられる。

### 3-3. 図形をノードで変形

**使う機能**：カーブに変換、ノードツール

**手順**

1. 矩形ツールで四角を描く。
2. **⌘↩ / Ctrl+Enter**（または コンテキストツールバーの **カーブに変換（Convert to Curves）**）で、ノードを持つ「カーブ」にする。
3. ノードツールで、上の2つの角のうち1つを選び、Shift を押しながら横にドラッグする。台形になる。
   - 上の2つを Shift+クリックで両方選び、内側へ動かすと左右対称の台形にもできる。

**確認**：変換前は四角のノードを動かせない（ハンドルで角を丸くするだけ）が、変換後は動かせること。

### 3-4. 簡単なイラストのトレース

**使う機能**：画像の配置、レイヤーのロック・非表示、ペンツール

**手順**

1. マグカップやバットなどをスマホで撮影し、パソコンに取り込む。
2. 新しいレイヤー「写真」を作り、**ファイル → 配置（Place）**（⌘⇧L / Ctrl+Shift+L）で写真を置く。
3. 「写真」レイヤーの不透明度を 50% くらいに下げ、**ロック** する。
4. その上に「トレース」レイヤーを作る。
5. ペンツールで輪郭をなぞる。直線部分はクリック、曲線部分はドラッグ。塗りはなし、線は 1 pt 程度。
6. 一通り描けたら、ノードツールでずれを直す。
7. 「写真」レイヤーを非表示にする。

**確認**：線画だけで何の絵か分かること。

**つまずきやすい点**

- 最初からノードを細かく打ちすぎない。曲線は「少ないノード＋長めのハンドル」のほうがなめらかになる。

## 第4章 図表を作る（Lv.4）

グラフは「値 → 長さ（mm）」の換算を先に決めてから描く。以下は換算の一例。

### 4-1. 棒グラフ

**使う機能**：変形パネル（数値入力・アンカー）、整列、グループ化

**換算**：値 1 = 0.5 mm（縦軸 0〜80 → 40 mm）

| 条件 | 平均 | 棒の高さ | SD | エラーバーの長さ（上側） |
| ---- | ---- | -------- | -- | ------------------------ |
| A    | 40   | 20 mm    | 5  | 2.5 mm                   |
| B    | 60   | 30 mm    | 8  | 4 mm                     |
| C    | 50   | 25 mm    | 6  | 3 mm                     |

**手順**

1. **縦軸**：ペンツールで縦線を描き、変形パネルで H = 40 mm、線の太さ 0.75 pt にする。
2. **目盛**：0, 20, 40, 60, 80 の位置（10 mm おき）に、長さ 1.5 mm 程度の短い横線を5本置く。1本描いて ⌘J / Ctrl+J で複製し、5本を選んで **垂直方向に等間隔配置** すると速い。
3. **目盛ラベル**：アーティスティックテキストで「0」「20」…「80」を作る（Arial 8 pt など）。目盛との **中央揃え（垂直方向）** と **右揃え** で並べる。
4. **軸ラベル**：「Value (a.u.)」を作り、変形パネルの回転（R）を 90°（または −90°）にして縦軸の左に置く。
5. 軸・目盛・ラベルを全部選んで **⌘G / Ctrl+G**（グループ名を「軸」にしておく）。
6. **棒**：矩形ツールで幅 8 mm 程度の四角を描く。変形パネルのアンカーを **下中央** にし、Y を縦軸の 0 の位置に合わせ、H を 20 / 30 / 25 mm にする。3本を **下揃え** と **水平方向に等間隔配置** で並べる。
7. **エラーバー**：各棒の上端から、上に SD の長さ分の縦線を描き、先端に短い横線（キャップ）を付ける。縦線と横線を **水平方向の中央揃え** で棒の中心に合わせる。
8. 塗りの色はスウォッチから選ぶ。

**確認**：線の太さ（0.5〜1 pt）、フォント、文字サイズが図全体で統一されていること。棒の高さの比が 40 : 60 : 50 になっていること。

**つまずきやすい点**

- 棒の高さを、角のハンドルをドラッグして合わせない。必ず変形パネルに数値を入れる。
- アンカーが「中央」のまま H を変えると、棒が上下両方に伸びて下端がずれる。

### 4-2. 折れ線グラフ

**使う機能**：グリッドとスナップ、ペンツール、破線、凡例

**換算**：x の1目盛 = 10 mm、値 1 = 0.5 mm。この換算だと、すべての点が **2.5 mm の倍数** の位置に来る。

| x               | 1    | 2    | 3    | 4    | 5    |
| --------------- | ---- | ---- | ---- | ---- | ---- |
| A の高さ（mm）  | 5    | 10   | 12.5 | 17.5 | 20   |
| B の高さ（mm）  | 7.5  | 7.5  | 15   | 15   | 22.5 |

**手順**

1. **表示 → グリッドと軸マネージャー（Grid and Axis Manager）** で、グリッドの間隔を **2.5 mm** にする。**表示 → グリッドを表示**（⌘' / Ctrl+'）でグリッドを出す。
2. ツールバーの **スナップ（磁石のアイコン）** をオンにし、スナップの設定で「グリッドにスナップ」を有効にする。
3. 縦軸と横軸を描く（4-1 と同じ要領）。
4. ペンツールで、A の5点を順に **クリック** して折れ線を描く。グリッドに吸着するので、表の高さの位置をクリックすればよい。Esc で確定する。
5. B も同じように描き、線パネルで **破線** にする。
6. **マーカー**：楕円ツールで直径 1.5 mm 程度の丸を1つ作り、⌘J / Ctrl+J で複製して各点に置く（スナップで点にぴったり合う）。A と B でマーカーの塗りを変えるとよい。
7. **凡例**：短い実線＋丸＋「A」、短い破線＋丸＋「B」を作り、グラフの右上に置く。

**確認**：A が実線、B が破線になっていること。凡例の線の種類がグラフと一致していること。

### 4-3. 散布図

**使う機能**：複製、塗りだけの不透明度

**手順**

1. 軸を描く。
2. 楕円ツールで丸を1つ作り、⌘J / Ctrl+J で複製しながら、右上がりになるように10個程度ばらまく。
3. 点の並びの真ん中を通るように、ペンツールで直線を1本引く（回帰直線のつもり）。
4. 丸を全部選び、**カラーパネルで塗りの不透明度** を **60%** にする。
   - レイヤーパネルの不透明度は「オブジェクト全体」（塗りと線の両方）に効く。カラーパネルの不透明度は「塗りだけ」に効く。散布図では、重なった点が見分けられるよう塗りだけ薄くすることが多い。

**確認**：重なった点が透けて見えること。

### 4-4. 概念図

**使う機能**：変形パネル、整列と等間隔配置、テキストの中央揃え、矢印

**手順**

1. 矩形ツールで四角を描き、変形パネルで W = 30 mm、H = 12 mm にする。
2. ⌘J / Ctrl+J で3回複製して4つにする。
3. 4つを選び、**上下中央揃え** と **水平方向に等間隔配置** で並べる。
4. アーティスティックテキストで「刺激」「反応」「動作開始」「スイング」を作る。
5. 四角と文字を1組ずつ選び、**水平方向の中央揃え** と **垂直方向の中央揃え** をする。
   - 整列の基準を「最初に選択したもの」にし、**四角を先に** 選ぶと、四角は動かずに文字だけが中央に来る。
6. 四角の間に、1-3 の要領で矢印を置く。
7. 四角と文字を組ごとに ⌘G / Ctrl+G でグループにする。

**確認**：四角の大きさと間隔がすべて同じで、文字が各四角の中央にあること。

**つまずきやすい点**

- 日本語の文字は、Arial では表示されないことがある。日本語には「ヒラギノ角ゴシック」などの日本語フォントを使う。

## 第5章 仕上げと書き出し（Lv.5）

### 5-1. 図領域とまとめ

**使う機能**：コピー＆ペースト、グループ、最背面、パネルラベル

**手順**

1. 180 × 80 mm の新しいドキュメントを作る。
2. 4-1 と 4-2 のグラフをそれぞれグループにしてコピー（⌘C / Ctrl+C）し、新しいドキュメントにペースト（⌘V / Ctrl+V）する。
3. 左に 4-1、右に 4-2 を置き、**上揃え** で上端を揃える。
4. 各図の左上に、アーティスティックテキストで「A」「B」を置く（太字、他の文字より少し大きく）。
5. **図領域**：ページと同じ大きさ（W = 180、H = 80、X = 0、Y = 0）の四角を描き、**⌘⇧[ / Ctrl+Shift+[** で最背面に送る。塗り・線はなしでよい。
6. 図領域の四角はロックしておく。

**確認**：2つの図の上端とパネルラベルの位置が揃っていること。図領域がページいっぱいにあること。

**つまずきやすい点**

- ペーストした図を拡大縮小すると線の太さや文字サイズが変わる。大きさを変えたときは、最後に線の太さと文字サイズを揃え直す。
- 線パネルの **「オブジェクトとともに拡大縮小（Scale with object）」** をオフにすると、拡大縮小しても線の太さが変わらない。

### 5-2. 書き出し

**使う機能**：書き出し（Export）の形式と設定

**手順**

1. **ファイル → 書き出し**（⌘⌥⇧W / Ctrl+Alt+Shift+W）を開く。
2. 次の4つを順に書き出し、`04_成果物` に保存する。

| 形式 | 主な設定                       | 種類     |
| ---- | ------------------------------ | -------- |
| PDF  | プリセット：印刷用など         | ベクター |
| SVG  | 標準のまま                     | ベクター |
| PNG  | DPI：300                       | ピクセル |
| JPG  | 品質を低く（例：30%）          | ピクセル |

3. それぞれのファイルサイズを比べる。
   - Mac：Finder でファイルを選んで ⌘I。
   - Windows：エクスプローラーでファイルを右クリック →「プロパティ」。表示を「詳細」にすると一覧でも見られる。
4. PDF と PNG を画像ビューア（Mac は「プレビュー」、Windows は「フォト」や Edge など）で開き、大きく拡大して比べる。PDF は線がなめらかなまま、PNG はギザギザ（ピクセル）が見える。JPG では文字や線のまわりにノイズが出る。

**確認**：ベクターとピクセルの違い、PNG と JPG の違いを説明できること。

### 5-3. MATLAB の図を取り込む（任意）

**手順**

1. MATLAB で図を作り、ベクター形式で保存する。

   ```matlab
   plot(1:10, (1:10).^2);
   exportgraphics(gcf, 'test_plot.pdf', 'ContentType', 'vector');
   ```

2. Affinity で **ファイル → 開く**（⌘O / Ctrl+O）から PDF を開く。
3. 全体がグループ（何重にも入れ子）になっているので、⌘⇧G / Ctrl+Shift+G を何度か押して解除する。
4. 線の太さ・フォント・色を変更する。

**つまずきやすい点**

- MATLAB の図には、見えない「クリッピング用の四角」や白い背景の四角が含まれていることがある。レイヤーパネルで中身を確認し、不要なものは削除する。
- PDF を開くとフォントの置き換えを聞かれることがある。使いたいフォントを選び直せばよい。

## トラブルシューティング

### ファイル名の先頭に見えない文字が入る

- **症状**：Finder やエクスプローラーでは普通の名前に見えるが、ターミナルやスクリプトでファイルを扱いにくい。
- **原因**：ファイル名をコピー＆ペーストしたときに、ゼロ幅スペース（目に見えない文字）が混ざった。
- **確認方法**：
  - Mac：ターミナルで `ls | cat -v` を実行すると、見えない文字が `M-bM-^@M-^K` のように表示される。
  - Windows：PowerShell で `Get-ChildItem | ForEach-Object { $_.Name.Length, $_.Name }` を実行し、見た目の文字数より長いファイル名を探す。
- **対処**：ファイル名を一度全部消して、キーボードで打ち直す。

### `~lock~` ファイルがある

- **症状**：`practice.af~lock~` のようなファイルがフォルダにある。
- **原因**：Affinity でファイルを開いている間だけ作られる一時ファイル。
- **対処**：Affinity でファイルを閉じれば消える。手で消さない。開いたまま `git commit` するとこれも含まれるので、コミットは Affinity を閉じてから行う。

### AI に .af を確認してもらえない

- **原因**：.af は Affinity 独自の形式で、AI は中身を表示できない。
- **対処**：PNG に書き出して、そのファイルを渡す。

### ファイルを開いたまま移動・名前変更した

- **症状**：保存したはずの内容が見つからない、保存時にエラーが出る、`~lock~` ファイルが残る。
- **原因**：Affinity が開いている .af の場所が変わった。
- **対処**：移動や名前変更は、Affinity でファイルを閉じてから行う（Windows では、開いているファイルは移動できないことが多い）。すでに移動してしまったときは、いったん閉じて、移動先から開き直す。
