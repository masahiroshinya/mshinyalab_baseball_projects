## 1. RM-ANOVA が答える問い

RM-ANOVA が調べるのは、ひとつの問いだけである。

> **「条件によって平均が違う」と言えるか？**

統計の言葉では、**帰無仮説**「すべての条件の母平均は等しい」を立て、データがこの仮説のもとで起こりにくいかどうかを調べる。起こりにくければ（p < .05）、帰無仮説を捨てて「条件のどこかに差がある」と判断する。

RM-ANOVA の結果からは、**どの条件とどの条件に差があるかは分からない**。それは事後比較（8 節）で調べる。

---

## 2. 全体像：ばらつきを 3 つに分ける

分散分析は、データ全体のばらつき（平方和 SS）を、原因ごとに分けて比べる方法である。反復測定では、全員が全条件を行うので、ばらつきを次の 3 つに分けられる。

| ばらつきの源 | 意味 | RT の SS | JASP の表 |
|---|---|---|---|
| 条件（Condition） | 条件によって平均が違うことによるばらつき | 6589 | Within Subjects Effects の Condition |
| 被験者（個人差） | もともと反応の速い人・遅い人がいることによるばらつき | 11220 | Between Subjects Effects の Residuals |
| 残差（誤差） | 上の 2 つで説明できない残り（条件の効き方の個人差や、測定のぶれ） | 4732 | Within Subjects Effects の Residuals |
| **合計** | | **22541** | |

RT の場合、個人差（11220）が全体の約半分を占める。RM-ANOVA は、この**個人差を誤差から取り除いて**から条件の効果を調べる。これが、同じ人の条件を比べる反復測定の強みである（4 節に数値の比較がある）。

## 3. Within Subjects Effects（被験者内効果）の表

この表が RM-ANOVA の本体である。

```
Cases       Sphericity Correction  Sum of Squares  df      Mean Square  F      p      η²
Condition   None                   6589            2.000   3294         11.14  <.001  0.5820
            Greenhouse-Geisser     6589            1.365   4826         11.14  .004   0.5820
Residuals   None                   4732            16.00   295.7
            Greenhouse-Geisser     4732            10.92   433.3
```

### 3.1 行（Cases と Sphericity Correction）

- **Condition**：条件の効果
- **Residuals**：残差（誤差）。F を計算するときの「ものさし」になる
- **None**：補正をしない値。球面性（6 節）が成り立つことを前提にする
- **Greenhouse-Geisser**：球面性の崩れに備えて自由度を小さくした値（6.3 節）

### 3.2 列

**Sum of Squares（平方和 SS）**
ばらつきの大きさ。条件の SS は「各条件の平均が全体の平均からどれだけ離れているか」を、2 乗して合計したもの。補正をしても SS は変わらない。

**df（自由度）**
- 条件：k − 1 = 3 − 1 = **2**
- 残差：(k − 1)(n − 1) = 2 × 8 = **16**

自由度は、平方和を「独立に動ける値の数」で割って、平均的なばらつき（MS）にするための数である。式の導き方は [技術説明.md](技術説明.md) の 11.1 節（自由度・補足）にある。

**Mean Square（平均平方 MS）**
MS = SS / df。

- 条件：6589 / 2 = 3294
- 残差：4732 / 16 = 295.7

**F（F 値）**
F = 条件の MS / 残差の MS = 3294 / 295.7 = **11.14**

「条件による違いが、誤差の何倍あるか」を表す。帰無仮説が正しければ（条件で差がなければ）F は 1 前後になり、条件で差があるほど大きくなる。

**p（有意確率）**
「帰無仮説が正しいとしたら、F がこの値以上になる確率」。p < .05 のとき「有意」と判断する。

- p は「帰無仮説が正しい確率」**ではない**
- p は「差の大きさ」**でもない**。差の大きさは効果量（η²）で見る

**η²（効果量）**
条件の違いが、ばらつきのどれだけを説明しているかを表す（7 節）。

### 3.3 RT の読み取り

補正なしで F(2, 16) = 11.14、p < .001。Greenhouse-Geisser 補正で F(1.37, 10.92) = 11.14、p = .004。どちらでも有意で、「RT は条件によって違う」と言える。

## 4. Between Subjects Effects（被験者間効果）の表

```
Cases      Sum of Squares  df  Mean Square  F  p
Residuals  1.122×10^4      8   1403
```

- **Residuals**：被験者の個人差によるばらつき（2 節の表の「被験者」）。SS = 11220、df = n − 1 = 8、MS = 11220 / 8 = 1403
- **F と p が空欄なのは正常**。この実験には被験者間の要因（群分け、例：経験者と未経験者）がないので、検定するものがない

**なぜこの表が大事か（個人差を取り除く効果）**
仮に、同じデータを「別々の人が各条件を行った」として普通の一元配置分散分析にすると、個人差が誤差に混ざる。

| | 誤差の SS | 誤差の df | 誤差の MS | F |
|---|---|---|---|---|
| RM-ANOVA（個人差を除く） | 4732 | 16 | 295.7 | **11.14** |
| 普通の分散分析（個人差が混ざる） | 4732 + 11220 = 15952 | 16 + 8 = 24 | 664.7 | **4.96** |

個人差を誤差から外すと、誤差の MS が半分以下になり、F が 2 倍以上になる。同じ人を全条件で測ると、少ない人数でも差を見つけやすいのはこのためである。

**Note: Type III Sum of Squares** は平方和の計算方法の種類。要因が 1 つ（Condition だけ）で欠損もないこの解析では、Type I・II・III のどれでも同じ値になるので、気にしなくてよい。

## 5. Descriptives（記述統計）の表

```
Condition  N  Mean   SD     SE     Coefficient of variation
Simple     9  201.4  22.42  7.475  0.1113
Go/No-Go   9  214.1  30.12  10.04  0.1407
Go/Stop    9  239.0  24.17  8.057  0.1011
```

| 列 | 意味 | 計算（Simple の例） |
|---|---|---|
| **N** | 被験者の数。**ここで 9 名になっているかを必ず確かめる** | 9 |
| **Mean** | 被験者平均の平均（ms） | 201.4 |
| **SD** | 標準偏差。被験者の間のばらつき | 22.42 |
| **SE** | 標準誤差 = SD / √N。平均の推定の精度 | 22.42 / 3 = 7.47 |
| **Coefficient of variation** | 変動係数 = SD / Mean。平均に対するばらつきの割合 | 22.42 / 201.4 = 0.111 |

**注意**

- この SD は、1 人 1 値にした後の**被験者の間**のばらつきである。1 人の中の試行のばらつきではない
- 平均の差（Simple 201 → Go/No-Go 214 → Go/Stop 239 ms）がどれくらい確かかは、SD を見るだけでは分からない。反復測定では、同じ人の条件の差を見るので、事後比較（8 節）で確かめる

### 5.1 SE と CV は、どれくらいなら「小さい」と言えるか

決まった基準はない。どちらも**何かと比べて**判断する。

**SE は「確かめたい差」と比べる**

SE は 95% 信頼区間（平均 ± t × SE、9 名なら t(8) = 2.31）に直すと読みやすい。

| 条件 | 平均 | SE | 95% 信頼区間 |
|---|---|---|---|
| Simple | 201.4 | 7.5 | 約 184〜219 ms |
| Go/No-Go | 214.1 | 10.0 | 約 191〜237 ms |
| Go/Stop | 239.0 | 8.1 | 約 220〜258 ms |

区間の幅が、確かめたい条件の差より十分に小さければ、精度は足りている。ただし反復測定では、各条件の SE より、**被験者ごとに計算した差の SE** が大事である（AI が CSV から計算）。

| 比較 | 差の平均 | 差の SE | t = 差 / SE |
|---|---|---|---|
| Go/Stop − Simple | 37.6 ms | 6.9 | 5.4 |
| Go/Stop − Go/No-Go | 24.9 ms | 10.5 | 2.4 |
| Go/No-Go − Simple | 12.7 ms | 6.2 | 2.0 |

差が SE の何倍か（t）で見るのが実用的で、事後比較の表の t がこれに当たる。

**CV は「別の条件・指標・研究」と比べる**

- CV = SD / Mean は、単位をそろえたばらつき。単位の違う指標（ms と体重比など）や、先行研究（報告された SD と平均から計算する）と比べるときに使う
- 「10% 未満なら小さい」などの目安は分野ごとの慣習で、統計学の基準ではない
- この表の CV は**被験者の間のばらつき（個人差）**で、測定の精度ではない。RT の 10〜14% は「人によって反応の速さが平均の 1 割ほど違う」という意味
- 0 に意味がある量（時間・力・速度）にだけ使える。位置の座標などには使えない

## 6. Assumption Checks（前提の確認）：球面性

### 6.1 球面性とは

RM-ANOVA は、「どの 2 条件の組を選んでも、条件の差（例：Go/Stop − Simple）のばらつきが同じ」という前提を置く。これを**球面性**という。詳しくは [技術説明.md](技術説明.md) の 11.3 節。

球面性が崩れていると、補正なしの F 検定は「差がある」と言いすぎる（本当は差がないのに p < .05 になる確率が 5% より大きくなる）。

### 6.2 Test of Sphericity の表

```
           Mauchly's W  Approx. X²  df  p-value  Greenhouse-Geisser ε  Huynh-Feldt ε  Lower Bound ε
Condition  0.5349       4.379       2   .112     0.6826                0.7752         0.5000
```

| 列 | 意味 |
|---|---|
| **Mauchly's W** | 球面性からのずれを表す値。1 なら完全に球面性が成り立ち、0 に近いほど崩れている |
| **Approx. X²** | W を χ² に変換した検定統計量 |
| **df** | k(k − 1) / 2 − 1。3 条件なら 2、4 条件なら 5 |
| **p-value** | 「球面性が成り立つ」という帰無仮説の検定。p < .05 なら球面性が崩れていると判断する |
| **Greenhouse-Geisser ε** | 球面性の崩れの程度を表す係数。1 なら崩れなし |
| **Huynh-Feldt ε** | GG の ε を、少し甘く（大きく）見直したもの |
| **Lower Bound ε** | ε がとりうる最も小さい値 = 1 / (k − 1)。3 条件なら 0.5 |

### 6.3 補正の仕組み

Greenhouse-Geisser 補正は、**F はそのままで、自由度に ε を掛けて小さくする**。

- 条件の df：2 × 0.6826 = **1.365**
- 残差の df：16 × 0.6826 = **10.92**

自由度が小さいほど、同じ F でも p は大きくなる（慎重な判断になる）。RT では、補正なしの p < .001 が、補正後は p = .004 になった。

### 6.4 この研究での扱い

- RT の Mauchly の検定は p = .112 で、球面性が崩れているとは言えない
- ただし、9 名のような少ない人数では、Mauchly の検定は崩れを見逃しやすい（検出力が低い）
- そこで、2026-10-29 の 8 名の解析と同じく、**Mauchly の結果にかかわらず Greenhouse-Geisser 補正の行を報告する**。補正は p を大きくする方向にしか働かないので、安全側の判断になる

#### 6.4.1 Mauchly の検定は、なぜ崩れを見逃しやすいか

- Mauchly の検定の帰無仮説は「球面性が成り立つ」。p > .05 から言えるのは「崩れているという証拠が足りない」ことだけで、「成り立っている」ことの証明にはならない（「有意でない ≠ 差がない」と同じ）
- この検定は、データから条件の差のばらつきを推定して比べる。9 名ではこの推定が大きくぶれるので、本当に崩れていても「偶然の範囲」と判定されやすい（検出力が低い）
- RT の例：Mauchly は p = .112 で有意でないが、GG の ε は 0.68。ε は 1 なら崩れなし、3 条件の最小値は 0.5 なので、0.68 は崩れなしよりも最悪の側に近い。検定は「崩れていない」と判定し、ε は「かなり崩れている」ことを示している

#### 6.4.2 常に GG 補正を使う理由

**補正は p を大きくする方向にしか働かない**：ε ≦ 1 を自由度に掛けるので、補正後の p は必ず補正前以上になる。

| RT | df | p |
|---|---|---|
| 補正なし | (2, 16) | < .001（約 .0009） |
| GG 補正 | (1.37, 10.92) | .004 |

**「安全側」の意味**：検定の誤りには、本当は差がないのに「差がある」と言う第 1 種の誤りと、本当の差を見逃す第 2 種の誤りがある。球面性が崩れているのに補正しないと、第 1 種の誤りの確率が決めた 5% より大きくなる。GG 補正は、崩れていてもこれを 5% 前後に抑える。

**代償**：検出力が少し下がる（第 2 種の誤りが増える）。ただし球面性がほぼ成り立つときは ε が 1 に近く、補正前とほとんど同じ p になるので、損はわずか。崩れていないのに補正しても失うものは小さく、崩れているのに補正しないと失うものは大きい。

**「Mauchly で決める」手順の問題**：「Mauchly が有意なら補正、有意でなければ補正なし」という 2 段階の手順は、6.4.1 のとおり見逃しが多く、見逃すと補正なしの甘い検定に進んでしまう。そのため、はじめから常に補正した値を使うことが多くの教科書で勧められている。7 つの指標すべてに同じ方法を使えるので、指標ごとに方法を変えたと見られる心配もない。

**Huynh-Feldt 補正**：GG は ε が 1 に近いときにやや補正しすぎる（厳しすぎる）傾向があり、それを和らげたのが Huynh-Feldt 補正（RT では ε = 0.78）。この研究では厳しい方の GG にそろえる。

## 7. 効果量 η²

### 7.1 なぜ効果量を見るのか

p は人数が増えると小さくなる。そのため、「有意かどうか」だけでは、差がどれくらい大きいかは分からない。効果量は、人数に左右されにくい「差の大きさ」の指標である。

### 7.2 計算

この表の η² は、条件と残差の平方和から計算されている。

η² = 条件の SS / (条件の SS + 残差の SS) = 6589 / (6589 + 4732) = **0.582**

- 個人差（11220）は分母に入らない。そのため、要因が Condition の 1 つだけのこの解析では、**JASP の η² は偏イータ二乗 η²p と同じ値**になる（全体の SS 22541 で割ると 0.292 になり、表の値と合わない）
- 要因が 2 つ以上になると η² と η²p は違う値になる。論文では、どちらを書いたかを明記する。JASP では Display → Estimates of effect size で η²p（partial η²）を選べる
- 補正をしても SS は変わらないので、η² も変わらない

### 7.3 目安

| η²p | 大きさの目安（Cohen, 1988） |
|---|---|
| .01 | 小 |
| .06 | 中 |
| .14 | 大 |

RT の .58 は「大」をはるかに超える。ただし、この目安は分野を問わない大まかなものなので、先行研究の値と比べるのがよい。詳しくは [技術説明.md](技術説明.md) の 11.5 節。

## 8. Post Hoc Tests（事後比較）

RM-ANOVA で有意になったら、**どの条件の組に差があるか**を事後比較で調べる。

### 8.1 表の出し方

Post Hoc Tests の項目で Condition を右の枠に移し、Correction の **Holm** にチェックを入れる。出力に「Post Hoc Comparisons - Condition」の表が出る。

### 8.2 列

| 列 | 意味 |
|---|---|
| **Mean Difference** | 2 条件の平均の差（左の条件 − 右の条件） |
| **SE** | 差の標準誤差 |
| **t** | t = 平均の差 / SE。対応のある t 検定の値 |
| **Cohen's d**（表示する場合） | 2 条件の差の効果量 |
| **p_holm** | Holm の方法で補正した p。**この列で有意かどうかを判断する** |
| p_bonf（出る場合） | Bonferroni の方法で補正した p。今回は使わない。p_holm と取り違えないこと |

比較の数は k(k − 1) / 2。RT（3 条件）は 3 組、他の指標（4 条件）は 6 組になる。

### 8.3 なぜ補正するのか

1 回の検定で「差がないのに差があると言ってしまう」確率は 5% だが、6 回検定すると、少なくとも 1 回それが起こる確率は約 26%（1 − 0.95⁶）になる。これを 5% に抑えるのが多重比較の補正である。詳しくは [技術説明.md](技術説明.md) の 11.4 節。

### 8.4 Holm の方法

Bonferroni の方法は、すべての p に比較の数 m を掛ける（または有意水準を α / m にする）。Holm の方法はこれを少しゆるめた方法で、次のように進める。

1. m 個の p を小さい順に並べる
2. いちばん小さい p を α / m と比べる。小さければ有意として、次へ進む
3. 2 番目の p を α / (m − 1) と比べる。小さければ有意として、次へ進む
4. 以下同じように進め、**有意にならなかったところで止める**（それより後はすべて有意でない）

JASP の p_holm は、これを「p に (m − 順位 + 1) を掛けた値」で表したもの（前の値より小さくならないように調整し、1 を超えたら 1 にする）。p_holm < .05 なら有意と読めばよい。

**架空の例**（m = 3、α = .05）

| 順位 | 元の p | 掛ける数 | p_holm | 判断 |
|---|---|---|---|---|
| 1 | .004 | × 3 | .012 | 有意 |
| 2 | .020 | × 2 | .040 | 有意 |
| 3 | .300 | × 1 | .300 | 有意でない |

Bonferroni なら 2 番目は .020 × 3 = .060 で有意にならない。Holm は、間違って有意と言ってしまう確率を Bonferroni と同じく 5% に抑えたまま、差を見つけやすい。

### 8.5 自由度

事後比較は、2 条件の差を被験者ごとに計算した対応のある t 検定なので、df = n − 1 = **8**。

### 8.6 Cohen's d の大きさ

Cohen's d は「2 条件の平均の差が SD の何倍か」。よく使われる目安は Cohen（1988）の **0.2 = 小、0.5 = 中、0.8 = 大**。

**反復測定では d に種類がある**（差を何の SD で割るか）。RT（9 名）の例（AI が CSV から計算）：

| 比較 | 平均の差 | d_z（差の SD で割る） | d_av（2 条件の SD の平均で割る） |
|---|---|---|---|
| Go/Stop − Simple | 37.6 ms | 37.6 / 20.8 = 1.81 | 37.6 / 23.3 = 1.61 |
| Go/No-Go − Simple | 12.7 ms | 12.7 / 18.7 = 0.68 | 12.7 / 26.3 = 0.48 |

- **d_z**：被験者ごとの差のばらつきで割る。d_z = t / √n。個人差を除くので大きめになりやすい
- **d_av**：各条件の SD（個人差を含む）で割る。別々の人を比べる研究の d に近く、比べやすい
- Cohen の目安は、もともと別々の群の比較を想定している。d_z にそのまま当てはめると、効果を大きく見積もりがち
- **JASP（0.98.1）の RM-ANOVA の事後比較の d**：表の注には書かれていないが、9 名の結果で検算すると、**平均の差 / √（全条件の分散の平均）**だった。RT の Simple–Go/Stop は 37.61 / √{(22.42² + 30.12² + 24.17²) / 3} = 37.61 / 25.78 = 1.46（表は −1.459）。MT でも一致した。個人差を含む SD で割るので d_av に近く、d_z（1.81）より小さい（2026-11-02 確認）
- 論文では、どの d を使ったかを書く
- 0.2・0.5・0.8 は、ほかに手がかりがないときの目安。できれば同じような課題の先行研究の効果量と比べる

## 9. Nonparametrics：Friedman 検定

```
Factor     X²F    df  p      Kendall's W
Condition  14.22  2   <.001  0.7901
```

### 9.1 何をしているか

Friedman 検定は、値そのものではなく、**被験者ごとに条件の順位**（例：その人の中でいちばん速い条件を 1 位）をつけて比べる。正規分布や球面性を仮定しないので、RM-ANOVA の結果が前提のずれに左右されていないかの確認に使う。詳しくは [技術説明.md](技術説明.md) の 11.6 節。

### 9.2 列

| 列 | 意味 |
|---|---|
| **X²F** | Friedman の検定統計量。条件ごとの順位の合計が、偶然に期待されるより偏っているほど大きくなる |
| **df** | k − 1 = 2 |
| **p** | 「どの条件も順位に偏りがない」という帰無仮説の検定 |
| **Kendall's W** | 一致係数。被験者の間で条件の順位の並びがどれだけそろっているか。0（ばらばら）〜 1（全員が同じ順） |

Kendall's W = X²F / {n(k − 1)} = 14.22 / (9 × 2) = **0.790**。9 名の多くが同じ順（Simple < Go/No-Go < Go/Stop）で RT が並んでいることを示す。

### 9.3 RT の読み取り

χ²F(2) = 14.22、p < .001 で、RM-ANOVA と同じく条件の差がある。前提を置かない検定でも結論が変わらないので、RM-ANOVA の結果は前提のずれに左右されていないと考えてよい。

## 11. 報告の書き方

df は 2 つ（条件・残差）を書く。補正した場合は、補正後の df（小数）を書き、どの補正を使ったかを方法に書く。

**RT の例**

> RT は条件の主効果が有意であった（*F*(1.37, 10.92) = 11.14, *p* = .004, η²p = .58；Greenhouse-Geisser 補正）。

**方法に書くこと**

- 被験者ごとの条件の平均値を用いたこと、人数（9 名）と除外した被験者・理由
- 球面性の検定（Mauchly）と、Greenhouse-Geisser 補正を用いたこと
- 事後比較の方法（対応のある t 検定、Holm の方法）
- 効果量の種類（η²p）
- 有意水準（α = .05）

## 12. この研究で注意すること

- **人数が少ない（9 名）**：有意にならなかった指標は「差がない」ではなく「差があるとは言えない」と書く。8 名と 9 名で結論が変わる比較（例：8 名では有意でなかった組）は、確定した結果として扱わない
- **S04 は Mark = k の試行だけ**：top を使う指標（MT・HookTime・LoopTime・AccelTime・PeakVelTop）では、S04 の値は 1 条件 3〜5 試行の平均。RT・PeakFz は床反力から求めるので、この影響はない
- **指標が 7 つある**：指標の間では多重比較の補正をしていない。主な仮説に関わる指標（MT・HookTime など）と、確認のための指標を分けて考える
- **η² と η²p**：要因が 1 つなので同じ値だが、論文では η²p と書く
- **8 名の結果との比較**：2026-10-29 の 8 名の結果は `RM-ANOVA_2026-1029.jasp`。RT は 8 名で *F*(1.39, 9.74) = 8.37, *p* = .012, η²p = .55 だった
