## 1. この研究デザインの特徴（統計を選ぶ前に）

この研究では、**同じ参加者（約20名）が4つの条件すべてを体験します**。

| 条件  | 内容         |
| ----- | ------------ |
| 条件1 | 自由スイング |
| 条件2 | 単純反応課題 |
| 条件3 | Go/Nogo課題  |
| 条件4 | Go/Stop課題  |

> **ポイント**: 「同じ人が全条件に参加する」デザインを **反復測定デザイン（repeated measures design）** と呼びます。これは、「人によってスイングが速い・遅いという個人差」が全条件で同じように影響するため、その個人差をうまく取り除いて「条件の効果だけ」を比べやすくなるという利点があります。

---

## 2. 主な統計手法の全体像

```
データ取得
   ↓
【前提チェック】正規性・球面性の確認
   ↓
【主分析】反復測定分散分析（RM-ANOVA）
   ↓（有意差が出た場合）
【事後検定】多重比較（Bonferroni補正）
   ↓
【効果の大きさ】効果量（η²p）の報告
```

---

## 3. 反復測定分散分析（RM-ANOVA）

### 3.1 なぜ使うのか？

4条件の平均値を比べるとき、「どれかの条件間に差がある」かどうかを検定したい。

- 2条件の比較なら **t検定** を使うが、4条件を一気に比べるには **分散分析（ANOVA）** を使う。
- さらに「同じ人が全条件に参加」しているので、通常のANOVAではなく **反復測定分散分析（RM-ANOVA）** を使う。

> **イメージ**: t検定が「2チームの平均点を比べる」なら、RM-ANOVAは「同じ選手が4種類の練習を受けたとき、どの練習が最も効果的か」を比べる手法です。

### 3.2 何を比べているのか？

RM-ANOVAは、次のことを検定します：

- **帰無仮説（H₀）**: 4条件すべての平均値は等しい（条件による差はない）
- **対立仮説（H₁）**: 少なくとも1つの条件間に差がある

### 3.3 F値とp値の解釈

RM-ANOVAを行うと **F値** と **p値** が計算されます。

| 指標          | 意味                                                                     |
| ------------- | ------------------------------------------------------------------------ |
| **F値** | 「条件間のばらつき」÷「測定誤差のばらつき」。大きいほど条件の効果が強い |
| **p値** | 「もし本当に差がないとしたら、この結果が偶然起こる確率」                 |

**判断基準**:

- p < 0.05 → 有意差あり（条件間に差がある）
- p ≥ 0.05 → 有意差なし（差があるとは言えない）

> **有意水準 α = 0.05** とは、「5%の確率で間違いを犯してよい」という判断基準です。慣習的にスポーツ科学・バイオメカニクス研究でよく使われます。

## 4. 前提条件の確認（検定の前に必ずチェック！）

RM-ANOVAが正しく機能するには、2つの前提条件を満たす必要があります。

### 4.1 正規性（Normality）

**意味**: データが「正規分布（釣り鐘型の分布）」に従っているか。

**確認方法**:

- **Shapiro-Wilk検定** を各条件・各従属変数に対して実施
- p > 0.05 → 正規性あり（問題なし）
- p < 0.05 → 正規性に問題あり → **Friedman検定**（後述）を検討

**補足**: サンプルサイズが20名程度と小さいため、正規性の確認は特に重要です。

### 4.2 球面性（Sphericity）

**意味**: 4条件すべての「条件間の分散の差」が均等かどうか。反復測定特有の前提条件。

**確認方法**:

- **Mauchly検定** を実施
- p > 0.05 → 球面性が成立（問題なし）
- p < 0.05 → 球面性が崩れている → **Greenhouse-Geisser補正**を適用する

> **Greenhouse-Geisser補正**: 球面性が崩れていても分析を続けられるよう、F値の自由度を調整する補正方法。SPSSやRでは自動的に計算されます。

---

## 5. 多重比較（Post-hoc検定）: Bonferroni補正

### 5.1 なぜ必要か？

RM-ANOVAで「どこかの条件間に差がある」ことはわかっても、**どの条件とどの条件の間に差があるか**はわかりません。それを調べるのが多重比較です。

ただし、4条件の総当たりで比較すると合計 **6通り**（4C2 = 6）の比較が生まれます。それぞれでα = 0.05を使うと、全体的な間違いの確率が膨らんでしまいます（**多重比較問題**）。

### 5.2 Bonferroni補正の仕組み

有意水準を比較の数で割ることで、全体の誤り率を α に保つ方法です。

```
補正後の有意水準 = α ÷ 比較の数 = 0.05 ÷ 6 ≈ 0.0083
```

つまり、各ペアの比較では **p < 0.0083** のときにのみ有意と判断します。

> **保守的な手法**: Bonferroni補正はやや厳しめの基準ですが、間違いを犯しにくい（偽陽性が少ない）という点で信頼性が高く、バイオメカニクス研究でよく使われます。

---

## 6. 効果量（偏イータ二乗 η²p）

### 6.1 なぜ効果量が必要か？

p値は「差があるかどうか」はわかりますが、「差がどのくらい大きいか」はわかりません。サンプルサイズが大きければ、ほんの少しの差でもp < 0.05になってしまいます。効果量は、差の「実際の大きさ」を表す指標です。

### 6.2 η²p（偏イータ二乗）の計算と解釈

```
η²p = 条件によるばらつき ÷ (条件によるばらつき + 誤差のばらつき)
```

| η²p の値 | 効果の大きさ |
| ---------- | ------------ |
| 0.01       | 小（small）  |
| 0.06       | 中（medium） |
| 0.14       | 大（large）  |

> η²p = 0.35 なら「4条件の違いが、データのばらつきの35%を説明している」という意味です。

## 7. サンプルサイズ（参加者数）の決め方

この研究では **約20名** の参加者を設定していますが、これは **検定力分析（Power Analysis）** によって算出されています。

| 指標               | 設定値 | 意味                               |
| ------------------ | ------ | ---------------------------------- |
| Cohen's f          | 0.35   | 想定する効果量（中〜大）           |
| α（有意水準）     | 0.05   | 第1種の誤り（偽陽性）の許容確率    |
| 1−β（検定力）    | 0.80   | 本当に差があるときに検出できる確率 |
| 必要サンプルサイズ | 約18名 | → 保守的に20名に設定              |

> **G\*Power** というフリーソフトを使うと、上記の値から必要なサンプルサイズを簡単に計算できます（RM-ANOVA, Within factors で設定）。

## 8. 正規性が保てない場合の代替手法

もし正規性検定（Shapiro-Wilk）でデータが正規分布に従わないことが判明した場合、RM-ANOVAの代わりに**ノンパラメトリック検定**を使います。

| 場面                             | 手法                                            |
| -------------------------------- | ----------------------------------------------- |
| 4条件の比較（RM-ANOVAの代替）    | **Friedman検定**                          |
| 事後検定（Bonferroni補正の代替） | **Wilcoxon符号順位検定 + Bonferroni補正** |
| 効果量                           | Kendall's W（Friedman検定用）                   |

> ノンパラメトリック検定はデータの順位を使うため、正規分布の前提を必要としません。ただし一般的に検出力はやや低くなります。

### 11.1 反復測定分散分析（RM-ANOVA）の詳細

#### 「分散分析」とは何を分析しているのか？

分散分析（ANOVA）は、「データのばらつきの原因を分解する」手法です。
データがばらつくのは、大きく3つの原因があります。

```
データ全体のばらつき（全変動）
  ├─ ① 条件の違いによるばらつき（条件間変動）← 知りたいもの
  ├─ ② 人による個人差（個人差変動）← 反復測定で取り除ける
  └─ ③ それ以外の偶然のばらつき（誤差変動）
```

**F値**は「条件間変動 ÷ 誤差変動」で計算されます。
条件の効果が大きいほど、F値は大きくなります。

```
F = 条件間変動 / 誤差変動
```

#### 通常のANOVAとRM-ANOVAの違い

| 手法                           | 誤差の扱い                                                          |
| ------------------------------ | ------------------------------------------------------------------- |
| 通常のANOVA（対応なし）        | 個人差が誤差に含まれてしまう → F値が小さくなりやすい               |
| **RM-ANOVA（対応あり）** | 個人差を誤差から取り除く → F値が大きくなりやすく、差を検出しやすい |

> **例**: 参加者Aはもともとスイングが速く、参加者Bは遅いとします。RM-ANOVAは「AもBも全条件に参加している」ことを利用して、この個人差を計算から除外できます。通常のANOVAでは除外できないため、検出力が下がります。

#### 具体的なイメージ（架空の数値例）

以下は、3名の参加者・3条件での反応時間（ms）を簡略化した例です。

| 参加者         | 自由スイング  | 単純反応      | Go/Nogo       |
| -------------- | ------------- | ------------- | ------------- |
| Aさん          | 400           | 350           | 420           |
| Bさん          | 300           | 250           | 320           |
| Cさん          | 500           | 450           | 520           |
| **平均** | **400** | **350** | **420** |

- 各条件の**平均値の差**（400, 350, 420）が「条件間変動」に対応します。
- AさんはBさんより常に100ms速いという「個人差」は、RM-ANOVAで除外されます。
- 残った誤差（各自の条件内のばらつき）だけを分母に使うため、差を検出しやすくなります。

#### 自由度について

RM-ANOVAのF値には「自由度（df）」が伴います。出力例：

```
F(3, 57) = 8.45, p < .001
```

- `3` = 条件の自由度（条件数 − 1 = 4 − 1 = 3）
- `57` = 誤差の自由度（(条件数 − 1) × (参加者数 − 1) = 3 × 19 = 57）

##### 【補足】誤差の自由度 `(k−1)(n−1)` はなぜこの式になるのか？

誤差の自由度は直感的にわかりにくいため、ここで丁寧に導出します。

---

**前提：RM-ANOVA の「誤差」とは何か**

RM-ANOVA では、全体のばらつきを以下の3つに分解します。

```
全変動（df = nk − 1）
 ├─ ① 参加者間変動（df = n − 1）  ← 個人差
 └─ ② 参加者内変動（df = n(k−1)）
      ├─ ② -a 条件間変動（df = k − 1）  ← 知りたい効果
      └─ ② -b 誤差変動（df = ?）        ← 残り
```

誤差の自由度は「参加者内変動の df」から「条件間変動の df」を引いた残りです。

```
df_誤差 = n(k−1) − (k−1) = (n−1)(k−1)
```

---

**直感的な導出：20人 × 4条件の表で考える**

20名 × 4条件のデータを、以下のような表として考えます。

|                    | 条件1 | 条件2 | 条件3 | 条件4 | 行平均（個人差） |
| ------------------ | :---: | :---: | :---: | :---: | :--------------: |
| 参加者 1           |  ・  |  ・  |  ・  |  ・  |       固定       |
| 参加者 2           |  ・  |  ・  |  ・  |  ・  |       固定       |
| ︙                 |      |      |      |      |                  |
| 参加者20           |  ・  |  ・  |  ・  |  ・  |       固定       |
| 列平均（条件効果） | 固定 | 固定 | 固定 | 固定 |     全体平均     |

誤差を計算する段階では、**個人差（行平均）と条件効果（列平均）はすでに取り除かれています**。
その結果、表のセルに次の2種類の制約がかかります。

**制約① 各行の制約（参加者内）**

各参加者の行平均は固定されているため、4つのセルのうち **3つが決まれば4つ目は自動的に決まります**。

```
1参加者あたりの自由度 = k − 1 = 3
```

**制約② 各列の制約（条件間）**

各条件の列平均も固定されているため、20人分の値のうち **19人分が決まれば残り1人分は自動的に決まります**。

```
参加者方向の自由度 = n − 1 = 19
```

**2つの制約を組み合わせる**

「各参加者につき3の自由度」が、独立に「19人分」ある、と考えます。

```
df_誤差 = (k − 1) × (n − 1) = 3 × 19 = 57
```

---

**総当たりで確認（全 df の内訳）**

| 変動の種類                       | 計算                           |      df      |
| -------------------------------- | ------------------------------ | :----------: |
| 全変動                           | nk − 1 = 20×4 − 1           |      79      |
| 参加者間変動（個人差）           | n − 1 = 19                    |      19      |
| 条件間変動                       | k − 1 = 3                     |      3      |
| **誤差変動**               | **(n−1)(k−1) = 19×3** | **57** |
| 合計（参加者間 + 条件間 + 誤差） | 19 + 3 + 57                    |    79 ✓    |

合計が全変動（79）と一致することで、計算が正しいことを確認できます。

---

> **まとめ**: 誤差の自由度 `(k−1)(n−1)` は、「個人差と条件効果を両方取り除いた後に、表の中に残る自由なセルの数」です。参加者方向に `(n−1)`、条件方向に `(k−1)` の自由度が掛け合わさった形になります。

### 11.2 正規性検定（Shapiro-Wilk検定）の詳細

#### 正規分布とは？

正規分布は「平均値を中心に、左右対称の釣り鐘型になる分布」です。多くの生物学的・心理学的データがこの分布に従いやすいとされています。

```
度数
 |        ****
 |      **    **
 |    **        **
 |  **            **
 |**                **
 +---------------------- 値
           ↑
          平均
```

#### Shapiro-Wilk検定の仕組み

「もし正規分布に従っているなら、こういうデータになるはず」という期待値と実際のデータを比較して、どのくらいずれているかをW統計量で表します。

- **W の値は0〜1の範囲をとる**
- W が1に近い → 正規分布に近い
- W が小さい → 正規分布からずれている

| 判断                   | 基準      |
| ---------------------- | --------- |
| 正規性あり（問題なし） | p > 0.05  |
| 正規性に問題あり       | p ≤ 0.05 |

#### QQプロット（視覚的な確認方法）

数値だけでなく、**QQプロット（Quantile-Quantile Plot）** でも正規性を視覚確認できます。

- 点が対角線（45°の直線）に沿っている → 正規分布に従っている
- 点が大きく曲がっている → 正規分布から外れている

> 統計初心者でも、QQプロットを見ることで直感的に正規性を判断できます。RやMATLABで簡単に描けます。

#### 注意点

- **サンプルサイズが小さいとき（n < 30）**：Shapiro-Wilk検定は特に有効です（この研究ではn ≈ 20なので使用を推奨）。
- **サンプルサイズが大きいとき（n > 100）**：ほんのわずかな逸脱でもp < 0.05になりやすいため、グラフでの確認が重要です。

### 11.3 球面性（Sphericity）と補正の詳細

#### 球面性とは何か？

球面性とは、「4条件のあらゆるペアの差スコアの分散が等しい」という条件です。

たとえば、4条件(A, B, C, D)があるとき、

- 「A−B の差スコアの分散」= 「A−C の差スコアの分散」= 「B−D の差スコアの分散」= ……

これらがすべて等しいときに「球面性が成立している」と言います。

> **なぜ「球面性」という名前か**：この条件を満たす共分散行列の形状が、数学的に「球体」になることに由来します（直感的には難しいですが、名前の由来として覚えておくと良いです）。

#### Mauchly検定

球面性が成立しているかどうかを Mauchly検定で確認します。

- p > 0.05 → 球面性OK → RM-ANOVAをそのまま実施
- p ≤ 0.05 → 球面性違反 → 補正が必要

#### Greenhouse-Geisser補正（ε 補正）

球面性が崩れているとき、RM-ANOVAのF検定は「差があると言い過ぎる（偽陽性が増える）」傾向があります。この偏りを修正するのがGreenhouse-Geisser補正です。

**ε（イプシロン）**という係数を使って自由度を小さく調整することで、より保守的なp値を計算します。

| ε の値       | 意味                           |
| ------------- | ------------------------------ |
| ε = 1.0      | 球面性が完全に成立（補正不要） |
| ε = 0.5〜1.0 | 軽度〜中度の球面性違反         |
| ε < 0.75     | 重度の球面性違反（補正必須）   |

> **Huynh-Feldt補正**：ε が 0.75 以上の場合、Greenhouse-Geisserよりも寛容な Huynh-Feldt補正を使うことも多いです。どちらを使うかは研究分野の慣習によりますが、バイオメカニクス研究ではGreenhouse-Geisserが安全とされます。

### 11.4 多重比較問題とBonferroni補正の詳細

#### 多重比較問題（Multiple Comparisons Problem）

同じデータに対して複数の検定を繰り返すと、「本当は差がないのに差があると誤判断する確率（第1種の誤り）」が累積して増えていきます。

1回の検定でα = 0.05とすると、「正しく判断できる確率」は 0.95 です。
k回の独立した検定を行うと：

```
少なくとも1回誤判断する確率 = 1 − (0.95)^k

k = 1 の場合：1 − 0.95^1 = 5.0%
k = 6 の場合：1 − 0.95^6 ≈ 26.5%  ← 4条件の総当たりでは6比較
```

つまり **何もしなければ、26.5%の確率で「偽の有意差」を見つけてしまいます**。

#### Bonferroni補正の考え方

**Family-Wise Error Rate（FWER）**を α = 0.05 以下に抑えるために、各比較の有意水準を厳しくします。

```
補正後の有意水準 = α ÷ 比較の数（k）
                 = 0.05 ÷ 6
                 ≈ 0.0083
```

この基準で各ペアを判断することで、全体的な誤判断の確率を5%以下に保てます。

#### 他の多重比較法との比較

| 手法                      | 特徴                                                 |
| ------------------------- | ---------------------------------------------------- |
| **Bonferroni補正**  | 最もシンプルで保守的。比較数が少ない場合に適している |
| Holm法（Holm-Bonferroni） | Bonferroniより少し寛容。検出力が若干高い             |
| Tukey HSD                 | 全ペア比較に特化。比較数が多い場合に効率的           |
| Šidák補正               | Bonferroniより若干寛容で数学的に正確                 |

> この研究では先行研究（Kida et al., 2005; Nakamoto & Mori, 2008）に倣いBonferroni補正を採用しています。

### 11.5 効果量（η²p）の詳細

#### 「統計的有意性」と「効果の大きさ」は別物

- **p値**：「差が偶然でない確率」を表す。サンプルサイズが増えると小さくなりやすい。
- **効果量**：「差がどれくらい大きいか」を表す。サンプルサイズに依存しない。

> **例**: n = 1000 のとき、ほんの 1ms の反応時間差でも p < 0.05 になりえます。でもその差は実際には意味がない（臨床的・実用的に重要でない）かもしれません。効果量はこの「意味の大きさ」を教えてくれます。

#### η²（イータ二乗）と η²p（偏イータ二乗）の違い

| 指標                  | 計算式                          | 特徴                           |
| --------------------- | ------------------------------- | ------------------------------ |
| η²                  | 条件間SS ÷ 全体SS              | 全ての変動成分を分母に含む     |
| **η²p（偏）** | 条件間SS ÷ (条件間SS + 誤差SS) | 注目する効果だけに焦点を当てる |

RM-ANOVAでは、通常 **η²p** を使います。
（η² より η²p の方が値が大きくなりやすい点に注意してください）

#### 効果量の解釈基準（Cohen, 1988）

| η²p の値 | 効果量       | 目安                                     |
| ---------- | ------------ | ---------------------------------------- |
| 0.01       | 小（small）  | 小さな効果。注意しないと見逃すくらいの差 |
| 0.06       | 中（medium） | 日常的に目で見てわかる程度の差           |
| 0.14       | 大（large）  | 明らかに大きな差                         |

#### Cohen's f との関係

サンプルサイズ計算（G*Power）では **Cohen's f** を使います。η²p から変換できます。

```
Cohen's f = √( η²p ÷ (1 − η²p) )

例: η²p = 0.11 のとき
f = √(0.11 ÷ 0.89) ≈ √0.124 ≈ 0.35（中程度〜大）
```

---

### 11.6 Friedman検定の詳細（ノンパラメトリック版RM-ANOVA）

#### 【前提】ノンパラメトリック検定とは何か？

「ノンパラメトリック（non-parametric）」という言葉は、**「パラメータ（parameter）を仮定しない」** という意味です。

**パラメータとは**、分布の形を決める数値のことです。たとえば正規分布は「平均 μ」と「標準偏差 σ」という2つのパラメータで形が決まります。

```
パラメトリック検定  → 「データは正規分布に従っている」と仮定して計算する
ノンパラメトリック検定 → 分布の形を一切仮定しない
```

分布を仮定しないために、**実際の数値ではなく「順位（ランク）」に変換してから計算します**。たとえば反応時間「290ms, 320ms, 380ms, 410ms, 500ms」という数値は、「1位, 2位, 3位, 4位, 5位」という順位に置き換えられます。順位だけを使うので、データの分布の形がどんな形であっても計算が成り立ちます。

| | パラメトリック検定（RM-ANOVA） | ノンパラメトリック検定（Friedman検定） |
|---|---|---|
| 分布の仮定 | 正規分布を仮定する | 仮定しない |
| 使うデータ | 実際の数値 | 順位に変換した値 |
| 検出力 | 高い | やや低い |
| 使う場面 | 正規性が成立しているとき | 正規性が崩れているとき |

> **一言まとめ**: データの分布の形を問わず使える、より汎用的な検定手法がノンパラメトリック検定です。ただし、正規性が成立しているときはパラメトリック検定の方が検出力が高いため、まずRM-ANOVAを試みるのが基本です。

---

#### 正規分布を仮定しない検定

Friedman検定は、データが正規分布に従わない場合に使う **ノンパラメトリック検定** です。
実際の数値ではなく、**順位（ランク）** に変換してから分析します。

#### 順位変換の仕組み

各参加者について、4条件のデータを小さい順に順位をつけます。

| 参加者                | 自由スイング | 単純反応    | Go/Nogo     | Go/Stop     |
| --------------------- | ------------ | ----------- | ----------- | ----------- |
| Aさん（元データ: ms） | 400          | 350         | 420         | 440         |
| Aさん（順位）         | **2**  | **1** | **3** | **4** |
| Bさん（元データ: ms） | 300          | 260         | 310         | 340         |
| Bさん（順位）         | **2**  | **1** | **3** | **4** |

このように各人の中で順位をつけ、全参加者の順位の平均を条件ごとに比較します。

#### 検定統計量（χ²統計量）

Friedman検定は **χ²（カイ二乗）統計量** を使って判断します。

```
χ²(df) = 値, p = 値
df = 条件数 − 1 = 3
```

p < 0.05 → 有意差あり → 事後検定へ（Wilcoxon符号順位検定 + Bonferroni補正）

#### RM-ANOVAとFriedman検定の比較

| 比較項目     | RM-ANOVA                 | Friedman検定           |
| ------------ | ------------------------ | ---------------------- |
| 正規性の前提 | 必要                     | 不要                   |
| 使用する情報 | 実際の数値               | 順位                   |
| 検出力       | 高い                     | やや低い               |
| 使う場面     | 正規性が成立している場合 | 正規性が崩れている場合 |

> **結論**: まず正規性を確認してRM-ANOVAを試みるのが基本方針です。正規性が保てない場合のみFriedman検定に切り替えます。

## 12. その他に考えられる統計手法

> ここでは、RM-ANOVA 以外にこの研究デザイン（反復測定・4条件・n≈20）に適用できる統計手法を紹介します。
> それぞれの「どんな手法か」「メリット」「デメリット」を整理しています。

---

### 12.1 線形混合効果モデル（Linear Mixed Model; LMM）

#### どんな手法か

RM-ANOVA の発展版です。「参加者の個人差」を**ランダム効果**として明示的にモデルに組み込むことで、より柔軟な分析が可能になります。Rの `lme4` パッケージや SPSS の「混合モデル」で実行できます。

```
反応時間 = 条件の効果（固定効果）+ 個人差（ランダム効果）+ 誤差
```

| 項目 | 内容 |
|------|------|
| **メリット** | ・欠損データがあっても分析できる（RM-ANOVAは欠損で参加者ごと除外される）<br>・球面性の仮定が不要<br>・繰り返し測定の相関構造を細かく指定できる |
| **デメリット** | ・設定項目が多く、初学者には難しい<br>・どのランダム効果を入れるか判断が必要<br>・RM-ANOVAより解釈の説明が複雑になる |

> **この研究への適用可否**: 欠損データが生じた場合や、球面性が崩れた場合の代替として有力。ただし n ≈ 20 では収束が不安定になる場合もある。

---

#### 【補足】なぜ LMM は欠損データに対応できて、RM-ANOVA はできないのか？

##### RM-ANOVA が欠損データに対応できない理由

RM-ANOVA は、すべての参加者が**すべての条件のデータを持っている**ことを前提に計算しています。

その理由は、RM-ANOVA の計算の核心が「**参加者ごとに全条件を比べること**」にあるからです。具体的には、「各参加者の全条件の平均（行平均）」を計算して個人差を取り除く操作が行われます。

```
参加者Aの行平均 = (条件1 + 条件2 + 条件3 + 条件4) ÷ 4
```

ここで条件3のデータが欠損していると、この計算自体ができなくなります。

```
参加者Aの行平均 = (条件1 + 条件2 + ？ + 条件4) ÷ 4  ← 計算不能
```

そのため RM-ANOVA では、**1つでも欠損がある参加者はデータ全体を丸ごと除外**するしかありません（これを「リストワイズ除去（listwise deletion）」と呼びます）。

たとえば 20 名のうち 3 名が 1 条件でも欠損していれば、実質 17 名分のデータしか使えず、検出力が下がります。

---

##### LMM が欠損データに対応できる理由

LMM は RM-ANOVA とは根本的に計算の構造が異なります。LMM は、「**あるデータが得られたとすると、パラメータ（条件の効果・個人差の大きさ）はどんな値であるはずか**」を推定する枠組みです。

```
観測されたデータ = 条件の効果 + 個人差 + 誤差
               ↑ここを最尤推定（または REML）で求める
```

この推定方法（最尤推定法）は、**「手元にあるデータだけ」から最もありそうなパラメータを計算します**。欠損しているデータは計算に使わないだけで、残りのデータは捨てずに活かせます。

具体的なイメージで比べると：

| | RM-ANOVA | LMM |
|---|---|---|
| 欠損がある参加者 | **全条件のデータを丸ごと除外** | 残りの条件のデータは使い続ける |
| 計算の考え方 | 「表の各セルを埋めてから計算」 | 「手元のデータから直接パラメータを推定」 |

---

##### 具体例で確認する

参加者Aが条件3だけ欠損しているとします。

| 参加者 | 条件1 | 条件2 | 条件3 | 条件4 |
|--------|:----:|:----:|:----:|:----:|
| A | 400 | 350 | **欠損** | 440 |
| B | 300 | 260 | 310 | 340 |
| ... | ... | ... | ... | ... |

- **RM-ANOVA の場合** → 参加者Aの行を丸ごと除外。条件1・2・4のデータも捨てられる。
- **LMM の場合** → 参加者Aの条件1・2・4のデータはそのまま使う。条件3だけが推定に参加しないだけ。

LMM ではこの「欠損を無視して残りを使う」操作が、最尤推定という数学的に正当な方法で行われるため、**恣意的な補完や除外をせずに済みます**。

---

> **まとめ**: RM-ANOVA は「全条件が揃った表」を前提とした手法なので、1つでも欠損があると参加者ごと除外するしかありません。LMM は「手元にあるデータからパラメータを直接推定する」手法なので、欠損があっても残りのデータを無駄なく活かせます。

---

### 12.2 多変量分散分析（MANOVA）

#### どんな手法か

複数の従属変数（例：反応時間・スイングスピード・床反力）を**同時に**分析する手法です。各変数を個別にRM-ANOVAするのではなく、変数間の相関も考慮しつつ条件の効果を検定します。

| 項目 | 内容 |
|------|------|
| **メリット** | ・複数の従属変数を一括検定できる<br>・変数間の相関を利用するため、情報損失が少ない<br>・第1種の誤りの累積を抑えられる |
| **デメリット** | ・サンプルサイズが従属変数の数より十分大きくないと機能しない（n ≈ 20 では変数を増やすと不安定）<br>・球面性の仮定の代わりに「多変量正規性」が必要<br>・解釈が難しく、どの変数が効いているか見えにくい |

> **この研究への適用可否**: 従属変数が多い場合には検討できるが、n ≈ 20 では変数が増えると検出力が下がるリスクがある。現在の方針（各変数を独立にRM-ANOVA）が安全。

---

### 12.3 ベイズ的アプローチ（Bayes Factor）

#### どんな手法か

従来の「p値による有意性検定（頻度論）」とは異なり、**「差がある仮説」と「差がない仮説」のどちらが、データによってより支持されるか**を比率（Bayes Factor; BF）で表す手法です。Rの `BayesFactor` パッケージや JASP（無料ソフト）で実行できます。

```
BF₁₀ = 「差あり仮説」を支持する度合い ÷ 「差なし仮説」を支持する度合い
BF₁₀ > 3  → 差ありを支持する証拠あり
BF₁₀ < 1/3 → 差なしを支持する証拠あり
```

| 項目 | 内容 |
|------|------|
| **メリット** | ・「差がない」ことも積極的に証明できる（p値では「差がないとは言えない」としか言えない）<br>・サンプルサイズが小さいときに特に有用<br>・事前情報（先行研究の効果量など）を取り込める |
| **デメリット** | ・事前分布（prior）の設定が結果に影響するため、設定の根拠が必要<br>・スポーツ科学・バイオメカニクス分野ではまだ普及度が低い<br>・解釈に慣れが必要 |

> **この研究への適用可否**: n ≈ 20 の小サンプルでは特に有用。「条件間に差がない」という結果が出た場合に、p値より説得力のある証拠を示せる。補完的な分析として有望。

---

### 12.4 順列検定（Permutation Test）

#### どんな手法か

「もし条件間に本当に差がないなら、データをランダムに並べ替えても同じような結果になるはず」という考え方に基づく手法です。正規分布などの分布の仮定を一切置きません。

```
① 実際のデータで統計量（F値など）を計算する
② データをランダムにシャッフルして統計量を何千回も計算する
③ 実際の統計量が、シャッフル分布の上位5%に入るか確認する
```

| 項目 | 内容 |
|------|------|
| **メリット** | ・正規性・球面性などの分布の仮定が不要<br>・サンプルサイズが小さくても使える<br>・直感的に理解しやすい原理 |
| **デメリット** | ・計算量が多い（数千〜数万回のシミュレーション）<br>・ソフトウェアの設定が必要（RやMATLABで実装）<br>・多重比較の調整方法が複雑になる場合がある |

> **この研究への適用可否**: 正規性が崩れていてFriedman検定でも不十分な場合の代替として使える。ただし実装コストが高いため、通常は最後の手段。

---

### 12.5 手法の選択ガイド（まとめ）

```
データが揃っている（欠損なし）
  ├─ 正規性 OK & 球面性 OK  → RM-ANOVA（推奨）
  ├─ 正規性 OK & 球面性 NG  → RM-ANOVA + Greenhouse-Geisser補正
  └─ 正規性 NG
       ├─ 軽度の逸脱         → RM-ANOVA（頑健性あり）
       └─ 重度の逸脱         → Friedman検定 or 順列検定

補完的に使いたい
  ├─ 「差がない」ことも証明したい → Bayes Factor（BF）
  └─ 複数の従属変数を同時検定    → MANOVA（n が十分な場合のみ）

欠損データがある
  └─ 線形混合効果モデル（LMM）
```

| 手法 | 正規性の仮定 | 欠損対応 | 解釈のしやすさ | この研究での優先度 |
|------|:-----------:|:-------:|:------------:|:--------------:|
| RM-ANOVA | 必要 | 不可 | ◎ | **第1候補** |
| Friedman検定 | 不要 | 不可 | ○ | 正規性NG時 |
| 線形混合効果モデル | 必要 | 可 | △ | 欠損発生時 |
| Bayes Factor | 必要 | 不可 | △ | 補完的に |
| MANOVA | 必要 | 不可 | △ | 変数統合時 |
| 順列検定 | 不要 | 不可 | ○ | 最終手段 |
