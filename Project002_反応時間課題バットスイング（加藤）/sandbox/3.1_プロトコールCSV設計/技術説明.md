# プロトコールCSV生成システム 技術説明

本ドキュメントは、反応時間課題バットスイング実験におけるプロトコールCSV生成スクリプト（`generate_protocol.m`）の技術的な仕様をまとめたものです。

## 1. カラム定義と意図

生成されるCSVファイルは以下のカラムを含みます。1行が1試行に対応します。

| カラム名 | 型 | 説明 | 意図・備考 |
|----------|----|------|------------|
| `trial_id` | int | 通し試行番号（1始まり） | 実験全体を通しての連番 |
| `block_id` | int | ブロック番号（1始まり） | 休憩の単位などとなるブロック。条件×フェーズ（練習/本番）ごとにインクリメントされる |
| `trial_in_block` | int | ブロック内試行番号（1始まり） | 現在のブロック内で何試行目か |
| `condition` | str | 実験条件 | `no_stimulus` (刺激なし), `simple_reaction` (単純反応), `go_nogo` (Go/No-Go) のいずれか |
| `trial_type` | str | 試行フェーズ | `practice` (練習) または `main` (本試行) |
| `stimulus_color` | str | LED色ラベル | `none` (消灯), `white` (白: R+G+B), `green` (緑), `red` (赤)。ハードウェア上のチャンネル割り当てはCSV外のMATLABスクリプトで管理する |
| `response_required` | str | 期待される反応 | `n/a` (反応なし), `go` (振る), `nogo` (振らない)。事後解析時の正誤自動判定などに使用 |
| `isi_sec` | float | 刺激間隔（秒） | 次の刺激までの間隔。一様乱数（3.0〜6.0秒）として事前生成された値 |
| `led_duration_sec` | float | LED点灯継続時間（秒）| 刺激の提示時間。基本は0.150秒。`no_stimulus`時は0.000秒 |
| `voltage_on` | float | LED点灯電圧（V） | DAQからの制御信号電圧。基本は5.0V。`no_stimulus`時は0.0V |
| `notes` | str | 備考 | ブロックの開始時などに条件名が記述される |

## 2. ランダム化の方針

スクリプトにおけるランダム要素は以下の通りです。

- **ISI (刺激間隔)**: `isi_min_sec` (3.0秒) から `isi_max_sec` (6.0秒) の間で一様乱数として各試行ごとに生成されます。
- **Go/No-Go 試行の順序**: `go_nogo`条件におけるGoとNo-Goの提示順序は、指定された `go_ratio` (0.70) に基づいて必要な試行数を計算したのち、ブロックごとに `randperm`（シャッフル）を用いてランダムに配置されます。
- **乱数シード**: スクリプト冒頭で `rng_seed` (42) を指定することで、同一設定でのスクリプト実行時は常に同じプロトコルが再現されるようにしています。

## 3. バリデーション項目

CSV書き出し直前に、MATLABスクリプト内で以下の整合性チェックを行っています。

1. **必須カラム存在確認**: スクリプト定義のカラムと作成されたテーブルの変数名が一致しているか。
2. **`trial_id` 連番確認**: `trial_id` が 1からテーブルの行数まで連続しているか。
3. **`condition` 値確認**: 許容された3つの文字列のいずれかであるか。
4. **`trial_type` 値確認**: `practice` または `main` のいずれかであるか。
5. **`stimulus_color` 値確認**: `none`, `white`, `green`, `red` のいずれかであるか。
6. **`response_required` 値確認**: `n/a`, `go`, `nogo` のいずれかであるか。
7. **整合性確認**: 
   - `no_stimulus` では `none`
   - `simple_reaction` では `white`
   - `go_nogo` では `green` または `red`
   となっているかをチェック。
8. **ISI 範囲確認**: `isi_min_sec` 〜 `isi_max_sec` の範囲内に収まっているか。
9. **`led_duration_sec` 確認**: `no_stimulus` 条件では 0.0、それ以外は 0.150 であるか。
10. **`voltage_on` 確認**: DAQの許容出力（0〜10V）の範囲内か、かつ `no_stimulus` 条件では 0.0 であるか。

## 4. MATLABでの読み込み方法

生成したCSVファイルをMATLABで読み込み、内容を確認・活用する場合は以下のように `readtable` を用います。

```matlab
% 文字列データも適切に扱えるよう readtable を使用
opts = detectImportOptions('protocol_sample.csv');
% text型の変数をstring型として読み込むための設定（必要に応じて）
opts = setvartype(opts, {'condition', 'trial_type', 'stimulus_color', 'response_required', 'notes'}, 'string');

protocol_tbl = readtable('protocol_sample.csv', opts);

% データの確認
disp(head(protocol_tbl, 5))  % 最初の5行を表示
summary(protocol_tbl)        % 各変数のサマリを表示
```

## サンプル出力について
