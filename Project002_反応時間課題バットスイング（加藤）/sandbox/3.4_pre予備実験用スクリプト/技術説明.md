# 3.4 pre 予備実験用スクリプト　技術説明

**作成日**: 2026-05-01  
**最終更新日**: 2026-05-04  
**作成者**: mshinyalab

本ドキュメントは、反応時間課題バットスイング予備実験における刺激呈示スクリプト群の技術的仕様をまとめたものです。

---

## 1. 実験条件の概要

本予備実験は以下の3条件で構成される。

| 条件 | 内容 | 測定指標 |
|------|------|---------|
| 1. 自由スイング | 認知負荷なし・自己ペースでスイング | スイングスピード、床反力、バイオメカニクス的指標 |
| 2. 単純選択反応課題 | 緑色LED（Go cue）に反応してスイング | 反応の速さ＋上記指標 |
| 3. Go-No Go課題 | 緑色LED（Go）はスイング、赤色LED（NoGo）は抑制 | 反応の速さ・正確さ＋上記指標 |

## 3. ハードウェア構成

3.3節と同じハードウェア構成を使用する。

### 電圧出力チャンネル

**AO0**（Qualisysトリガー兼 白色LED）

| 電圧 | 機能 |
|------|------|
| +5V | Qualisysへのトリガー（TTL, positive） |
| -5V | 白色LED点灯（ready cue） |
| 0V  | 消灯 |

**AO1**（緑/赤 LED）

AO1チャンネルに緑と赤のLEDを**正負逆向きに**接続することで、電圧の正負によって点灯色を切り替える。

| 電圧 | 機能 |
|------|------|
| +5V | 緑色LED点灯（go cue） |
| -5V | 赤色LED点灯（nogo cue） |
| 0V  | 消灯 |

## 4. 実験プロトコール

### 4.1 単純選択反応課題

```
Qualisysキャプチャー開始 → Qualisysトリガー
→ 白色LED点灯（Ready cue）→（Foreperiodをランダマイズ）→ 緑色LED点灯（Go cue）
→ バットスイング
```

### 4.2 Go-No Go課題

```
Qualisysキャプチャー開始 → Qualisysトリガー
→ 白色LED点灯（Ready cue）→（Foreperiodをランダマイズ）
    → 緑色LED点灯（Go cue）  → バットスイング
    → 赤色LED点灯（NoGo cue）→ スイング抑制
```

## 5. タイミングパラメータ

| パラメータ | 変数名 | 値 |
|-----------|--------|-----|
| 最初の消灯時間 | `ini_duration` | 0.1 s |
| トリガー信号幅 | `trig_signal_duration` | 0.1 s |
| トリガー→ready 間隔 | `trig_to_ready_interval` | 1.0 s |
| ready cue 提示時間 | `ready_signal_duration` | 0.5 s |
| Foreperiod（ready→go/nogo） | `Foreperiod` | 試行ごとに可変（CSV参照） |
| go/nogo cue 提示時間 | `gonogo_signal_duration` | 0.5 s |
| 最後の消灯時間 | `off_duration` | 0.1 s |
| Enter キー待機 + カウントダウン | ― | 可変（Enter後4秒カウントダウン固定） |

> **試行間インターバルについて：** 旧実装の固定4秒ITIを廃止。  
> 代わりに各試行の開始前に Enter キー待機（Qualisys capture 準備）＋ 4秒カウントダウン（待機姿勢移行）を設けた。  
> これにより1試行＝1 capture の分割計測が可能となった。

1試行の波形総出力時間 = `ini_duration + trig_signal_duration + trig_to_ready_interval + Foreperiod + gonogo_signal_duration + off_duration` = **1.8 + Foreperiod 秒**

総波形時間（10試行） = Σ(1.8 + Foreperiod_i) = **約39.5秒**  
総実験時間（10試行） = 総波形時間 + Enter待機時間（可変） + カウントダウン40秒（10試行×4秒）

1試行のタイミング図（Foreperiod = F 秒の場合）：

```
AO0  |____|TTTTT|___________|RRRRR|_______________|_____|
AO1  |___________________________________|GGGGG|_____|

     0   0.1  0.2          1.2   1.7        1.2+F  1.2+F+0.5

凡例:
  T: +5V トリガー（Qualisys起動）
  R: -5V 白色LED（ready cue）
  G: ±5V 緑/赤LED（go/nogo cue）
  _: 0V 消灯
```

## 7. スクリプトの処理フロー

```
① パラメータ設定（電圧値・タイミング）
② CSVファイル読み込み（uigetfileでダイアログ選択）
③ DAQ初期化（AO0・AO1）
④ 試行ループ（1試行ずつ手動トリガー）：
     試行番号・CueText・Foreperiodをコンソールに表示
     → Foreperiod検証チェック
     → 波形生成（waveform0・waveform1）
     → Enterキー待機（Qualisys capture 待機状態にセット後に押す）
     → 4秒カウントダウン表示（待機姿勢への移行時間）
     → DAQ出力（preload → start）
     → pause(waveform_duration)　波形完了まで待機
     → stop(dq)　DAQ状態リセット
⑤ エラー時はDAQを0Vに強制リセット（try-catch）
```

## 8. 単純選択反応課題とGo-No Go課題の相違点

| 項目 | 単純選択反応 | Go-No Go |
|-----|------------|---------|
| 使用チャンネル | AO0・AO1 | AO0・AO1 |
| AO1電圧 | 常に +5V（緑LED固定） | go: +5V / nogo: -5V |
| switch文 | なし（固定値） | あり（CueTextで分岐） |
| 測定対象 | 反応の速さ | 反応の速さ・正確さ |

## 9. トラブルシューティング記録

### 9.1 Unable to queue additional data while running

**発生状況：** 試行の自動繰り返し実装後、4試行目で発生。

**原因：** `start(dq, 'Finite')` がノンブロッキング（即時復帰）で動作する場合、関数から返った後もDAQオブジェクトが内部的に「実行中」状態のままとなる。そのため、次の試行の `preload()` を呼び出した時点でエラーになる。

**解決策：** DAQ出力完了後に `stop(dq)` を呼び出してDAQ状態を明示的にリセットする。ただし、タイミングに注意が必要（→ 9.2 参照）。

---

### 9.2 stop(dq) によるLED点灯なし

**発生状況：** `start(dq, 'Finite')` の直後に `stop(dq)` を追加したところ、LEDが一切点灯しなくなった。

**原因：** `start(dq, 'Finite')` がノンブロッキングの場合、即座に返ってくるため直後の `stop(dq)` が波形出力を強制終了させてしまう。

**解決策：** `stop(dq)` を `pause()` の後に移動し、pause の待ち時間に波形総出力時間を指定する。

```matlab
start(dq, 'Finite');
waveform_duration = ini_duration + trig_signal_duration + trig_to_ready_interval + ...
                    Protocol.Foreperiod(iTrial) + gonogo_signal_duration + off_duration;
pause(waveform_duration);   % 波形完了まで待機（ITIはEnterキー待機＋カウントダウンで代替）
stop(dq);                   % DAQ状態をリセット
```

**留意点：** Foreperiod が最大（3.0s）の場合、波形総出力時間は 4.8s となる。`pause` に `waveform_duration` を含めることで、すべてのForeperiod水準で確実に波形が完了してから `stop(dq)` が呼ばれる。
