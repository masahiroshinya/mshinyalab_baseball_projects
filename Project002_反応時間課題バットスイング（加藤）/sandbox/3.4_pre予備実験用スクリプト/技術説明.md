# 3.4 pre 予備実験用スクリプト　技術説明

**作成日**: 2026-05-01  
**最終更新日**: 2026-05-11  
**作成者**: mshinyalab

本ドキュメントは、反応時間課題バットスイング予備実験における刺激呈示スクリプト群の技術的仕様をまとめたものです。

---

## 1. 実験条件の概要

本予備実験は以下の3条件で構成される。

| 条件 | 内容 | 測定指標 |
|------|------|---------|
| 0. 自由スイング | ready/go cue あり・フォアピリオド固定（3.0s）・自由なスイング動作 | スイングスピード、床反力、バイオメカニクス的指標 |
| 1. 単純選択反応課題 | 緑色LED（Go cue）に反応してスイング | 反応の速さ＋上記指標 |
| 2. Go-No Go課題 | 緑色LED（Go）はスイング、赤色LED（NoGo）は抑制 | 反応の速さ・正確さ＋上記指標 |

## 3. ハードウェア構成

3.3節と同じハードウェア構成を使用する。

### 電圧出力チャンネル

**AO0**（Qualisysトリガー兼 白色LED）

| 電圧 | 機能 |
|------|------|
| +5V | Qualisysへのトリガー（TTL, positive） |
| -5V | 白色LED点灯（ready cue） |
| 0V  | 消灯 |

**AO1**（緑/赤 LED）

AO1チャンネルに緑と赤のLEDを**正負逆向きに**接続することで、電圧の正負によって点灯色を切り替える。

| 電圧 | 機能 |
|------|------|
| +5V | 緑色LED点灯（go cue） |
| -5V | 赤色LED点灯（nogo cue） |
| 0V  | 消灯 |

## 4. 実験プロトコール（タイミング構造）

全3条件で共通のタイミング構造（Qualisysトリガー＋初期位置計測期間＋LEDキュー）を採用する。

### 4.0 自由スイング

```
Qualisysトリガー → 初期位置計測（1.0s）
→ 白色LED点灯（Ready cue, 0.5s）→（Foreperiod固定: 3.0s）→ 緑色LED点灯（Go cue, 0.5s）
→ バットスイング（自由なスイング動作）
```

### 4.1 単純選択反応課題

```
Qualisysトリガー → 初期位置計測（1.0s）
→ 白色LED点灯（Ready cue, 0.5s）→（Foreperiodをランダマイズ）→ 緑色LED点灯（Go cue, 0.5s）
→ バットスイング
```

### 4.2 Go-No Go課題

```
Qualisysトリガー → 初期位置計測（1.0s）
→ 白色LED点灯（Ready cue, 0.5s）→（Foreperiodをランダマイズ）
    → 緑色LED点灯（Go cue, 0.5s）  → バットスイング
    → 赤色LED点灯（NoGo cue, 0.5s）→ スイング抑制
```

## 5. タイミングパラメータ

| パラメータ | 変数名 | 値 |
|-----------|--------|-----|
| 最初の消灯時間 | `ini_duration` | 0.1 s |
| トリガー信号幅 | `trig_signal_duration` | 0.1 s |
| トリガー→ready 間隔（初期位置計測用） | `trig_to_ready_interval` | 1.0 s |
| ready cue 提示時間 | `ready_signal_duration` | 0.5 s |
| Foreperiod（自由スイング） | `foreperiod_fix` | 3.0 s（固定） |
| Foreperiod（単純反応・Go-No Go） | `Foreperiod` | 試行ごとに可変（CSV参照） |
| go/nogo cue 提示時間 | `gonogo_signal_duration` | 0.5 s |
| 最後の消灯時間 | `off_duration` | 0.1 s |
| スイング完了待機時間 | `swing_max_duration` | 5.0 s |
| Enter キー待機 + カウントダウン | ― | 可変（Enter後4秒カウントダウン固定） |

> **`trig_to_ready_interval` の意図：** Qualisysトリガー後の1.0秒間はLEDを消灯したまま静止させ、この期間のモーションデータを**初期位置（分析基準）**として使用する。全3条件で共通の設定。

> **試行間インターバルについて：** 各試行の開始前に Enter キー待機（Qualisys capture 準備）＋ 4秒カウントダウン（待機姿勢移行）を設けた。これにより1試行＝1 capture の分割計測が可能となった。

1試行の波形総出力時間：

- **自由スイング**：`ini + trig + trig_to_ready + foreperiod_fix + gonogo_signal + off` = **4.8 s**
- **単純反応・Go-No Go**：`ini + trig + trig_to_ready + Foreperiod + gonogo_signal + off` = **1.8 + Foreperiod 秒**

1試行のタイミング図（Foreperiod = F 秒の場合）：

```
AO0  |____|TTTTT|___________|RRRRR|_______________|_____|
AO1  |___________________________________|GGGGG|_____|

     0   0.1  0.2          1.2   1.7        1.2+F  1.7+F

凡例:
  T: +5V トリガー（Qualisys起動）
  R: -5V 白色LED（ready cue）
  G: ±5V 緑/赤LED（go/nogo cue）
  _: 0V 消灯
```

## 7. スクリプトの処理フロー

### 自由スイング（`demo3_4_0_free_pre.m`）

```
① パラメータ設定（電圧値・タイミング・固定Foreperiod）
② DAQ初期化（AO0・AO1）
③ 試行ループ（nTrial = 5）：
     試行番号・Foreperiodをコンソールに表示
     → 波形生成（waveform0・waveform1）
     → Enterキー待機 → 4秒カウントダウン
     → DAQ出力（preload → start）
     → pause(waveform_duration) → stop(dq) → pause(swing_max_duration)
④ エラー時はDAQを0Vに強制リセット（try-catch）
```

### 単純反応・Go-No Go（`demo3_4_1_...` / `demo3_4_2_...`）

```
① パラメータ設定（電圧値・タイミング）
② CSVファイル読み込み（uigetfileでダイアログ選択）
③ DAQ初期化（AO0・AO1）
④ 試行ループ（1試行ずつ手動トリガー）：
     試行番号・CueText・Foreperiodをコンソールに表示
     → Foreperiod検証チェック
     → 波形生成（waveform0・waveform1）
     → Enterキー待機 → 4秒カウントダウン
     → DAQ出力（preload → start）
     → pause(waveform_duration) → stop(dq) → pause(swing_max_duration)
⑤ エラー時はDAQを0Vに強制リセット（try-catch）
```

## 9. トラブルシューティング記録

### 9.1 Unable to queue additional data while running

**発生状況：** 試行の自動繰り返し実装後、4試行目で発生。

**原因：** `start(dq, 'Finite')` がノンブロッキング（即時復帰）で動作する場合、関数から返った後もDAQオブジェクトが内部的に「実行中」状態のままとなる。そのため、次の試行の `preload()` を呼び出した時点でエラーになる。

**解決策：** DAQ出力完了後に `stop(dq)` を呼び出してDAQ状態を明示的にリセットする。ただし、タイミングに注意が必要（→ 9.2 参照）。

---

### 9.2 stop(dq) によるLED点灯なし

**発生状況：** `start(dq, 'Finite')` の直後に `stop(dq)` を追加したところ、LEDが一切点灯しなくなった。

**原因：** `start(dq, 'Finite')` がノンブロッキングの場合、即座に返ってくるため直後の `stop(dq)` が波形出力を強制終了させてしまう。

**解決策：** `stop(dq)` を `pause()` の後に移動し、pause の待ち時間に波形総出力時間を指定する。

```matlab
start(dq, 'Finite');
waveform_duration = ini_duration + trig_signal_duration + trig_to_ready_interval + ...
                    Protocol.Foreperiod(iTrial) + gonogo_signal_duration + off_duration;
pause(waveform_duration);   % 波形完了まで待機
stop(dq);                   % DAQ状態をリセット
```

**留意点：** Foreperiod が最大（5.0s）の場合、波形総出力時間は 6.8s となる。`pause` に `waveform_duration` を含めることで、すべてのForeperiod水準で確実に波形が完了してから `stop(dq)` が呼ばれる。
