## 研究の背景・目的・意義

実際の野球打撃では、投手のボールの軌道・球種を瞬時に知覚・判断してスイングを開始するという高度な認知的処理が要求される。しかし、従来のバッティングバイオメカニクス研究の多くは自由スイング（外部的な時間制約なし）を対象としており、認知的判断がスイング動作に与える影響は十分に検討されていない（Nakamoto & Mori, 2008; Kida et al., 2005）。

Go/Nogo課題は「振る/振らない」の二択判断という構造において野球打者の状況判断と高い対応を持ち、競技経験に応じた反応時間の変化が先行研究で示されている（Nakamoto & Mori, 2008; Kida et al., 2005）。本研究は、Go/Nogo課題パラダイムを実際のバットスイングに組み合わせることで認知負荷を段階的に操作し、認知判断がバットスイング動作（反応時間・スイングスピード・床反力・三次元キネマティクス）に与える影響を明らかにすることを目的とする。

本研究の結果、認知負荷に応じたスイング動作の変容が示されれば、「打者の認知判断」と「動作のバイオメカニクス」が密接に連関することが明らかとなる。この知見は、打撃トレーニングの科学的根拠を提供するとともに、スポーツ認知科学・運動制御分野における基礎研究として重要な貢献が期待される。

## 研究対象者の属性・採用基準・除外基準

健常な成人野球経験者を研究対象とする。採用基準（inclusion criteria）として、年齢が 18–30 歳であること、および硬式または軟式野球の打撃経験を有することを設定する。除外基準（exclusion criteria）として、実験参加時に上肢・下肢・体幹に器質的障害を有する者、またはバット操作に痛みや不安を抱く者は研究対象としない。

## 研究対象者の人数

本研究では、反復測定分散分析（3条件：自由スイング・単純反応課題・Go/Nogo課題）を用いて条件間の動作パラメータを比較する。先行研究（Kida et al., 2005; Nakamoto & Mori, 2008）における効果量を参考に、中程度以上の効果量（Cohen's f = 0.35、α = 0.05、1−β = 0.80）を想定した検定力解析が要請するサンプルサイズは約 18 名であった。これをやや保守的に見積もり、**20 名程度**の参加者を対象として実験を行う。

## 使用する装置

1. **三次元モーションキャプチャーシステム（Qualisys）**：反射マーカーを身体およびバットに貼付し、三次元動作情報を計測する装置。Advanced Inverse Modeling（AIM）により身体各セグメントの姿勢を推定する。
2. **フォースプレート（Kistler製）**：スイング中に足裏が地面から受ける力（床反力）を精密に計測する装置。
3. **NI DAQボード（National Instruments製）**：刺激呈示用 LED への電圧出力、および Qualisys への同期トリガー信号の送信に使用する。
4. **LED刺激呈示装置（自作）**：白色・緑色・赤色の LED を搭載した刺激呈示基板。NI DAQ ボードの電圧出力により点灯を制御する。
5. **デジタルビデオカメラ**：被験者がスイング課題を行う様子を撮影する装置。

## 実験プロトコール

１．インフォームドコンセント（所要時間：10 分）

実験概要を説明し、質疑応答の後にインフォームドコンセントを得る。

２．基礎情報の記録（所要時間：5 分）

年齢・性別・身長・体重・野球経験年数・利き手を記録する。

３．着替え・マーカー貼付（所要時間：20 分）

モーションキャプチャー用の反射マーカーを解剖学的ランドマークに貼付する。マーカー貼付の際に着替えが必要な場合は、カーテンで区切られた更衣スペースを使用する。バットへのマーカー貼付および Qualisys での rigid body 登録を行う。

４．器具セットアップ・較正（所要時間：10 分）

Qualisys の空間較正（L 字型キャリブレーションツール）を実施し、残差が許容範囲内であることを確認する。静止立位キャプチャーにより AIM 骨格モデルを構築する。

５．ウォームアップ（所要時間：5 分）

実験課題に慣れるため、各条件につき数試行の練習スイングを行う。

６．実験本体（所要時間：約 75 分）

以下の 3 条件を実施する。条件の実施順序は参加者間でカウンターバランスをとる。

- **自由スイング条件**：20試行（10試行 × 2ブロック）＋ブロック間休憩（約 25 分）
- **単純反応課題**：20試行（10試行 × 2ブロック）＋条件間・ブロック間休憩（約 25 分）
- **Go/Nogo課題**：20試行（10試行 × 2ブロック）＋ブロック間休憩（約 25 分）

各条件間には 5 分以上の休憩を設ける。

７．後処理・着替え（所要時間：10 分）

反射マーカーを外し、着替えてもらう。

**実験全体の所要時間**：最大 135 分（約 2 時間 15 分）

## 測定の詳細

### 三次元動作計測（モーションキャプチャー）

**システム**
Qualisys Track Manager（QTM）による三次元光学式モーションキャプチャーシステム。身体セグメントの追跡には Advanced Inverse Modeling（AIM）マーカーセットを使用する。AIM は各セグメント上に技術的マーカー（クラスター）を貼付し、静止立位キャプチャーから骨格モデルを構築する手法であり、機能的関節中心の推定が可能である（Qualisys AB, 2024）。

**サンプリングレート**：200 Hz

**身体マーカーセット**

AIM の設計指針に従い、以下のセグメントおよび解剖学的ランドマークにマーカーを貼付する。

| セグメント | 貼付部位（予定） | 役割 |
|-----------|----------------|------|
| 骨盤 | 骨盤（腸骨稜部） | 体幹並進速度補正用基準点 |
| 大腿（両側） | 大転子・腓骨頭（AIMクラスター4点以上） | 大腿セグメント姿勢推定 |
| 下腿（両側） | 外果（AIMクラスター） | 下腿セグメント姿勢推定 |
| 足部（両側） | 踵骨・第1中足骨骨頭 | 足部セグメント定義 |
| 上腕（両側） | 肩峰・上腕骨外側顆（AIMクラスター） | 上腕セグメント姿勢推定 |
| 前腕（両側） | 橈骨茎状突起・尺骨茎状突起（AIMクラスター） | 前腕セグメント姿勢推定 |
| 体幹 | C7棘突起・胸骨柄・両側肩峰 | 体幹セグメント定義 |

※最終的な貼付部位は AIM 構造体定義の確定後に更新する。

**空間較正**
計測前に QTM 標準の L 字型較正ツールを用いてキャリブレーションを実施し、残差（residual）が許容範囲内（目安：< 1 mm）であることを確認する。静止立位キャプチャー（3 秒以上）により AIM 骨格モデルを構築する。

---

### 床反力計測

**システム**
Kistler 製フォースプレートを使用し、スイング中の床反力（Ground Reaction Force: GRF）を計測する。QTM に接続したアナログ入力チャンネルを介して、モーションキャプチャーと同期して収録する。

**サンプリングレート**：1000 Hz（QTM 内でモーションキャプチャーと同期収録）

**計測チャンネル**

| チャンネル | 内容 |
|-----------|------|
| Fz | 鉛直方向床反力 |
| Fy | 前後方向床反力（投手–捕手方向） |
| Fx | 左右方向床反力 |
| Mx, My, Mz | 各軸回りのモーメント |
| CoPx, CoPy | 圧力中心（Center of Pressure） |

**体重正規化**
各参加者の実験前に静止立位計測（3 秒間）を行い、鉛直方向床反力（Fz）の平均値から体重（BW）を推定する。各 GRF 値は BW で除した値（単位：%BW）を用いて参加者間比較を行う。

---

### バット動作計測（Rigid Body）

Qualisys の rigid body 機能を用いてバットの 6 自由度姿勢（位置・回転）を推定する。

| マーカーラベル | 貼付位置 | 用途 |
|---|---|---|
| `bottom` | バット・グリップ端（最下部） | スイング速度の代替計測点（手部代替） |
| `top` | バット先端（最上部） | バット長軸ベクトルの定義 |
| クラスターマーカー（4点以上） | バット胴部（テープ固定） | Rigid body 姿勢推定 |

---

### 刺激呈示・同期システム

**電圧出力チャンネル**

| チャンネル | 電圧 | 機能 |
|-----------|------|------|
| AO0 | +5V（TTL） | Qualisys 外部トリガー（計測開始） |
| AO0 | −5V | 白色 LED 点灯（Ready cue） |
| AO0 | 0V | 消灯 |
| AO1 | +5V | 緑色 LED 点灯（Go cue） |
| AO1 | −5V | 赤色 LED 点灯（Nogo cue） |
| AO1 | 0V | 消灯 |

AO1 では緑色 LED と赤色 LED を正負逆向きに並列接続することで、電圧の正負により点灯色を切り替える。MATLAB Data Acquisition Toolbox を用いて電圧波形を生成し、NI DAQ から出力する。AO0 から出力する TTL パルス（+5V、100 ms）を QTM の外部トリガ入力チャンネルに接続し、試行開始と計測開始を同期させる。

### 試行タイミング構造

各試行における刺激タイミングは以下の通りである（全 3 条件共通フレーム）。

```
t = 0.0 s  : 試行開始（AO0 より +5V TTL パルス → QTM 計測開始）
t = 0.1 s  : TTL パルス終了（消灯期間開始）
t = 1.1 s  : 初期位置計測期間終了（被験者は静止して構えを作る）
t = 1.1 s  : Ready cue（白色 LED 点灯、0.5 s）
t = 1.6 s  : Ready cue 消灯
t = 1.6 s〜: Foreperiod（1.2〜1.8 s、試行ごとにランダム）
t = F  s   : Go / Nogo cue（緑 or 赤 LED 点灯、0.5 s）
           ：Go cue ならスイング、Nogo cue ならスイングを抑制
t = F+0.5 s: Cue 消灯 → スイング完了待機（最大 5.0 s）
```

**Foreperiod の設計根拠**：Foreperiod は実際の野球投球動作（ワインドアップ開始からリリースまで）を模擬する。大学・社会人レベルの投手では概ね 1.2〜1.8 秒とされており（Nakamoto & Mori, 2008）、この範囲を可変 Foreperiod として採用した。水準は {1.2, 1.4, 1.5, 1.6, 1.8} 秒の 5 水準から等頻度でランダムに割り当てる。自由スイング条件の Foreperiod は 1.5 秒固定とする。

---

### 反応時間の定義

反応時間（RT）は、Go cue（緑色 LED）の点灯フレームからバットスイング開始フレームまでの時間差として定義する。

**スイング開始の定義（Nasu et al., 2020 に準拠）**：バットグリップ端（`bottom` マーカー）の合成速度が、当該試行の最大合成速度の 5% を超えた最初のフレームをスイング開始点とする。

算出手順：
1. `bottom` マーカーの位置データ（200 Hz）に 4 次 Butterworth 低域通過フィルタ（カットオフ周波数：10 Hz）を適用する
2. フィルタ済みデータから 3 軸速度（vx, vy, vz）を数値微分により算出する
3. 合成速度 `v = sqrt(vx² + vy² + vz²)` を算出する
4. 試行内の最大合成速度（PeakSpeed）を同定する
5. `v > PeakSpeed × 0.05` を満たす最初のフレームをスイング開始フレームとする

```
RT [ms] = (スイング開始フレーム − Go cue onset フレーム) × (1000 / 200)
```

Nogo 試行、およびスイング開始が検出されない試行は NaN として除外する。

---

### スイングスピードの定義

最大スイングスピード（Peak Swing Speed）は、バットグリップ端（`bottom` マーカー）の**体幹補正済み合成速度**の試行内最大値として定義する。

**体幹補正**：スイング中、全身が投手方向（X 軸正方向）へ並進するため、`bottom` マーカーの速度には「バットスイング自体の速度」と「体幹並進速度」の両成分が含まれる。骨盤マーカー（`pelvis`）の X 軸速度を体幹並進速度の代表値として用い、差し引くことで純粋なスイング速度を推定する（Nasu et al., 2020 に準拠）。

```
補正済み X 速度    = v_bottom_X − v_pelvis_X
補正済み合成速度   = sqrt( 補正済み X 速度² + v_bottom_Y² + v_bottom_Z² )
Peak Swing Speed   = max( 補正済み合成速度 )  [当該試行内]
```

## 取得・公開するデータ

参加者の基礎データとして、年齢・性別・身長・体重・野球経験年数・利き手を取得する。実験で取得するデータとして、三次元動作データ（マーカー座標）・床反力データ・ビデオ映像がある。これらのデータは各参加者に番号を割り付けた上で匿名性を担保して管理する。顔画像や顔画像が含まれる映像は公開しない。

## データ解析

**モーションキャプチャーデータ**：4 次 Butterworth 低域通過フィルタ（カットオフ周波数：10 Hz）で平滑化後、反応時間・スイングスピードおよび各関節角度・角速度を算出する。

**GRF データ**：体重正規化（%BW）後、踏み込み時のピーク鉛直力（Fz）・前後力（Fy）・圧力中心（CoP）の試行内ピーク値およびタイミングを抽出する。

**統計解析**：3 条件間の比較に反復測定分散分析（RM-ANOVA）を用い、有意差が認められた場合は Bonferroni 補正による多重比較を行う。効果量（偏イータ二乗 η²p）を合わせて報告する。
