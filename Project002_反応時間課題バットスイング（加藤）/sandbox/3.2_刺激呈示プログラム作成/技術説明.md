## 2. ハードウェア構成

### DAQチャンネルとLEDの対応

| チャンネル | 接続先 | 役割 |
|---|---|---|
| `ao0` | 緑LED + Qualisys Sync In（並列接続） | Go刺激 / 単純反応刺激 / QTMトリガ |
| `ao1` | 赤LED | No-Go刺激 |

### 並列接続の仕組み

`ao0` にはLEDとQTMのSync In端子が並列に接続されている。`ao0` が5Vを出力すると、緑LEDの点灯とQTMへのトリガ信号送信が同時に行われる。

```
ao0 --+-- 緑LED（刺激呈示）
      +-- Qualisys Sync In（トリガ・イベントマーカー）
```

この構成により、LEDが点灯するタイミングが自動的にQTMデータ上のイベントとして記録される。

### 電圧仕様

| 状態 | 出力電圧 |
|---|---|
| LED点灯 | 5.0 V |
| LED消灯 / 初期化 | 0.0 V |
| QTMトリガパルス幅 | 50 ms |

## 3. プログラムの処理フロー

```
① DAQオブジェクト初期化（全チャンネル0V）
　　↓
② QTM準備確認メッセージ表示
　　↓
③ ユーザーがEnterを押す
　　↓
④ ao0に5Vパルス（50ms）→ QTM録画開始 + 緑LED一瞬点灯
　　↓
⑤ 5秒カウントダウン
　　↓
⑥ 試行ループ（プロトコールCSVに従って繰り返し）
　　├── ISI待機（CSV値 + オフセット5秒）
　　├── LED点灯（色に応じたチャンネルに電圧出力）
　　├── 点灯時間待機（0.15秒）
　　└── LED消灯（全チャンネル0V）
　　↓
⑦ 完了メッセージ表示
　　↓
⑧ ユーザーがQTM録画を手動停止
```

## 5. タイミング制御の仕組み

ISIおよびLED点灯時間の待機には `tic/toc` を用いた高精度ループを採用している。`pause` 関数のみでは精度が保証されないため、空ループと微小 `pause` を組み合わせた実装としている。

```matlab
t_start = tic;
while toc(t_start) < wait_time
    pause(0.001);   % CPU占有を防ぐ微小スリープ
end
```

## 6. QTM連携の設定

スクリプト実行前にQTM側で以下の設定が必要。

| 設定項目 | 値 |
|---|---|
| Project Options → Processing → Calculate 6DOF | **両方ON**（Real time / Capture） |
| Capture time | **90秒以上**（試行数に応じて調整） |
| Trigger port 設定 | Positive edge（0V→5Vの立ち上がり）でキャプチャ開始 |
| Trigger遅延 | 20,000 μs（20ms）以上 |

> 詳細は `manual/03_qtm_use_manual_summary.md` のトラブルシューティングセクションを参照。

## 7. 安全処理

エラー発生時や中断時でも必ずLEDを消灯するよう `try-catch` ブロックで保護している。

```matlab
catch ME
    if exist('dq', 'var')
        write(dq, [0.0, 0.0]);   % 全チャンネル消灯
    end
    rethrow(ME);
end
```
