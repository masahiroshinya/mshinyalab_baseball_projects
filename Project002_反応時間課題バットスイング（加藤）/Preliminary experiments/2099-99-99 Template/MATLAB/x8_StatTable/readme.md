
## x8_StatTable — 統計処理用データテーブル

ワークフロー ステップ8に対応。

`x7_MultiTrialAnalysisResultsChecked` の結果から、統計ソフト（R、SPSS、JASP など）に入力するためのデータテーブルを作成・保存するフォルダ。

### 格納するもの
- 統計処理用データテーブル（`.mat` ファイル）

### 作成のポイント
- 1行1データポイント（tidy data 形式）を基本とする
- 被験者ID・条件・試行番号などの識別変数を含める

### 次のステップ
作成したテーブルを `x9_Statistics` または外部の統計ソフトで分析する。
