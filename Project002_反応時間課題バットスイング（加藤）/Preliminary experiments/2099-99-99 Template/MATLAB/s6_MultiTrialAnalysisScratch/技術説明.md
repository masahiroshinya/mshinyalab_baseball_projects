## 1. このシステムの目的と位置づけ

本システムは、シングル試行で確認した各種分析（反応時間算出など）を、**全被験者・全条件・全試行**に対して自動的に適用し、結果を一括収集・比較するためのアプリケーションです。

分析ワークフロー上の位置づけ：

```
x3_DataChecked/    ← 入力：目視確認済みデータ
       ↓
m6_analyze_multi_trial.m   ← 本システム（本ファイルで設計を説明）
       ↓
x6_MultiTrialAnalysisResults/  ← 出力：全試行の分析結果
```

---

## 2. システム設計の方針

### 2-1. 「1試行を処理する関数」と「全体ループ」を分離する

本システムは以下の2層構造を採用します。

```
【層1】メインスクリプト m6_analyze_multi_trial.m
  - 被験者ループ × 条件ループ × 試行ループ を回す
  - 結果をテーブルに格納・保存する
  - 分析項目の追加・削除はここで行う

【層2】関数 analyzeOneTrial(Data, Prm)
  - Data（1試行分）を受け取り、分析結果 struct を返す
  - 新しい分析項目を追加するときは、この関数に追記する
```

この分離により、「新しい分析指標を追加したい」→ 関数だけを修正すればよい、という構造になります。

### 2-2. 結果はすべて MATLAB テーブルで管理する

全試行の結果を `ResultsTable`（MATLAB `table` 型）に格納します。
テーブルの各行 = 1試行、各列 = 分析項目 という形式です。

| Subject | Condition | Trial | CueType | RT_ms | SwingSpeed_degps | ... |
|---------|-----------|-------|---------|-------|-----------------|-----|
| 1       | gonogo    | 1     | Go      | 342.0 | 1205.3          | ... |
| 1       | gonogo    | 2     | NoGo    | NaN   | 250.1           | ... |

この形式にすることで：
- `varfun`, `groupsummary` 等で条件別・被験者別の集計が容易になる
- `writetable` で CSV 出力してExcel・R・Python でも扱える

## 4. 実装コード

### 4-1. 1試行処理関数 `analyzeOneTrial.m`

```matlab
function result = analyzeOneTrial(Data, Prm)
% analyzeOneTrial  1試行分のデータを受け取り、分析結果を struct で返す
%
%   INPUT
%     Data : DataArray(iTrial, iCondition) の1要素
%     Prm  : parameters 構造体
%
%   OUTPUT
%     result : 以下のフィールドを持つ struct
%       .cueType       : 'Go' or 'NoGo' or 'Unknown'
%       .RT_ms         : 反応時間 [ms]（未検出時は NaN）
%       .swingDetected : logical（スイング開始が検出されたか）
%       .swingSpeed_degps : スイング中の最大角速度 [deg/s]
%       .tSwingOnset   : スイング開始フレーム（未検出は NaN）
%       .tCueMarker    : キューフレーム

THRESHOLD_OMEGA = 300;  % [deg/s]（Shinya et al., 2020）

% ---- 前処理: NaN 補間 ----
fs = Data.FrameRate;
fc = Prm.Fc;
[b, a] = butter(2, fc / (fs / 2));

fields = fieldnames(Data.Markers);
for i = 1:numel(fields)
    f = fields{i};
    x = Data.Markers.(f);
    t = (1:size(x,1))';
    for col = 1:size(x,2)
        nanIdx = isnan(x(:,col));
        if any(nanIdx) && any(~nanIdx)
            x(nanIdx,col) = interp1(t(~nanIdx), x(~nanIdx,col), t(nanIdx), 'linear', 'extrap');
        end
    end
    Data.Markers.(f) = x;
end

% ---- フィルタリング ----
M = filt_all_fields(b, a, Data.Markers);

% ---- バット長軸の角速度計算（Shinya et al., 2020）----
r_bottom    = M.bottom;
r_top       = M.top;
v_long      = r_top - r_bottom;
v_long_norm = sum(v_long.^2, 2).^0.5;
e_long      = v_long ./ v_long_norm;
de_long     = diff3p(e_long, 1/fs);
omega_rad   = sum(de_long.^2, 2).^0.5;
omega_deg   = omega_rad * (180 / pi);

% ---- LED タイミング取得 ----
led_go   = Data.LEDData(:, 2);
led_nogo = Data.LEDData(:, 1);
tCueGo   = find(led_go   >  2, 1, 'first');
tCueNoGo = find(led_nogo < -2, 1, 'first');

if ~isempty(tCueGo)
    tCueAnalog = tCueGo;
    cueType    = 'Go';
elseif ~isempty(tCueNoGo)
    tCueAnalog = tCueNoGo;
    cueType    = 'NoGo';
else
    result = makeEmptyResult('Unknown');
    return
end

tCueMarker = round(tCueAnalog / Data.AnalogFs * fs);

% ---- スイング開始検出 ----
nFrames     = length(omega_deg);
searchRange = tCueMarker : nFrames;
idxAbove    = find(omega_deg(searchRange) > THRESHOLD_OMEGA, 1, 'first');

if isempty(idxAbove)
    tSwingOnset    = NaN;
    swingDetected  = false;
else
    tSwingOnset    = searchRange(1) + idxAbove - 1;
    swingDetected  = true;
end

% ---- 反応時間算出 ----
if swingDetected
    RT_ms = (tSwingOnset - tCueMarker) / fs * 1000;
else
    RT_ms = NaN;
end

% ---- 新規分析項目：スイング中の最大角速度 ----
%   キュー以降のウィンドウ内での最大値をスイングスピードとして記録する
if tCueMarker <= nFrames
    swingSpeed_degps = max(omega_deg(tCueMarker:end));
else
    swingSpeed_degps = NaN;
end

% ---- 結果を struct にまとめて返す ----
result.cueType          = cueType;
result.RT_ms            = RT_ms;
result.swingDetected    = swingDetected;
result.swingSpeed_degps = swingSpeed_degps;
result.tSwingOnset      = tSwingOnset;
result.tCueMarker       = tCueMarker;
end


% ---- ローカル関数：LED 未検出時の空 result ----
function result = makeEmptyResult(cueType)
result.cueType          = cueType;
result.RT_ms            = NaN;
result.swingDetected    = false;
result.swingSpeed_degps = NaN;
result.tSwingOnset      = NaN;
result.tCueMarker       = NaN;
end
```

### 4-2. メインスクリプト `m6_analyze_multi_trial.m`

```matlab
% ========================================================
% m6_analyze_multi_trial.m
% 全被験者・全条件・全試行に対してマルチ試行分析を実行する
% ========================================================

clear; close all; clc;

addpath('s6_MultiTrialAnalysisScratch')  % analyzeOneTrial.m のパスを追加

% ---- 分析対象の設定 ----
subjectList   = [1, 2, 3];             % 分析する被験者番号
conditionList = {1, 2, 3};            % 1=free, 2=simple, 3=gonogo
condNameMap   = {'free', 'simple', 'gonogo'};

Prm = parameters;

% ---- 結果格納用テーブルの初期化 ----
%   行数は後で growRows してもよいが、事前確保の方が速い
ResultsTable = table();

% ---- 被験者ループ ----
for iSubject = subjectList

    dataFilePath = sprintf('x3_DataChecked/Data%02d', iSubject);
    if ~exist([dataFilePath '.mat'], 'file')
        fprintf('Subject %d: データファイルなし → スキップ\n', iSubject);
        continue
    end
    load(dataFilePath)
    fprintf('\n=== Subject %d ===\n', iSubject);

    % ---- 条件ループ ----
    for iCondIdx = 1:numel(conditionList)
        iCondition = conditionList{iCondIdx};
        condName   = condNameMap{iCondIdx};

        nTrials = size(DataArray, 1);

        % ---- 試行ループ ----
        for iTrial = 1:nTrials

            Data = DataArray(iTrial, iCondition);

            % 空データのチェック（フィールドが存在しない試行を安全にスキップ）
            if isempty(Data.Markers)
                continue
            end

            try
                result = analyzeOneTrial(Data, Prm);
            catch ME
                fprintf('Subject %d, Cond %s, Trial %d: エラー "%s" → スキップ\n', ...
                    iSubject, condName, iTrial, ME.message);
                continue
            end

            % ---- 1試行分をテーブル行として追記 ----
            newRow = table( ...
                iSubject,           ...
                string(condName),   ...
                iTrial,             ...
                string(result.cueType),         ...
                result.RT_ms,                   ...
                result.swingDetected,           ...
                result.swingSpeed_degps,        ...
                'VariableNames', { ...
                    'Subject', 'Condition', 'Trial', ...
                    'CueType', 'RT_ms', 'SwingDetected', 'SwingSpeed_degps' ...
                });

            ResultsTable = [ResultsTable; newRow]; %#ok<AGROW>

            fprintf('  Cond=%s  Trial=%2d  [%s]  RT=%.1f ms\n', ...
                condName, iTrial, result.cueType, result.RT_ms);
        end
    end
end

% ---- 結果の保存 ----
saveDir  = 'x6_MultiTrialAnalysisResults';
savePath = fullfile(saveDir, sprintf('Results_Subject%s_%s.mat', ...
    num2str(subjectList, '%d-'), datestr(now, 'yyyymmdd')));
save(savePath, 'ResultsTable');
fprintf('\n結果を保存しました: %s\n', savePath);

% CSV にも出力（Excel や Python・R でそのまま扱える）
csvPath = strrep(savePath, '.mat', '.csv');
writetable(ResultsTable, csvPath);
fprintf('CSV 出力: %s\n', csvPath);
```

## 5. 新しい分析項目を追加する方法

新規指標を追加する際は **`analyzeOneTrial.m` のみを変更**します。
メインスクリプト側は「どのフィールドを `newRow` に入れるか」の列定義を追記するだけです。

### 手順（例：「スイング開始前の角速度の安定性」を追加する場合）

**Step 1 — `analyzeOneTrial.m` に計算を追記**

```matlab
% ---- 新規分析項目：キュー前500ms 間の角速度 SD（ベースライン安定性）----
preWindow = max(1, tCueMarker - round(0.5 * fs)) : tCueMarker - 1;
if numel(preWindow) >= 2
    baselineSD = std(omega_deg(preWindow));
else
    baselineSD = NaN;
end
result.baselineSD_degps = baselineSD;
```

**Step 2 — `makeEmptyResult` に初期値を追記**

```matlab
result.baselineSD_degps = NaN;
```

**Step 3 — メインスクリプトの `newRow` 定義に列を追加**

```matlab
newRow = table( ...
    ...
    result.baselineSD_degps, ...
    'VariableNames', { ...
        ..., 'BaselineSD_degps' ...
    });
```

## 6. 条件別・被験者別の比較

メインスクリプト実行後、`ResultsTable` に対して以下のコードで集計・比較ができます。

### 6-1. 条件別 RT の平均と SD

```matlab
% Go 試行のみ抽出
GoTable = ResultsTable(strcmp(ResultsTable.CueType, 'Go') & ResultsTable.SwingDetected, :);

% 条件ごとに RT を集計
condStats = groupsummary(GoTable, 'Condition', {'mean', 'std'}, 'RT_ms');
disp(condStats)
```

### 6-2. 被験者別の箱ひげ図

```matlab
figure;
boxplot(GoTable.RT_ms, GoTable.Subject);
xlabel('被験者番号');
ylabel('反応時間 (ms)');
title('被験者別 RT 分布（Go 試行）');
grid on;
```

### 6-3. 条件 × 被験者の交互比較

```matlab
figure;
conditions = unique(GoTable.Condition);
for k = 1:numel(conditions)
    cond = conditions{k};
    idx  = strcmp(GoTable.Condition, cond);
    subplot(1, numel(conditions), k);
    boxplot(GoTable.RT_ms(idx), GoTable.Subject(idx));
    title(cond);
    ylabel('RT (ms)');
    xlabel('被験者');
    grid on;
end
sgtitle('条件別・被験者別 RT 比較');
```

### 6-4. NoGo 試行の抑制率（インヒビション率）

```matlab
% 条件 gonogo の NoGo 試行に限定
nogoRows = strcmp(ResultsTable.CueType, 'NoGo') & strcmp(ResultsTable.Condition, 'gonogo');
nogoTable = ResultsTable(nogoRows, :);

% 被験者ごとの NoGo 抑制率
[subjects, ~, idx] = unique(nogoTable.Subject);
inhibitionRate = NaN(numel(subjects), 1);
for k = 1:numel(subjects)
    rows = idx == k;
    inhibitionRate(k) = mean(~nogoTable.SwingDetected(rows)) * 100;  % [%]
end

T_inhib = table(subjects, inhibitionRate, ...
    'VariableNames', {'Subject', 'InhibitionRate_pct'});
disp(T_inhib)
```
