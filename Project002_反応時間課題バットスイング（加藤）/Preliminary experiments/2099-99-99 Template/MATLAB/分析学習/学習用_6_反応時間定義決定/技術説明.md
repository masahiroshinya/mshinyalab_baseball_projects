# 反応時間の定義：本研究における2つの方針

**作成日**: 2026-06-09

## 1. 概要

本研究では、実験設計（個別マーカーを使うか、剛体トラッキングのみか）によって採用できる定義が変わります。
そのため、以下の**2つの方針**を並行して整理・検討します。

---

## 2. 方針1：Nasu et al. (2020) 準拠（個別マーカー版）

バットに**個別の反射マーカー**（`bottom` = グリップ端、`top` = バット先端）を貼付し、かつ**骨盤にもマーカーを貼付**して計測する場合に適用します。

| 要素 | 定義 |
|------|------|
| **使用データ** | `bottom` マーカー（グリップ端の個別反射マーカー）＋ 骨盤マーカー |
| **速度方向** | **X軸方向の1次元速度**（ホームベース方向 = 投手–捕手方向） |
| **体幹補正** | `bottom` の X軸速度 から 骨盤マーカーの X軸速度 を減算 |
| **閾値** | 被験者ごとの全試行平均ピーク速度の **10%** |
| **刺激開始点** | LED電圧が 2V を超えた最初のアナログサンプル |
| **適用条件** | バットに `bottom` マーカーを貼付し、かつ骨盤マーカーを計測する実験設計の場合 |

**Nasu et al. (2020) からの変更点：**
- マーカーの位置：手部セグメント → `bottom`（グリップ端マーカー）で代替

**根拠文献：** Nasu et al. (2020)（詳細は `s6_literature_notes.md` 参照）

---

## 3. 方針2：剛体トラッキング専用版

バットを**剛体（rigid body）としてのみトラッキング**する場合に適用します。個別マーカー（`top`/`bottom`）は存在しません。

| 要素 | 定義 |
|------|------|
| **使用データ** | バット剛体の**原点**（Qualisys で設定したグリップ端付近の基準点）の位置座標 |
| **速度方向** | 3D合成速度 |
| **閾値** | 被験者ごとの全試行平均ピーク速度の **10%** |
| **刺激開始点** | LED電圧が 2V を超えた最初のアナログサンプル |
| **適用条件** | バットを剛体としてのみトラッキングする実験設計の場合 |

**方針1からの変更点：**
- 使用データ：`bottom` 個別マーカー → 剛体原点（グリップ端付近に設定）
- 速度の計算方法：同じ（位置の差分から3D合成速度を算出）

> **重要な前提：** Qualisys Track Engineering でバット剛体の**原点をグリップ端付近に設定**しておくことが必要です。
> 原点の位置は実験設計の段階で確認・決定してください。

**根拠文献：** Punchihewa et al. (2020)、Sarkar & James 他（2011）（詳細は `s6_literature_notes.md` 参照）

---

## 4. 2つの方針の比較

| 比較項目 | 方針1（Nasu et al. 完全模倣版） | 方針2（剛体専用版） |
|----------|--------------------------------|---------------------|
| **使用データ** | `bottom` 個別反射マーカー＋骨盤マーカー | 剛体原点（グリップ付近に設定） |
| **先行研究との対応** | Nasu et al. (2020) を完全模倣 | Punchihewa et al. 2020、Sarkar & James 他 |
| **速度の計算** | X軸1次元速度（骨盤補正あり） | 3D合成速度 |
| **閾値** | 平均ピーク速度の10% | 平均ピーク速度の10% |
| **実験設計の条件** | バット個別マーカー＋骨盤マーカーが必要 | 剛体トラッキングのみでOK |
| **Qualisys設定の依存** | なし（マーカー名で指定） | 剛体原点の位置設定に依存 |

> **方針の選択：** 本実験でバットに個別マーカーを貼付するか、剛体のみでトラッキングするかに応じて、どちらかを採用します。
> 両方のデータが得られる場合は、方針1と方針2で算出した反応時間を比較することができます。

## 6. 定義選択の判断基準（フェーズ4 参照）

最終的な定義を選択する際は、以下の観点から評価してください。

| 判断基準 | 内容 |
|---|---|
| **先行研究との整合性** | 同様の研究で使われている定義に合わせると、結果の比較・考察がしやすい |
| **検出の安定性** | 閾値が低すぎるとノイズを拾いやすく、高すぎるとスイング開始の検出が遅れる |
| **生理学的妥当性** | 「スイングが始まった」という現象を最もよく表しているか |
| **再現性** | 同じデータを再分析したとき、同じ結果が得られるか |

## 7. `parameters.m` への実装例（フェーズ4 完了後に反映）

定義が確定したら、`parameters.m` に以下のパラメータを追記します（AIアシスタントに依頼）。

```matlab
% 反応時間算出パラメータ
Prm.RT.ThresholdRatio = 0.10 ;       % スイング開始閾値（ピーク速度に対する割合）
Prm.RT.OnsetMarker    = 'bottom' ;   % スイング開始検出に使用するマーカー
```

> 上記は確定した定義に合わせて値を変更してください。変更はAIアシスタントに依頼することを推奨します。
