# 技術説明（トラブルシューティング記録）

## 1. step4可視化スクリプトでの変数名タイポによる未定義エラー

### 事象
`step4_forstudy_check_single_trial_results.m` の実行時、以下のエラーが発生した。
```
関数または変数 'dataFilePath' が認識されません。

エラー: step4_forstudy_check_single_trial_results (行 28)
load(dataFilePath)
```

### 原因の分析
* 27行目で定義されている変数名が `dataFilepath`（**p**が小文字）であるのに対し、28行目の `load` 関数の引数として `dataFilePath`（**P**が大文字）が指定されていました。
* MATLABでは変数の大文字と小文字が厳密に区別されるため、28行目で参照した `dataFilePath` が未定義とみなされエラーが発生しました。
* また、関連する箇所として、31行目の解析結果ファイルパスの定義において、`x4_SingeTrialAnalysisResults`（**l**が抜けている）というスペルミスも発見されました。本来のフォルダ名は `x4_SingleTrialAnalysisResults` です。

### 切り分けの手順
1. エラーメッセージから、`step4_forstudy_check_single_trial_results.m` の 28行目で参照している `dataFilePath` がワークスペースに存在しないことを確認。
2. 27行目で `dataFilepath = sprintf(...)` と定義されている箇所を確認し、大文字・小文字のスペルミスを発見。
3. 31行目の `resultFilePath = sprintf('x4_SingeTrialAnalysisResults/...')` におけるフォルダ名と、実際のフォルダ名 `x4_SingleTrialAnalysisResults` を照合し、タイポを発見。

### 解決策（修正案）
1. `step4_forstudy_check_single_trial_results.m` の 27行目の変数名を `dataFilePath`（大文字の **P**）に修正します。
2. 同ファイル 31行目のパス文字列内 `x4_SingeTrialAnalysisResults` を `x4_SingleTrialAnalysisResults` に修正（"l" を補う）します。

#### 修正前 (27-28行目, 31-32行目)
```matlab
27: dataFilepath = sprintf('x3_DataChecked/Data%02d', iSubject) ;
28: load(dataFilePath)

31: resultFilePath = sprintf('x4_SingeTrialAnalysisResults/SingleTrialAnalysisResults%02d', iSubject) ;
32: load(resultFilePath)
```

#### 修正後 (27-28行目, 31-32行目)
```matlab
27: dataFilePath = sprintf('x3_DataChecked/Data%02d', iSubject) ; % 'p' を大文字の 'P' に修正
28: load(dataFilePath)

31: resultFilePath = sprintf('x4_SingleTrialAnalysisResults/SingleTrialAnalysisResults%02d', iSubject) ; % 'Singe' を 'Single' に修正
32: load(resultFilePath)
```
