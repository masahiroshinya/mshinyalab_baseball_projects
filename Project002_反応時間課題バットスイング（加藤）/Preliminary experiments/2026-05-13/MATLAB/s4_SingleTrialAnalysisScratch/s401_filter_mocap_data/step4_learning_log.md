## 1. マーカーデータとフォースプレートデータの違いの理解

フォースプレートで測定される「床反力（GRF）」や「圧力中心（CoP）」は、マーカーの位置データとは異なる物理特性と計測設定を持っていることを学んだ。

* **サンプリング周波数 ($fs$)**:
  マーカー（位置）データが $200\text{ Hz}$ であるのに対し、フォースプレートデータは通常 $1000\text{ Hz}$ 以上で計測される。力は位置に比べて非常に高速に変化するため、高い時間分解能が必要である。
* **混入するノイズ源**:
  マーカー座標では測定誤差や反射のブレが主だが、フォースプレートでは商用電源ノイズ（$50/60\text{ Hz}$ のハムノイズ）やアンプの電気ノイズ、設置された床の微小な固有振動が高周波ノイズとして混入しやすい。

## 2. フィルター適用の目的

フォースプレートデータにローパスフィルターを適用することで、以下の効果が得られる。

* **ノイズの除去**: 機器由来の高周波ノイズや商用電源ノイズを取り除き、人間が実際に地面を押している滑らかな「真の力」を取り出す。
* **高精度な指標算出**: ノイズを除去することで、スイング中の踏み込み力（GRF）のピーク値や、地面を押す総量である力積（Impulse）、足裏の荷重位置を示すCoP（圧力中心）の軌跡を正しく算出できる。

## 3. フィルターパラメータの設計

* **カットオフ周波数 ($fc$)**:
  バットスイングなどの動作分析では、踏み込み動作の主要な周波数成分を損なわないよう、**$15\text{ Hz} \sim 50\text{ Hz}$** の範囲でローパスフィルターを設計するのが一般的である。
* **フィルター次数 ($order$)**:
  マーカーデータと同様に、2次（`order = 2`）のバターワースフィルターを基本とする。
* **ゼロ位相化 (`filtfilt`)**:
  時間のズレ（位相遅れ）をゼロにするため、MATLABの `filtfilt()` 関数で「順方向・逆方向」の2回フィルタリングを行う。これにより、スイング中の「力の立ち上がりタイミング」や「ピークの瞬間」をミリ秒単位で正確に維持できる。

## 4. 生体力学における重要課題：「カットオフ周波数の不一致問題」

将来的に「関節モーメント（関節トルク）」や「関節パワー」を逆ダイナミクス計算で求める場合、非常に重要なルールがある。

* **問題点**:
  位置データ（キネマティクス）と力データ（キネティクス）を掛け合わせて計算を行う際、それぞれのカットオフ周波数 $fc$ が異なっていると、時間遅れや波形変化のミスマッチから、インパクト（接地）の瞬間に「偽の関節トルク（アーティファクト）」が発生してしまう。
* **対策**:
  サンプリング周波数が異なっていても、**マーカーとフォースプレートのカットオフ周波数 $fc$ は同じ値（例：ともに $15\text{ Hz}$ や $30\text{ Hz}$ など）に揃えてフィルタリングを行う**のが生体力学の標準プロトコールである。

## 5. MATLABでの実装手順イメージ

```matlab
% 1. パラメータ設定
fs_fp = 1000 ;  % フォースプレートのサンプリング周波数 [Hz]
fc_fp = 30 ;    % カットオフ周波数 [Hz]（※逆ダイナミクスを行う場合はマーカーと揃える）
order = 2 ;     % フィルター次数

% 2. バターワースフィルター係数の設計
[b_fp, a_fp] = butter(order, fc_fp / (fs_fp / 2), 'low') ;

% 3. ゼロ位相フィルタリングの適用
% 共通関数 filt_all_fields を用いて、構造体内の全成分に一括適用
Force1_filt = filt_all_fields(b_fp, a_fp, Data.Force1) ;
Force2_filt = filt_all_fields(b_fp, a_fp, Data.Force2) ;
```

### 6-1. CoP（圧力中心）の物理的意味

Figure 2 を確認する際、「踵方向への移動」という表現の意味が最初はわからなかった。

* **CoP とは何か**:
  CoP（Center of Pressure：圧力中心）とは、「足裏のどの位置に体重が集中してかかっているか」を1点の座標（mm）で表したものである。足全体に分布している圧力の重心位置にあたる。
* **CoPx の軸の方向**:
  `s401c_filter_forceplate.m` のサンプルデータでは、CoPx の正方向（＋）を踵側に設定している。
  ```
  つま先 ←──────────────── 踵
         [-30mm]  [0mm]  [+30mm]
                             ↑
                         CoPx の＋方向
  ```
* **バットスイング中の後ろ足（Force1）で起きていること**:
  グラフ上で CoPx が −10 mm から +50 mm へと増加（プラス方向へ移動）している。
  これは、スイング開始とともに後ろ足がつま先で地面を蹴り出し、体重を前足に移す動作を反映している。蹴り出しが進むにつれ、後ろ足に残った力の中心が踵側に寄っていく。

### 6-2. Figure 3 の観察：カットオフ周波数の不一致が残すノイズ

Figure 3 で $fc = 30\text{ Hz}$（黒線）と $fc = 100\text{ Hz}$（赤線）を比較した。

* **観察内容**:
  赤線（$fc = 100\text{ Hz}$）は細かいギザギザが多く残っており、黒線（$fc = 30\text{ Hz}$）は滑らかであった。
* **正確な解釈**:
  これは信号の「パワーの大小」ではなく、「**ノイズの残存量の違い**」である。$fc$ を 100 Hz と高く設定すると、0〜100 Hz の成分をすべて通過させてしまうため、本来除去すべき高周波ノイズが波形に残り続ける。$fc = 30\text{ Hz}$ に揃えることで、ノイズをしっかり除去した滑らかな波形が得られる。
* **逆ダイナミクスへの影響**:
  将来、関節トルクを求める際は「位置データ（モーキャプ）× 力データ（フォースプレート）」を掛け合わせる計算を行う。モーキャプを $fc = 30\text{ Hz}$ で滑らかにしていても、フォースプレートの $fc$ を 100 Hz のままにしておくと、赤線のようにギザギザが残ったデータ同士の積になってしまい、インパクトの瞬間に存在しないはずの「偽の関節トルク（アーティファクト）」が発生する。これが Section 4 で学んだ「カットオフ周波数の不一致問題」の実体である。

## 7. 「力」が「位置」に比べて素早く変化する物理的・身体的メカニズム

なぜ、位置の変化に対して「力」だけが一瞬で劇的に変化するのか。その仕組みを2つの視点から整理した。

### 7-1. 身体的なメカニズム：エンジンと車体のタイムラグ
筋肉（力）と体（位置）の関係は、自動車の「エンジン」と「車体」の関係に似ている。

* **エンジン（筋肉）が一瞬でフルパワーになる**:
  脳から「動け！」と命令が出ると、筋肉が一瞬で「ギュッ」と硬くなり、地面をグッと押す**「力」が一瞬で発生**する。
* **重い車体（体）はすぐには動けない**:
  しかし、体には「重さ（質量）」がある。エンジンが一瞬でフルパワーになっても、重い車体が実際に動き出す（位置が変わる）までには必ずタイムラグが生じる。
* **結論**:
  筋肉は一瞬で硬くなれるが、重い体が動き出すには時間がかかるため、位置の変化よりも先に力だけが素早く立ち上がる。

### 7-2. 物理的なメカニズム：すべては「ものすごく硬いバネ」
足裏（シューズ）やフォースプレート、骨などは、物理的には**「目に見えないほど硬いバネ」**の集まりとして解釈できる。

* **フニャフニャなバネ（クッションなど）**:
  手で押し縮めるとき、10センチくらい「大きく、ゆっくり」縮めることで、ようやく反発力（力）が生まれる。これは「位置が大きくゆっくり変わることで、力もゆっくり変わる」状態。
* **カチカチに硬いバネ（フォースプレートや骨）**:
  フォースプレートなどの硬い物体は、見た目には1ミリも凹んでいないように見えるが、ミクロの顕微鏡レベルでは**わずか「0.001ミリメートル」だけミクロに縮んでいる**。
  硬いバネは、このほんのわずかな変形だけで、一瞬にして巨大な力（反発力）を生み出す。
* **結論**:
  硬いもの同士がぶつかる局面では、位置は 0.001ミリという極小の変化（ほぼゼロ）しかしていないのに、力だけが一瞬で跳ね上がる。
