# 技術説明：床反力分析

## 補助関数の場所

`2026-0604/MATLAB/` に以下の補助関数が配置されています。
MATLABのカレントフォルダを `MATLAB/` に設定すれば `addpath` は不要です。

| 関数名 | 用途 |
|---|---|
| `load_qualisys_mat.m` | Qualisys の .mat ファイルを読み込み、マーカー・フォースプレートデータを整形して返す |
| `lineplot.m` | 現在の axes に垂直（`'v'`）または水平（`'h'`）な補助線を描く |
| `filt_all_fields.m` | Data 構造体の全フィールドにローパスフィルタをかける |
| `interp_nan_spline.m` | マーカー欠損区間（NaN）をスプライン補間する |
| `diff3p.m` | 3点差分法による数値微分 |

---

## `load_qualisys_mat` の仕様

### 呼び出し方

```matlab
Data = load_qualisys_mat(folderName, fileName)
```

- `folderName`：.mat ファイルが入っているフォルダ（カレントフォルダからの相対パス）
- `fileName`：拡張子なしのファイル名（例：`'S01_free0001'`）

### 返り値 `Data` の主なフィールド

| フィールド名 | サイズ | 内容 |
|---|---|---|
| `Data.Force1` | nAnalogSamples × 3 | プレート1の力 [N]（列：Fx, Fy, Fz） |
| `Data.Force2` | nAnalogSamples × 3 | プレート2の力 [N]（列：Fx, Fy, Fz） |
| `Data.Moment1` | nAnalogSamples × 3 | プレート1のモーメント [N·m] |
| `Data.Moment2` | nAnalogSamples × 3 | プレート2のモーメント [N·m] |
| `Data.FPLocation1` | — | プレート1の設置座標 |
| `Data.FPLocation2` | — | プレート2の設置座標 |
| `Data.Markers` | 構造体 | マーカー名をフィールド名とした座標データ（nFrames × 3） |
| `Data.MarkerArray` | nFrames × 3 × nMarkers | 全マーカー座標の配列 |
| `Data.Analog.Frequency` | スカラー | アナログデータのサンプリング周波数 [Hz]（床反力・LEDなど） |
| `Data.FrameRate` | スカラー | マーカーのサンプリング周波数 [Hz] |

### 符号反転について

関数内部で力の符号を反転しています（`force1 = -Data.Force(1).Force'`）。

これは**フォースプレートが計測する力（地面に加えられた力）の向きを、人体に作用する力（床反力）の向きに変換するため**です。

```
フォースプレートの生データ：  地面が受けた力（ヒトが床を踏む向きが正）
符号反転後（Force1, Force2）：  ヒトが受けた力（床がヒトを押す向きが正）

→ Fz > 0 ：床がヒトを上向きに押している（足が床に接地している）
→ Fz = 0 ：その足は床から離れているか、力がかかっていない
```

コード内コメントによると「ヒトが +x 方向に移動する力を +Fx とする」という座標系を採用しています。

## アナログデータとマーカーデータのサンプリング周波数の違い

| データ種別 | フィールド | 典型値 |
|---|---|---|
| マーカー座標 | `Data.FrameRate` | 200 Hz |
| 床反力・LEDなどアナログ | `Data.Analog.Frequency` | 1000 Hz |

床反力は素早い力の変化を捉えるため、マーカーより高い周波数で計測されます。
時間軸を作る際は、どちらのデータに対してどちらのサンプリング周波数を使うかに注意してください。

## トラブルシューティング

### TS-01：`load_qualisys_mat` 実行時にファイルが見つからないエラー

**発生日：** 2026-06-09
**ユーザー：** mshinyalab

**エラーメッセージ：**
```
ファイルまたはディレクトリ '../../2026-0604/x1_RawData/2026-0604予備実験\S01_free0001' が見つかりません。
```

**原因（2つ）：**

1. **相対パスの基点の誤解** — 相対パスは「スクリプトの場所」ではなく「MATLABのカレントフォルダ」を基準に解釈される。カレントフォルダが `2026-0604/MATLAB/` のとき、`../../` は `2026-0604/` まで上がってしまい、その階層には `x1_RawData/` が存在しない。

2. **フォルダ名のアンダースコア漏れ** — コードは `2026-0604予備実験` と記述していたが、実際のフォルダ名は `2026-0604_予備実験`（`_` あり）。

**切り分け手順：**
1. MATLABコマンドウィンドウで `pwd` を実行し、カレントフォルダを確認した。
2. `Get-ChildItem`（PowerShell）でフォルダ構造を確認し、`x1_RawData` の実際の場所とフォルダ名を特定した。

**解決策：**
```matlab
% 修正前
folderName = '../../2026-0604/x1_RawData/2026-0604予備実験';

% 修正後（カレントフォルダが MATLAB/ の場合）
folderName = 'x1_RawData/2026-0604_予備実験';
```

### TS-02：`Data.AnalogFs` フィールドが認識されないエラー

**発生日：** 2026-06-09
**ユーザー：** mshinyalab

**エラーメッセージ：**
```
フィールド名 "AnalogFs" が認識されません。
```

**原因：**
ワークフローのサンプルコードおよびこの技術説明.md に `Data.AnalogFs` と記載していたが、実際の Qualisys .mat ファイルにはそのフィールドが存在しない。アナログのサンプリング周波数は `Data.Analog.Frequency`（ネストした構造体）に格納されている。

**切り分け手順：**
1. `fieldnames(Data)` でトップレベルのフィールド一覧を確認した。
2. `Data.Analog` を実行してサブフィールドを確認し、`Frequency` を発見した。
3. `Frequency` の大文字・小文字に注意（`frequency` は不可）。

**解決策：**
```matlab
% 修正前
Data.AnalogFs

% 修正後
Data.Analog.Frequency
```

**影響箇所：** スクリプト内で `Data.AnalogFs` を参照している全行（`fprintf` と `fsAnalog = ...` の2か所）。

## `lineplot` の使い方

```matlab
lineplot(X, 'v', 'r--')   % x = X に赤い破線の垂直補助線を引く
lineplot(Y, 'h', 'k-')    % y = Y に黒い実線の水平補助線を引く
```

第3引数以降は `plot` と同じ線スタイル指定が使えます。
`xline` と異なりラベル引数はありませんが、`hold on` 状態の axes でも軸範囲が変化しません。
