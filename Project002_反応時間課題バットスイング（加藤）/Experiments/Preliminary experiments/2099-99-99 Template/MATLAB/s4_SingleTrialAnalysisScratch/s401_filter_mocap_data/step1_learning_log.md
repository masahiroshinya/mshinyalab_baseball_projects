## 1. グラフの見方（時間領域と周波数領域）

スクリプト実行結果（Figure 1, Figure 2）の左右のグラフの違いについて。

- **左側の列（時間領域）**:
  - 横軸：Time [s]（時間）
  - 縦軸：Amplitude [mm]（振幅・どれくらい動いたか）
  - FFT（フーリエ変換）される前の、生の波形データ（パラパラ漫画の状態）。
- **右側の列（周波数領域 / パワースペクトル）**:
  - 横軸：Frequency [Hz]（周波数・1秒間に何回揺れるか）
  - 縦軸：Power [mm]（その周波数の揺れがどれくらい強く含まれているか）
  - 生の波形データを **FFT（高速フーリエ変換）** にかけ、「どの周波数成分がどれくらい含まれているか」という成分表に変換したもの。

### Amplitude（振幅）とは？
- グラフの中心（ゼロ）から、波の山（または谷）までの高さのこと。
- モーキャプの文脈（単位 `mm`）では、**「マーカーが空間的に何ミリ揺れ動いたか」** という物理的なズレの量を表す。

## 2. モーキャプノイズの性質（なぜ白色雑音なのか？）

ノイズには大きく分けて特定の周波数に集中するものと、そうでないものがある。

1. **ハムノイズ（特定の周波数に集中するノイズ）**
   - 筋電図（EMG）などに入りやすい、電源由来の電気的ノイズ（東日本なら50 Hz）。
   - 周波数グラフでは **50 Hz の位置に鋭い1本のピーク** が立つ。
   - ピンポイントでノイズの周波数が分かるため、そこだけを「狙い撃ち」して消すことができる（ノッチフィルタ）。
2. **モーキャプのノイズ（ランダムノイズ / 白色雑音）**
   - カメラのピクセル計算誤差、マーカーの微小な振動、光の乱反射などがランダムに重なって発生する。
   - 特定のリズムを持たないため、周波数グラフでは **0 Hz から 100 Hz まで全体にわたってパワーが広がった状態（白色雑音・ホワイトノイズ）** になる。
   - ノイズが全帯域に散らばっているため、特定の周波数だけを狙い撃ちで消すことができない。

## 3. なぜローパスフィルターが必要なのか？（次のステップへの接続）

モーキャプのノイズが「全体にべたーっと広がる白色雑音」であるため、狙い撃ちでの消去はできない。
そこで、**「人間の動作（バットスイング）は低い周波数帯（約 0〜10 Hz）に集中している」** という性質を利用する。

- **解決策**: 低い周波数（スイング動作）だけを通過させ、それより高い周波数（広範囲に広がるランダムノイズ）をスパッと切り捨てる。
- これが **ローパスフィルター（Low-pass filter）** の役割である。

## 4. 補足：バットスイング解析におけるFFTの使い方（STFTとの違い）

- 一般的な音声解析などでは、時間変化に伴う周波数の変化を見るために「時間を細切れにしてFFTをかける（STFT / スペクトログラム）」手法が取られる（時間と周波数の両立）。
- しかし、今回のバットスイング解析のノイズ除去においては、**「ノイズ（白色雑音）も、スイング動作も、計測中はずっと一定の帯域に存在する」** ため、STFTを使う必要はない。
- 全体のデータに一気にFFTをかけて得られたパワースペクトル（成分表）だけを見て、「何 Hz 以上をノイズとして切り落とすか（カットオフ周波数）」を決めるだけで十分である。
