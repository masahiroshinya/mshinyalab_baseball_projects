## 1. 実際のバットスイングデータへのフィルター適用
* **概要**:
  `SampleData.mat`（バットの先端・根本の3次元座標データ）に対し、サンプリング周波数 `fs=200Hz`、カットオフ周波数 `fc=30Hz`、2次（`order=2`）のバターワースローパスフィルターを適用した。
* **観察内容**:
  プロットされたグラフ全体を見ると、フィルター前後でバットの大きな軌跡は全く変わっていないように見えた。しかし、波形を拡大（ズーム）して観察すると、元のデータ（グレーの線）には細かいギザギザした高周波ノイズが含まれており、フィルター適用後のデータ（黒の滑らかな線）ではそのノイズが綺麗に除去され、かつグレーの波形のちょうど中心を通っていることが確認できた。

## 2. ゼロ位相フィルタリング（filtfilt）の重要性
* **理論的背景**:
  通常のフィルター処理（一方向のみのフィルタリング）では、データがフィルターを通る際に計算の遅延が生じ、波形が時間的に後ろへズレる「位相遅れ」が発生する。バットスイングのインパクトの瞬間など、ミリ秒単位のタイミングが重要な生体力学（バイオメカニクス）分析において、この遅れは致命的となる。
* **解決策**:
  MATLABの `filtfilt()` 関数は、データを「前から後ろ（順方向）」へフィルタリングした後、さらに「後ろから前（逆方向）」へもフィルタリングをかける。これにより、順方向で生じた位相遅れが逆方向の処理で打ち消され、**「位相遅れゼロ（Zero-phase）」**でのノイズ除去が可能となる。
* **モーキャプ分析での教訓**:
  ズームしたグラフで「黒い線がグレーの線のギザギザの中心を、左右にズレることなく通っている」という観察結果は、まさにこのゼロ位相フィルタリングが成功している証拠である。タイミングを維持したまま滑らかな軌跡を得ることが、速度や加速度の正確な算出に不可欠である。

## 3. フィルターを2回かけることによる「次数の魔法」
* **理論的背景**:
  `filtfilt` 関数はデータを「前向き」と「後ろ向き」の合計2回フィルターにかける。これは直感的には「ザルを2回くぐらせる」ことと同じであるため、ノイズはより強力に除去される。
* **次数の実質的な倍増**:
  スクリプト上で `order = 2`（2次）と設定していても、`filtfilt` で2回フィルターを通すことにより、**実質的には 4次（order = 4）のフィルターをかけたのと同じ減衰特性（切れ味）**が得られる。
* **モーキャプ分析での教訓**:
  生体力学の分野で「2次または4次のバターワースフィルター」が標準とされるのはこのためである。プログラム上で設定を2次（`order = 2`）にしておき、`filtfilt` を使って位相遅れをゼロにしつつ、実質的に4次の強力で理想的なフィルター効果（綺麗な滑らかさ）を得る、というのが研究者の間で使われる王道のテクニックである。

## 4. バターワースフィルターという名前の由来と意味
* **由来**:
  1930年にこのフィルターの計算式を発明したイギリスの物理学者、スティーブン・バターワース（Stephen Butterworth）の名前に由来している。
* **特性と選ばれる理由**:
  チェビシェフ・フィルターなど、ノイズをより急激にカットできる他のフィルター（ザル）も存在するが、それらは副作用として残したいデータ（通過帯域）に「偽の波打ち（リップル）」を発生させてしまう欠点がある。
  対してバターワースフィルターは、**「通過帯域が極限まで平坦（フラット）で、波打ち等の変なクセを一切つけない」**という特性を持つ。
* **モーキャプ分析での教訓**:
  人間の動きの軌跡を歪ませることなく、「最も素直に、安全にフィルターをかけることができる計算式（ブランド）」であるため、バイオメカニクス分野での標準的な手法として広く採用されている。
