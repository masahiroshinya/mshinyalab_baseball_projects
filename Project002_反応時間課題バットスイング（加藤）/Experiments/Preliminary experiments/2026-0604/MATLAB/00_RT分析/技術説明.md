## 2. 手部 Onset の算出方法（Nasu et al. 2020 方式）

### 2.1 定義

**投手方向の手部速度（骨盤速度を除いたもの）が、平均ピーク速度の 10% を超えた時点。**

> "Swing onset was defined as the moment at which the hand velocity exceeded a certain threshold, which was **10% of the mean peak velocity** for each batter."

### 2.2 算出手順

| # | 手順             | 内容                                                                                                         |
| - | ---------------- | ------------------------------------------------------------------------------------------------------------ |
| 1 | NaN 補間         | **マーカーごとに**欠損を線形補間で埋める                                                               |
| 2 | 代表点を作る     | 手部 =`Firtst` / `Second` / `Third` の重心骨盤 = `RASIS` / `LASIS` / `RRPSIS` / `LPSIS` の重心 |
| 3 | 平滑化           | 30 Hz バターワース 2次・`filtfilt`（実効4次）                                                              |
| 4 | 相対位置         | `相対位置 = 手部重心 − 骨盤重心`、mm → m に変換                                                          |
| 5 | 微分             | `diff3p`（中心差分）で速度 [m/s]                                                                           |
| 6 | 成分を取る       | **+X 成分のみ**（+X = 投手方向）                                                                       |
| 7 | 試行ごとのピーク | `peakVel(i) = max(v)`                                                                                      |
| 8 | 閾値を決める     | `thrVel = 0.10 × mean(peakVel)`（**全試行のピークの平均**の 10%）                                   |
| 9 | Onset を検出     | ピーク時刻から**時間を遡り**、`v ≤ thrVel` となった最後の点                                         |

手順 8 で閾値が全試行の平均ピークに依存するため、**2 パス構成**になる。第1パスで全試行の速度波形とピークを求めて閾値を確定し、第2パスで Onset を検出する。

### 2.3 各手順の根拠

**手順1・2：補間はマーカーごとに、代表点を作る前に行う**

「重心」はマーカー座標の単純算術平均であり、マーカーが作る図形の幾何学的重心（解剖学的な質量中心ではない）。

補間より先に平均してしまうと、欠損フレームでは使用マーカー数が変わり、代表点が数十 mm 単位で不連続に移動する。微分すると偽の速度スパイクになるため、必ずマーカーごとに補間してから平均する。なお `filtfilt` は NaN を全体に伝播させるので、補間はフィルタより前でもある。

> 手部は剛体登録されているので、最小二乗剛体変換（Söderkvist & Wedin 法）で欠損を再構成すればより正確になる。本テスト分析では線形補間で済ませている。

**手順4：骨盤速度を引く理由**

体幹の並進成分を除去し、「手が体に対して動き出した瞬間」を捉えるため。体重移動で身体全体が投手方向へ流れると手部の絶対速度も上がるが、それはスイング開始ではない。

**手順6：投手–捕手方向をラボ座標系 +X に固定する理由**

骨盤 ML 軸から都度計算する方法もあるが、マーカーのラベル誤りがあると座標系ごと反転してしまう（§7.1 で実際に発生）。固定軸ならその影響を受けない。

**手順7：`max(v)` であって `max(abs(v))` ではない理由**

速度波形は、ステップ／割れの局面で一方向へ動いたのち、スイング本体で逆方向のピークが出る。絶対値で取ると試行によって拾う局面が変わり、開始時刻が数百 ms ずれる。原法は投手方向への手部の前進を見ているので、`max(v)` に限定する。

**手順8：相対閾値（10%）である理由**

スイングの大きさには個人差があるため、全員に同じ絶対閾値を当てると、スイングが大きい打者ほど早く閾値に達し、検出タイミングが体格・技術レベルによって系統的にずれる。ピーク速度に対する比で定義すればこの系統誤差が入らない。

**手順9：ピークから遡って探す理由**

前向き（t=0 から順方向）に「初めて閾値を超えた点」を探すと、構え・ステップ動作で生じる小さな山を誤検出しうる。本データでもスイング本体の 0.5〜1 秒前に 0.2〜1.1 m/s の前進成分が現れ、閾値を超える試行があった。

### 2.4 原著との違い

| 項目         | 原著（Nasu 2020）          | 本実装                  |
| ------------ | -------------------------- | ----------------------- |
| 計測機器     | 慣性センサー Xsens、240 Hz | 光学式 Qualisys、250 Hz |
| 手部の代表点 | Xsens のセグメント原点     | 剛体3点の幾何学的重心   |
| 骨盤の代表点 | Xsens のセグメント原点     | 骨盤4点の幾何学的重心   |

代表点の取り方の違いは、剛体の速度式 `v_P = v_O + ω × r` の第2項として現れる。Onset の時点では角速度 ω がほぼゼロなので検出時刻への影響は小さく、影響が出るのは主にピーク速度（＝閾値）の側。

## 3. 床反力 Onset の算出方法（比較対象）

### 3.1 定義

**後ろ足の鉛直床反力 Fz1 が、静止時の平均から標準偏差の 10 倍以上ずれた状態が 30 ms 続いた、その最初の時点。**

既存の `m3_analyze_single_trial.m` と同じロジック。

### 3.2 算出手順

| # | 手順             | 内容                                                    |
| - | ---------------- | ------------------------------------------------------- |
| 1 | データを取る     | `Data.Force1(:,3)` = plate1（後ろ足）の Fz、1000 Hz   |
| 2 | ベースライン区間 | **キュー直後 0.5 秒**（`Prm.RT.BaseSec = 0.5`） |
| 3 | 静止時の統計量   | その区間の平均`mu` と標準偏差 `sd`                  |
| 4 | 閾値判定         | `abs(Fz1 - mu) > Prm.RT.FzK * sd`（`FzK = 10`）     |
| 5 | 持続条件         | 上記が`Prm.RT.DurMs = 30` ms 連続した最初の区間を探す |
| 6 | Onset            | その区間の**先頭サンプル**の時刻                  |

### 3.3 各手順の根拠

**手順2：ベースラインをキュー直後に取る理由**

既存実装は「キュー直前 0.5 秒」だが、今回は t=0 がキューなのでキュー前が存在しない。動作開始が最短でも 1.4 秒なので 0〜0.5 秒は静止区間として使えるが、被験者が構えを完了する前だと SD が過大になり、閾値 `10*sd` が緩くなって検出が遅れる。本データの plate1 の SD は試行間で 4.6〜8.7 N とばらついているので、プロットで目視確認すること。

**手順4：偏差の絶対値で判定する理由**

後ろ足の荷重は増える方向にも減る方向にも動きうるため。沈み込みで荷重が増える場合と、踏み込み足へ体重を移して荷重が抜ける場合の両方を検出する。絶対値で見ているので、Fz の符号の向きは検出結果に影響しない。

**手順5：持続条件を設ける理由**

誤検出防止。単発のノイズスパイクが 10 SD を超えても、30 ms 続かなければ動作開始とはみなさない。

## 4. 提案コード

`00_RT分析/s_nasu_rt_check.m` として保存する想定。MATLAB のカレントディレクトリは `2026-0604/MATLAB/` とする。

```matlab
function s_nasu_rt_check()

% Nasu et al. (2020) 方式のスイング開始検出と、床反力（後ろ足 Fz1）による
% 動作開始検出を比較する（2026-08-03 テストデータ用）。
% 今回はアナログの LED 信号がないため、計測開始（t=0）をキュー提示時刻とみなす。

Prm = parameters ;

folderName = fullfile('x1_RawData', '2026-0803_RT_check') ;
fileNames  = {'RT_6DOF0001', 'RT_6DOF0002', 'RT_6DOF0004', 'RT_6DOF0006'} ;
nTrial     = numel(fileNames) ;

% ---- 第1パス：全試行を読み込み、投手方向の手部速度とそのピークを求める ----
%  閾値は全試行の平均ピーク速度に依存するので、先に全試行分を出しておく。
S = struct('velHandX', {}, 'Fz1', {}, 'fs', {}, 'fsA', {}) ;
peakVel = nan(nTrial, 1) ;

for iTrial = 1:nTrial

    Data = load_qualisys_mat(folderName, fileNames{iTrial}) ;

    fs  = Data.FrameRate ;
    fsA = size(Data.Force1, 1) / (Data.Frames / fs) ;   % = 1000 Hz
    [b, a] = butter(2, Prm.Fc/(fs/2)) ;

    % マーカーごとに補間 → 重心 → フィルタ（この順序が必須。§2.3）
    hand = filtfilt(b, a, mean_marker(Data.Markers, {'Firtst', 'Second', 'Third'})) ;
    pelv = filtfilt(b, a, mean_marker(Data.Markers, {'RASIS', 'LASIS', 'RRPSIS', 'LPSIS'})) ;

    % 手部から骨盤を引き、体幹の並進成分を除く。
    % 単位は mm なので 1000 で割って m にしてから微分する。
    relPos   = (hand - pelv) / 1000 ;                 % [m]
    velRel   = diff3p(relPos, 1/fs) ;                 % [m/s]
    velHandX = velRel(:, 1) ;                         % +X = 投手方向

    S(iTrial).velHandX = velHandX ;
    S(iTrial).Fz1      = Data.Force1(:, 3) ;          % 符号は読み込み時に反転済み
    S(iTrial).fs       = fs ;
    S(iTrial).fsA      = fsA ;

    peakVel(iTrial) = max(velHandX) ;                 % 投手方向の最大値＝スイング本体
end

% ---- 相対閾値：平均ピーク速度の 10% ----
thrVel = 0.10 * mean(peakVel) ;

% ---- 第2パス：スイング開始と床反力の動作開始を検出 ----
Result = table('Size', [nTrial 5], ...
    'VariableTypes', {'string','double','double','double','double'}, ...
    'VariableNames', {'Trial','PeakVel','RTHand','RTForce','Diff'}) ;

for iTrial = 1:nTrial

    fs  = S(iTrial).fs ;
    fsA = S(iTrial).fsA ;
    v   = S(iTrial).velHandX ;

    % スイング開始：ピークから時間を遡り、閾値を下回った最初の点（§2.3）
    [~, idxPeak] = max(v) ;
    idxOn = find(v(1:idxPeak) <= thrVel, 1, 'last') ;
    tHand = idxOn / fs ;                              % [s] キュー = t=0

    % 床反力：キュー直後 0.5 秒を静止区間とし、
    % |Fz1 - mu| > k*sd が 30 ms 続いた最初の時点を動作開始とする。
    Fz1   = S(iTrial).Fz1 ;
    nBase = round(Prm.RT.BaseSec * fsA) ;
    mu    = mean(Fz1(1:nBase)) ;
    sd    = std(Fz1(1:nBase)) ;

    thrFz = Prm.RT.FzK * sd ;
    over  = abs(Fz1 - mu) > thrFz ;
    holdN = round(Prm.RT.DurMs/1000 * fsA) ;
    idxF  = first_sustained(over, holdN) ;
    tForce = idxF / fsA ;                             % [s]

    Result.Trial(iTrial)   = fileNames{iTrial} ;
    Result.PeakVel(iTrial) = peakVel(iTrial) ;
    Result.RTHand(iTrial)  = tHand  * 1000 ;          % [ms]
    Result.RTForce(iTrial) = tForce * 1000 ;          % [ms]
    Result.Diff(iTrial)    = (tHand - tForce) * 1000 ;

    plot_trial(S(iTrial), thrVel, mu, thrFz, tHand, tForce, fileNames{iTrial}) ;
end

fprintf('\n閾値（平均ピーク %.2f m/s の 10%%）= %.3f m/s\n\n', mean(peakVel), thrVel) ;
disp(Result)

end


% ---- 指定マーカーの幾何学的重心 ----
%  各マーカーを個別に補間してから平均する（§2.3）。
function y = mean_marker(Markers, names)
x = nan(size(Markers.(names{1}), 1), 3, numel(names)) ;
for i = 1:numel(names)
    x(:,:,i) = interp_nan_linear(Markers.(names{i})) ;
end
y = mean(x, 3) ;
end


% ---- 列ごとに NaN を線形補間 ----
function x = interp_nan_linear(x)
t = (1:size(x,1))' ;
for col = 1:size(x,2)
    nanIdx = isnan(x(:,col)) ;
    if any(nanIdx) && any(~nanIdx)
        x(nanIdx,col) = interp1(t(~nanIdx), x(~nanIdx,col), t(nanIdx), 'linear', 'extrap') ;
    end
end
end


% ---- 閾値超えが holdN サンプル続いた最初の位置（m3 と同じロジック）----
function idx = first_sustained(over, holdN)
idx = [] ;
d = diff([0; over(:); 0]) ;
starts = find(d==1) ; ends = find(d==-1)-1 ;
run = find((ends-starts+1) >= holdN, 1, 'first') ;
if ~isempty(run), idx = starts(run) ; end
end


% ---- 手部速度と Fz1 を時間軸を揃えて重ね描き ----
%  縦線 = onset（赤 = 手部、青 = 床反力）、破線 = 検出に使った閾値。
%  onset の時刻はタイトルに出す（波形の上には重ねない）。
function plot_trial(s, thrVel, mu, thrFz, tHand, tForce, name)
tM = (1:numel(s.velHandX))' / s.fs ;
tA = (1:numel(s.Fz1))'      / s.fsA ;

figure('Name', name) ;

subplot(2,1,1)
plot(tM, s.velHandX, 'k') ; hold on
yline(thrVel, 'r--') ;
xline(tForce, 'b') ; xline(tHand, 'r') ;
ylabel('手部速度 X [m/s]') ; xlim([0 5])
title(sprintf('%s   手部 %.0f ms / 床反力 %.0f ms （差 %+.0f ms）', ...
      name, tHand*1000, tForce*1000, (tHand-tForce)*1000), 'Interpreter', 'none')

subplot(2,1,2)
plot(tA, s.Fz1, 'k') ; hold on
yline(mu + [-1 1] * thrFz, 'r--') ;
xline(tForce, 'b') ; xline(tHand, 'r') ;
ylabel('後ろ足 Fz1 [N]') ; xlabel('計測開始からの時間 [s]') ; xlim([0 5])
end
```

## 6. 制約と注意点

**RT の絶対値には意味がない。**
キューを計測開始としているため、上表の 1.4〜2.2 秒は「QTM の録画開始ボタンを押してから被験者が動くまで」であり、実験者のボタン操作の間合いを含む。解釈可能なのは**手部 onset と床反力 onset の差（+81〜135 ms）のみ**で、反応時間そのものの値として報告してはならない。

本番計測では LED にフォトセンサを取り付けてアナログ収録し、刺激提示時刻を記録すること。

**平均ピーク速度の試行数。**
Nasu の「打者ごとの平均ピーク速度」は本来より多くの試行から求めるもの。4 試行では 1 試行の外れ値が閾値を直接動かす。本番では全試行を用いること。

**床反力ベースラインの目視確認。**
§3.3 のとおり、静止区間が実際に静止しているかをプロットで確認すること。

## 7. データ品質の記録

### 7.1 RT_6DOF0003（除外）：RASIS と LASIS のラベルが左右逆

静止区間の骨盤 ML 軸（RASIS→LASIS）が `[-0.97, 0.24, 0]` となり、他5試行の `[+0.9, -0.3, 0]` と真逆だった。QTM のラベリングで左右が入れ替わっている。加えて RASIS 56%・LASIS 73% と欠損も大きい。

→ QTM 側でラベルを修正すること。なお投手方向を +X に固定していれば座標系の反転は防げるが、骨盤速度の算出自体は誤ったままなので、ラベル確認は別途必要。

### 7.2 RT_6DOF0005（除外）：静止区間の RASIS が 80% 欠損

全区間でも 21% 欠損。線形補間で埋めても骨盤速度の基準として信頼できない。

### 7.3 マーカー欠損率一覧（全6試行）

| -------- | ----- | ------------------ | ------------------------------ |

| 0002     | 0%    | 14%                | 採用                           |
| 0003     | 56%   | 73%                | **除外**（ラベル左右逆） |
| 0004     | 3%    | 17%                | 採用                           |
| 0005     | 21%   | 1%（静止区間 80%） | **除外**                 |

バット5点は全試行で欠損 0%。骨盤マーカー、特に LASIS の欠損が全体に多いので、本番計測前に**カメラ配置とマーカー貼付位置の見直し**を推奨する。
