# バットスイングスピードの定義：本研究における2つの方針

## 1. 概要

本研究における「バットスイングスピード（swing speed）」を定義します。

スイングスピードは以下の**2つの用途**で使用されます。

| 用途 | 内容 |
|------|------|
| **スイング開始検出の閾値** | 反応時間算出のためのスイング開始フレーム検出に使用（全試行の平均ピーク速度の10%） |
| **パフォーマンス指標** | バッターのスイング能力を表す独立した分析変数として使用する場合 |

> **重要**：反応時間定義（`学習用_6`）でスイング開始の検出に使うマーカーと、スイングスピードを測定するマーカーは**異なります**。
> - スイング**開始検出**：`bottom` マーカー（グリップ端）を使用（方針1）
> - スイング**スピード測定**：`top` マーカー（バット先端＝バレル）を使用（方針1）

---

## 2. バットスイングスピードの一般的な定義（先行研究）

### 2.1 スポーツ科学・業界標準の定義

スポーツ計測機器や公式統計では、バットスピードを以下のように定義しています。

| 定義元 | 計測位置 | 代表値 |
|--------|----------|--------|
| MLB Statcast | バット先端から約**15cm（6インチ）** 以内のスウィートスポット | MLB平均：71–75 mph（≈ 32–34 m/s）|
| Blast Motion | バット先端から**6インチ**の位置の直線速度 | — |
| WSU Sports Science Lab | バット質量中心（スウィートスポット付近）の直線速度 | — |

> **スウィートスポット**とは、バット先端から4〜8インチ（約10〜20cm）の範囲にある、インパクト時の振動（sting）が最小となる領域です。一般的には先端から6インチ（≈ 15cm）の点で近似されます。

### 2.2 学術研究における定義と測定値

| 文献 | 計測位置 | 速度の種類 | 代表値 | 計測方法 |
|------|----------|------------|-------|----------|
| Welch et al. (1995) | バット（全体） | 直線速度の最大値 | **31 m/s**（≈ 70 mph） | 23マーカー、6カメラ、200 fps |
| Nicholls et al. (2003) | **バット遠位端（barrel/tip）** + 近位端（grip） | 直線速度（水平成分） | 遠位端：35–37 m/s、近位端：4–5 m/s | 高速ビデオ |
| Kidokoro & Morishita (2021) | バット先端（4マーカー）+ 先端から45cm（4マーカー） | 3D瞬間速度 | — | モーションキャプチャ、キュービックスプライン回帰 |

### 2.3 先行研究から得られる示唆

1. **バット先端（遠位端/バレル）が計測標準**：Nicholls et al. (2003) がバット遠位端の速度を報告しており、先端速度の測定が最も一般的です。
2. **グリップ端（近位端）はバレルより約7倍遅い**：Nicholls et al. (2003) では、遠位端（35–37 m/s）に対し近位端（4–5 m/s）と大きな差があります（てこの原理）。
3. **ピーク速度はインパクト直前に発生**：加速フェーズの最後、インパクト直前にバット速度が最大になります。
4. **本研究方針1の根拠**：`top` マーカー（バット先端）の3D合成ピーク速度を使う 方針1 は、Nicholls et al. (2003) の「遠位端速度」の定義と一致します。

## 3. 方針1：個別マーカー版（`top` マーカー使用）

バットに個別の反射マーカー（`top` = バット先端、`bottom` = グリップ端）を貼付している場合に適用します。

| 要素 | 定義 |
|------|------|
| **使用マーカー** | `top`（バット先端＝バレル付近） |
| **速度方向** | **3D 合成速度** |
| **代表値（1試行）** | 試行内のピーク速度（`max(netVelTop)`） |
| **代表値（被験者全体）** | 全試行の平均ピーク速度 |
| **適用条件** | バットに `top` マーカーを貼付している実験設計の場合 |

### なぜ `top` マーカー（バット先端）を使うのか

バットはグリップを支点とした**回転運動**をするため、**てこの原理**により先端（バレル）が最も速く動きます。

- Nicholls et al. (2003) の実測値：バット遠位端（バレル）= 35–37 m/s、グリップ端 = 4–5 m/s
- 先端の速度はグリップ端の約**7倍**

```
グリップ（支点）─────────── バレル（先端）
            ↑                    ↑
         4–5 m/s              35–37 m/s（Nicholls 2003）
```

反応時間算出では `bottom` マーカーでスイング開始を検出しますが、スイングスピードの指標は `top` マーカーで測定します。

## 4. 方針2：剛体トラッキング専用版

バットを剛体（rigid body）としてのみトラッキングする場合に適用します（`top` / `bottom` の個別マーカーなし）。

| 要素 | 定義 |
|------|------|
| **使用データ** | バット剛体の**原点**（Qualisys で設定したグリップ端付近の基準点）の位置座標 |
| **速度方向** | **3D 合成速度** |
| **代表値** | 試行内のピーク速度・全試行の平均ピーク速度 |
| **適用条件** | 剛体トラッキングのみの実験設計の場合（予備実験など） |

> **注意**：剛体原点はグリップ端付近に設定されているため、バレルの速度（方針1の `top` マーカー）より大幅に**小さい値**になります（Nicholls et al. 2003 によると約7分の1）。
> 試行間・条件間の**相対的な比較**には使用できますが、先行研究のバット速度の値と直接比較する際は注意が必要です。

## 5. 速度の計算方法

位置データ（mm）から速度（mm/s）を算出する一般的な手順です。

### 手順

1. **フィルタリング**：位置データにバターワースフィルタをかけてノイズを除去する
2. **微分（速度算出）**：`diff3p` 関数（中心差分法）で速度を算出する
3. **3D 合成速度**：X・Y・Z 方向の速度成分を合成する

### MATLAB コード例（方針1）

```matlab
% フィルタリング済み top マーカーの3D合成速度を算出
top = M.top ;                             % top マーカー位置（n × 3 行列、単位: mm）
velTop = diff3p(top, 1/fs) ;              % 中心差分で速度算出（mm/s）
netVelTop = sum(velTop.^2, 2).^0.5 ;     % 3D合成速度（mm/s）
peakVelTop = max(netVelTop) ;            % 1試行のピーク速度
```

### 補足：`diff3p`（中心差分法）とは

`diff` 関数（前向き差分）と異なり、前後のフレームを使って計算するため、**より精度の高い速度推定**ができます。

```
中心差分：v[i] = (x[i+1] - x[i-1]) / (2 × Δt)
前向き差分：v[i] = (x[i+1] - x[i]) / Δt   ← 位相がずれる
```

なお、Kidokoro & Morishita (2021) のように**キュービックスプライン補間**で高精度な速度を求める方法もありますが、本研究のようなサンプリング周波数（100 Hz）では中心差分法で十分です。

## 6. ピーク速度の定義

### 6.1 1試行のピーク速度

1試行における3D合成速度波形の**最大値**を「ピーク速度」とします。

> **検索範囲の注意**：待機中の微細な動きを除外するため、LED点灯後（`tCueMarker` 以降）を対象範囲にすることを推奨します。

```matlab
searchRange = tCueMarker : length(netVelTop) ;
peakVel = max(netVelTop(searchRange)) ;
```

### 6.2 全試行の平均ピーク速度（反応時間閾値の算出用）

反応時間のスイング開始検出閾値は「**全試行の平均ピーク速度の10%**」で算出します（Nasu et al. 2020 に準拠）。

```matlab
% 全試行のピーク速度を収集して平均を算出
nTrials = size(DataArray, 1) ;
peakVelArray = zeros(nTrials, 1) ;

for iTrial = 1:nTrials
    Data_i = DataArray(iTrial, iCondition) ;
    M_i    = filt_all_fields(b, a, Data_i.Markers) ;
    top_i  = M_i.top ;
    vel_i  = diff3p(top_i, 1/fs) ;
    netVel_i = sum(vel_i.^2, 2).^0.5 ;
    searchRange_i = tCueMarker : length(netVel_i) ;
    peakVelArray(iTrial) = max(netVel_i(searchRange_i)) ;
end

meanPeakVel = mean(peakVelArray, 'omitnan') ;   % 全試行の平均ピーク速度
threshold   = 0.10 * meanPeakVel ;             % スイング開始の閾値（10%）
```

## 7. 方針1と方針2の比較

| 比較項目 | 方針1（個別マーカー版） | 方針2（剛体専用版） |
|----------|------------------------|---------------------|
| **計測点** | `top`（バット先端＝バレル） | 剛体原点（グリップ端付近） |
| **速度の大きさの目安** | 35–37 m/s（Nicholls 2003 相当） | 4–5 m/s（グリップ端相当、Nicholls 2003） |
| **先行研究との対応** | バレル速度 = スポーツ科学での標準的な「バット速度」の定義に一致 | 近似的な代替指標（先行研究との直接比較に注意） |
| **適用実験** | 追加実験・本実験（マーカー追加後） | 予備実験（2026-05-13、2026-0604） |
| **反応時間検出との対応** | スイング開始は `bottom`、スピードは `top`（別マーカー） | どちらも剛体原点で共通 |
