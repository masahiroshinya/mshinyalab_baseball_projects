# 分析除外メモ（exclusion_memo.csv）の使い方

x5 などで波形を目視確認したときに、「分析から除外したい試行」とその理由を書き留めるためのメモです。
1行に1試行ずつ書きます。

## 列の意味

| 列名 | 内容 | 書き方の例 |
|---|---|---|
| Subject | 被験者番号 | `5` |
| Condition | 条件名 | `free` / `simple` / `gonogo` / `gostop` |
| Trial | 試行番号（x5 の図の Trial 番号） | `12` |
| Target | 除外する対象 | `top`（速度のみ）/ `Fz`（床反力のみ）/ `all`（試行ごと） |
| Reason | 除外理由（具体的に） | `ピーク付近で top 速度が途切れている` |
| Recorder | 記入者 | `加藤` |
| Date | 記入日 | `2026-09-28` |

記入例：

```
Subject,Condition,Trial,Target,Reason,Recorder,Date
5,free,12,Fz,Fz2 のゼロ点がずれている,加藤,2026-09-28
5,gonogo,3,top,ピーク付近で top が欠損,加藤,2026-09-28
```

## 注意

- **Reason にカンマ（,）を入れない。** 入れると列がずれます。区切りたいときは「、」や「／」を使ってください。
- Excel で開いて編集しても構いません。保存するときは「CSV UTF-8」形式を選んでください。ほかの形式で保存すると日本語が文字化けします。
- このメモは記録のためのものです。現時点では、x6 以降のコードはこのファイルを読みません。除外を解析に反映させる場合は、別途コードを修正してください。MATLAB からは次のように読み込めます。

  ```matlab
  T = readtable('exclusion_memo.csv', 'TextType', 'string') ;
  ```
