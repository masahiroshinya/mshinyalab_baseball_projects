## 4. 結果の整理

### 4.1 確定して言えること（9 名でも 8 名でも同じ結論）

- **RT** は条件で異なり、Go/Stop が Simple より約 38 ms 長かった
- **MT** は条件で異なり、Free が他の 3 条件より 113〜168 ms 長く、Go/Stop が Simple より約 55 ms 長かった
- **① フック局面**の時間は条件で大きく異なり（η²p = .80）、6 組すべてに差があった。短い順に Simple（262 ms）< Go/No-Go（289 ms）< Go/Stop（343 ms）< Free（422 ms）で、9 名の並びはほぼそろっていた（Kendall's W = .96）
- **ピーク速度**（PeakVelTop）は条件で変わらなかった
- 以上から、MT の延長は ① フック局面に集中し、スイングの速さは保たれていた。8 名の解析（2026-10-29）の結論は、S04 を加えても変わらなかった

### 4.2 条件で変わるとは言えないこと

- **③ 加速局面**：主効果は有意でなく（p = .120）、有意な組もなかった。条件の平均の差は 66〜72 ms の範囲で、時間の刻み（4 ms、1 フレーム）の 1〜2 個分である。8 名で有意だった主効果は、S04 を加えると消えた
  - ただし Friedman 検定は p = .029 で、7 指標で唯一 Mauchly の検定が有意（p = .033）だった。分布が偏っている可能性があり、扱いに注意する

### 4.3 まだ確定とは言えないこと

- **② ループ局面**：主効果は p = .049 で境界的。Go/Stop が Free より約 29 ms 短い（p = .009）組は 8 名と同じで、Friedman 検定も有意（p = .035）。傾向は続いているが、主効果の p が .05 に近く、S04 の加わり方で結論が変わりうる
- **PeakFz2**：主効果は p = .046 だが、有意な組はなく、Friedman 検定も有意でない（p = .102）。条件の差があるとは、まだ言えない

## 5. 注意すること

- **S04 の top の値は少数の試行による**：top を使う指標の S04 の値は、Mark = k の 3〜5 試行の平均である。8 名 → 9 名で ② ③ の結論が動いたのは S04 を加えたためで、S04 の値の確からしさに左右されている。RT と PeakFz2 は床反力から求めるので、この影響はない
- **人数が少ない（9 名）**：有意でない結果は「差がない」ではなく「差があるとは言えない」と書く
- **指標の間の多重比較は補正していない**：7 指標を別々に検定している。主な仮説に関わる指標（MT・① フック）と、確認のための指標を分けて扱う
- **S03 は 2026-11-03 に再測定する予定**：再測定したデータを加えたら、x2 → x8 を通してこの解析をやり直す（10 名）
